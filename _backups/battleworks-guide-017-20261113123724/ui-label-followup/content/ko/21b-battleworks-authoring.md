## 1. 레시피로 시작하기

[지팡이 또는 편집 명령](#mob-editor/mob-editor-setup)으로 BattleWorks를 엽니다. **패턴 작업대 → 공격 레시피**에서 시작할 공격을 고르세요.

| 레시피 | 기본 동작 |
| --- | --- |
| 넓게 베기 — Wide sweep | 연결된 지면 경고와 기본 휘두르기를 사용하는 근접 공격 |
| 돌진 후 베기 — Charge and slash | 준비 중 접근하고 멈춘 뒤 베기 |
| 지연 지면 공격 — Delayed ground strike | 타겟 위치를 저장하고 그 자리를 경고한 뒤 저장 위치 타격 |
| 후퇴 후 반격 — Retreat and counter | 준비 중 물러난 뒤 전방 히트박스로 반격 |

레시피는 편집 가능한 패턴과 리소스를 추가합니다. 외부 마법이나 모델을 설치하지는 않습니다. 모델과 맞지 않는 애니메이션은 제외되므로 현재 NPC에 맞는 클립을 선택하세요. 지연 지면 공격은 저장한 위치를 때리므로, 플레이어가 이동하면 피할 수 있습니다.

## 2. 간편 편집으로 조정하기

추가한 패턴을 선택하고 **간편 편집**을 엽니다. 이름, 활성화, 최소·최대 거리, 준비·실행·회복 길이, 재사용 대기를 조정합니다. 시간 입력에는 초 환산도 표시됩니다. 정상 서버 속도에서 20틱은 1초입니다.

연결된 히트박스를 골라 피해와 기본 크기를 바꾸세요. 다른 종류의 액션이 피해를 주는 공격은 **상세 편집**에서 해당 액션을 조정합니다. 화면을 전환해도 기존 조건·이벤트·이동·애니메이션은 유지됩니다. 간편 화면이 기존 문서를 단순한 파일로 바꾸지는 않습니다.

피해나 크기를 바꾸기 전에 **여러 패턴이 공유 중**인지 확인하세요. 현재 패턴만 바꾸려면 **이 히트박스 독립시키기**를 사용합니다. 전체 모양과 타격 틱은 [히트박스 라이브러리](#mob-editor/battleworks-hitboxes)에서 확인합니다.

## 3. 다른 문서에서 쓸 기술 보관하기

1. 공격을 선택하고 **기술 저장**을 누릅니다.
2. 같은 서버에서 같은 플레이어로 다른 전투 문서를 엽니다.
3. **내 기술**에서 항목을 선택한 뒤 **기술 불러오기**를 누릅니다.
4. 가져온 패턴·콤보 대상·히트박스·파티클을 확인한 뒤 문서를 저장합니다.

보관함은 해당 서버의 플레이어별로 나뉩니다. 불러오면 독립된 리소스 ID를 만들고 묶음 내부 참조를 다시 연결합니다. 참조한 파티클 파일은 묶을 수 있지만 외부 모드·모델·소리·스킬 제공자는 대상 환경에도 필요합니다. 모델이 맞지 않아 가져오기가 거부되면 문서는 바뀌지 않습니다.

## 4. 복사할 때 공유 범위 고르기

| 기술 복사 선택 | 결과 |
| --- | --- |
| 독립 복사 — Independent copy | 공격, 연결된 콤보 패턴, 히트박스, 파티클 효과를 새 ID로 복사 |
| 기존 리소스 공유 — Share existing resources | 선택한 패턴만 복사하고 연결 리소스는 공유 |

변형 공격의 피해나 파티클을 따로 바꾸려면 독립 복사를 사용하세요. 여러 공격이 같은 정의를 유지해야 하면 공유를 선택합니다. 공유 리소스를 수정하면 이를 참조한 모든 패턴에 영향을 줍니다. 이름만 바꾸어도 참조가 분리되는 것은 아닙니다.

## 5. 되돌린 뒤 저장·적용하기

**실행 취소 / 다시 실행**은 문서 편집과 파일 불러오기 상태를 되돌립니다. 뒤로·앞으로 화살표는 편집 화면 방문 기록을 이동합니다. 문서 실행 취소로 서버 보관함에 이미 저장한 기술이 삭제되지는 않습니다.

새 작업 경로는 **다른 이름으로 저장**으로 만듭니다. 원하는 NPC가 연결되어 있으면 이후 **저장**을 눌러 연결하거나 NPC 파일 목록에서 적용하세요. [파일과 보관함 경로](#mob-editor/battleworks-files)도 참고하세요.

Simulation으로 모션과 히트박스를 확인한 다음 서바이벌에서 실제 전투를 시험합니다. 시각 경고만으로 피해가 생기지 않습니다. 보스 전체를 시험하기 전에 [히트박스 연결 지면 경고](#mob-editor/battleworks-hitboxes)와 [아레나 초기화](#mob-editor/battleworks-encounters)를 설정하세요.
