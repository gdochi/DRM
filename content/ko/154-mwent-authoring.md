## 테이블에 게임 연결

운영자는 빈손으로 테이블을 Shift+우클릭해 저장한 MWENT 게임이나 내장 프로필을 선택합니다. 같은 게임 ID를 여러 테이블에서 재사용할 수 있습니다. 연결할 때마다 블록별 JSON을 만들 필요가 없습니다. 일반 플레이어의 덱 선택과 운영자의 공용 게임 설정은 별개입니다.

현재 게임 편집기에서는 규칙·시작 조건·보상·연출과 내장 AI 선택을 관리합니다. 승리 보상은 Rewards 탭에서 설정합니다. 기본 AI 연습은 무료·무보상이며, 서버가 시작 조건·지급 대상·승패를 판정합니다. DRM 통화·조건·액션을 선택하면 해당 제공자가 필요합니다.

## 0.1.5 사용자 카드 만들기

1. **뭰트 테이블 → 카드 편집기** 또는 **Mods Config → Minigames → 커스텀 카드 → 카드 편집기**로 엽니다. `/minigame cards`도 사용할 수 있습니다.
2. 새 카드를 만들거나 기존 카드를 **다른 이름으로 저장**해 사용자 카드로 복제합니다.
3. 진영·프레임·희귀도·전력·비용, 모델과 장비를 정합니다.
4. 능력의 발동 시점 → 조건 → 대상 → 작동 → 비용·제한 순서로 설정합니다.
5. 저장한 카드를 컬렉션·덱·카드팩·획득 풀에 연결하고 실제 대전에서 확인합니다.

저장은 카드 정의를 등록하며 실물 카드나 소유 수량을 지급하지 않습니다. 기본 카드를 외형 변형으로 복제한 경우 원본과 소유 수량·복사 제한을 공유하고 전투 수치는 원본을 따릅니다. 진행 중인 경기는 시작할 때의 카드 내용을 유지합니다.

능력은 카드당 최대 12개이며 각 능력은 조건 8개·작동 8개를 지원합니다. 배치·명령·턴 종료·파괴·이동·회복·카드 사용 등의 사건을 연결합니다. 직접 대상 선택은 배치와 명령에 사용하고, 자동 발동에는 전체·무작위 대상 등을 사용합니다. 시나리오·장소·함정과 장 진행도 작성할 수 있습니다.

## 공성 모델과 선택 연동

0.1.5는 노포·투석기·대포·자동장전기·동력식 노포·속사포·보급 수레의 자체 모델을 제공합니다. 엔티티 카드 외형의 병기 모델에서 선택합니다. Create·Big Cannons 없이도 기본 모델과 카드 능력을 사용합니다. 호환 외형 팔레트는 실제 설치된 자산이 있을 때만 활용하며 카드 전투를 월드 동력망이나 실제 포탄 장치와 연결하는 기능은 아닙니다.

DNPC 클론 외형은 선택 연동입니다. 기본 대체 엔티티를 함께 저장하며, 제공자나 템플릿이 없으면 기본 모델로 돌아갑니다. 클론의 AI·작업·소지품·전투 능력치를 카드 규칙으로 가져오지 않습니다.

## 카드팩 만들기

카드팩 편집기는 고정 카드·가중치 풀·수량·마지막 선택 카드와 팩 외형을 설정합니다. 카드 풀에 넣은 카드가 플레이어에게 사용 가능한지 확인하세요. 팩의 표시와 개봉 결과는 서버가 관리합니다. 상인·상자 배포는 [획득 설정](#mwent/acquisition)에 연결합니다.

## 저장 위치 참고

| 위치 | 내용 |
| --- | --- |
| `config/dochi_minigames/games/mob_battle/` | 재사용하는 MWENT 게임·AI 연결 프로필 |
| `config/dochi_minigames/cards/custom_card_<번호>.json` | 0.1.5 사용자 카드 정의 |
| `config/dochi_minigames/card_packs/` | 카드팩 정의 |
| `config/dochi_minigames/acquisition.json` | 활성 카드 획득 설정 |
| `<월드>/data/dochi_minigames/cards/` | 플레이어별 보관 수량 |
| `<월드>/data/dochi_minigames/decks/` | 플레이어별 저장 덱 |

DRM을 설치해도 게임·카드·팩은 Minigames가 소유합니다. 기본 파일을 바꾸기보다는 Save As로 사용자 파일을 만들고 연결하세요. 예전 `table_<32자리 hex>` 파일은 `config/dochi_minigames/internal/tables/`의 읽기 호환 자료로 보존하며 새 블록마다 자동 생성하지 않습니다. DRM GUI Maker의 레이아웃 JSON은 게임 규칙과 별도입니다.
