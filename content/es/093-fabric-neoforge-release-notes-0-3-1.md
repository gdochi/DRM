## Agregar nombres y etiquetas al diálogo

En **GUI Maker → Text → Content**, elija su propio texto o **NPC name**. Coloque etiquetas independientemente del diálogo principal: nombres, ubicaciones o instrucciones cortas.

Establezca la posición, el tamaño, el relleno y el borde de cada cuadro **Save As** y selecciónelo para la conversación. Seguir [personalización de pantalla](#core-fabric/gui-system).

![Un cuadro de texto independiente seleccionado en GUI Maker.](assets/media/guides/drm-031-neo1211/gui-text.png "DRM 0.3.1 / NeoForge 1.21.1. Añádelo con + Texto y elige Entrada directa o Nombre de NPC en Contenido. El cuadro de texto sobre el texto del diálogo se coloca independientemente del cuerpo del diálogo.")

## Actualización DNPC de la capacitación y el apoyo al diálogo

En los objetivos más antiguos 1.20.1 / 1.21.1, los parches Editor compatibles DNPC y Cobblemon permiten a los entrenadores con bloqueo de posición correr y regresar.

Cobblemon El modo **Sequential** en Fabric/NeoForge 1.21.1 da recompensas después de completar el diálogo. Ver [ ajustes de recompensa](#drm-cobblemon-editor/cobblemon-trainer-editor).

## Archivos de instalación

Forge 1.20.1 usa Java 17; Fabric/NeoForge 1.21.1 usa Java 21; los archivos separados 26.3 usan Java 25. Ver [26.3 diferencias](#core-fabric/minecraft-26-3).
