# 문서용 무음 반복 영상

초기 작업에서는 GIF 3개를 영상으로 변환하고 신규 촬영 3개를 더해 5개 언어 문서 40곳에 적용했다. 이후 GIF 변환본의 색상 손실을 확인해 간호순·침대·레머넌트 장면을 실제 게임에서 다시 촬영했다. 교체된 3개 영상은 `src/media/guides/short-videos-color-20261106/`에 있고, 관련 문서 20곳이 새 경로를 사용한다. 나머지 초기 영상은 `src/media/guides/short-videos-20261106/`에 유지한다. 커밋·푸시와 모드 구현 변경은 수행하지 않았다.

신규 장면은 NeoForge 1.21.1 / DRM 0.3.1 / DNPC 0.1.3 / BattleWorks 0.1.6으로 별도 촬영 월드에서 기록했다. 촬영 도구가 실제 편집 화면과 서버 요청을 조작했으며 수동 마우스 녹화나 NPC 생성 전체 과정으로 표현하지 않는다. 대화 예제 준비와 전투 설정은 녹화 전에 수행했다. BattleWorks 클립은 피해 발생을 검증한 자료다. 기본 생성 패턴의 애니메이션 실패 로그가 있으므로 애니메이션·공격 예고 범위·회피의 성공 자료로 취급하지 않는다. 해당 모드 구현은 변경하지 않았다.

최초 GIF 변환본은 이미 팔레트가 줄어든 입력을 사용해 녹색 안내 글자 등이 갈색으로 뭉개졌다. 이를 보정 필터로 덮지 않고, 별도 촬영 월드 `color-videos-neo1211-en-01`에서 1,592개의 새 원본 PNG 프레임을 기록해 교체했다. GIF를 거치지 않고 BT.709 색 행렬·범위를 명시해 MP4/WebM을 만들었으며, 포스터는 첫 원본 프레임과 RGB 픽셀이 일치한다. 브라우저는 WebM을 우선 사용하고 MP4로 호환 재생한다.

## 표시와 검증

- 자동 재생·무음·무한 반복·모바일 인라인 재생과 기본 재생 조작을 제공한다. 시스템의 동작 줄이기가 활성화된 경우 자동 재생을 멈추고 수동 재생을 허용한다.
- 첫 프레임 PNG를 포스터로 제공하고 1280×720 크기를 예약한다. 환경 배지와 기존 다국어 캡션을 보존했다. Forge 문서에 쓰인 NeoForge 영상도 영상 캡션에 실제 촬영 환경을 명시한다.
- `scripts/encode-guide-video.py`: 기본 입력은 타임스탬프가 있는 원본 PNG 프레임이다. 기존 GIF의 팔레트 손실을 다시 영상에 옮기지 않도록 GIF 입력은 명시적인 `--allow-gif`가 있어야 허용한다. 두 영상 형식의 색 정보와 전체 프레임 디코딩을 확인하고 해시·길이·크기를 기록했다.
- `npm.cmd run build`, `npm.cmd run verify`, `npm.cmd run verify:translations`: 문서·영상·포스터·환경·배포 경로와 번역 일치 검증.
- `npm.cmd run verify:videos`: 80개 데스크톱/모바일 화면과 고유 영상 6개에서 실제 자동 재생, 디코딩 프레임 증가, 탐색, 일시정지, 반복 경계, MP4 호환 재생 및 동작 줄이기를 확인했다. 이전 GIF 전용 검사 두 개는 이 검사로 대체했다.
- `docs/evidence/guide-videos-20261106/`: 인코딩 영수증, 실제 환경/JAR 해시, 서버 검증 기록, 대표 프레임과 브라우저 결과.
- 색상 교정 후 `docs/evidence/video-colors-20261106/`에 새 촬영·워크플로 확인·프레임 해시와 색 비교를 기록했다. 실제 Chrome 디코딩 화면과 원본 PNG의 평균 RGB 오차는 255단계 기준 약 0.78~1.14였다. 사이트의 영상 화면 140개와 고유 영상 11개의 재생·모바일·MP4 호환 검사도 통과했다.

## 복구와 정리

수정 전 파일과 원본 GIF 백업: `_backups/guide-videos-20261106-210045/`. 신규 촬영은 `short-videos-neo1211-en-04` 실행을 채택했다. 첫 실행의 로컬 연결 권한 실패, 다음 실행의 구도 문제, 세 번째 실행의 NPC 위치 이동에 따른 대화 거리 문제는 게시본에서 제외했다. 최종 촬영 월드·실패한 실행·인코딩 도구 설치본·중간 프레임은 모두 정리했다. 재사용 가능한 촬영 계획과 변환·검증 코드는 보존했다.

색상 교정 전 영상 9개 파일·문서·설정·인코더 백업: `_backups/video-colors-20261106-220727/`. 새 촬영 원본의 대표 프레임·전체 프레임 해시·서버 확인·인코딩 영수증은 보존하고, 촬영 인스턴스·대량 중간 프레임·작업용 인코딩 도구는 정리했다. 교체 전 팔레트 변환 영상은 백업에 보존하며 게시 자산에서는 제거했다.
