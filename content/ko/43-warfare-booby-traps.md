## 편집기와 런타임 구분

`DW 부비트랩 코어`는 크리에이티브 모드 제작 도구입니다.

* 코어로 블록을 우클릭하면 해당 블록의 편집기를 엽니다.
* 코어로 허공을 우클릭하면 등록된 트랩 관리자를 엽니다.
* 설정한 트랩을 일반 블록 상호작용으로 시험할 때는 코어를 손에서 치웁니다.

편집기와 관리자는 제작자 화면입니다. 비밀번호 입력과 트랩 효과는 플레이어 런타임 동작이며 서버가 최종 검증과 발동을 판정합니다.

## 부비트랩 유형

| 유형 | 대상과 동작 |
| --- | --- |
| `비밀번호 문` | 바닐라 문 전용이며 인증 후 문을 엽니다. |
| `비밀번호 상자` | 인벤토리 GUI가 있는 블록에 인증 후 접근합니다. |
| `즉시 폭발 블록` | 상호작용 즉시 폭발합니다. |
| `지연 폭발` | 설정한 경고를 출력하고 기다린 뒤 폭발합니다. |
| `LRT 수류탄` | 선택 모드가 설치된 경우 LesRaisins Tactical Equipments 원본 수류탄 엔티티를 발사합니다. |

유형을 고르면 필요한 기본 필드를 자동 적용하지만 저장 전에 결과 전체를 확인하세요.

## 비밀번호와 접근 규칙

비밀번호 트랩은 숫자 4~12자리 PIN 또는 1~32자 암호문을 지원합니다. 대소문자 구분, 소유자 통과, 진입 방향, 반대편 처리, 문 닫힘 방식, 허용 오류 횟수, 오류 누적 시간, 잠금 시간, 실패 효과를 설정할 수 있습니다.

실패 효과는 경고 메시지, 직접 피해, 폭발 중 하나입니다. 비밀번호는 설정 후 편집 가능한 평문 초안으로 유지하지 않으며, 비밀번호 방식이나 대소문자 정책을 바꾸려면 새 비밀번호를 입력해야 합니다.

## 페이로드와 부가 효과

폭발 트랩은 위력, 블록 파괴, 화염, 지연 시간, 경고음, 경고 입자를 설정합니다. 선택 효과는 발동 플레이어를 밀쳐내고, 발동 플레이어·반경 내 모든 플레이어·반경 내 모든 생명체에 최대 8개의 포션 효과를 적용할 수 있습니다.

LRT 수류탄 페이로드는 수류탄 종류, 신관, 강도, 수량, 방향, 각도, 필요한 경우 고정 yaw/pitch를 설정합니다. LesRaisins Tactical Equipments가 없거나 선택한 수류탄을 만들 수 없으면 저장·발동을 거부합니다.

## 생명주기와 시험

트랩은 `활성`과 `무장`이 모두 켜져 있을 때만 발동합니다. 소유자 통과, 파괴 방지, 레드스톤 동작, 쿨다운, 일회용, 발동 후 상태 제거, 대상 블록 제거, 주변 블록 파괴, 화염 생성도 중요한 설정입니다.

다음 순서로 시험하세요.

1. `활성`과 `무장`을 켠 단순 트랩 하나를 저장합니다.
2. `DW 부비트랩 코어`를 손에서 치웁니다.
3. 소유자 통과를 켰다면 소유자가 아닌 테스트 플레이어로 일반 상호작용합니다.
4. 효과와 생명주기를 확인한 뒤 비밀번호 실패, 포션 효과, LRT 페이로드를 추가합니다.

## 관리자, 마커, 프로필

코어로 허공을 우클릭하면 등록 트랩을 검색하고 정상, 비활성, 비무장, 청크 미로드, 대상 블록 변경, 지연 폭발 대기, 필수 모드 없음 상태를 확인할 수 있습니다. `트랩 해제`는 트랩 상태만 제거하고, `블록 제거`는 상태와 대상 블록을 함께 제거합니다. 파괴성 관리자 동작은 같은 버튼을 한 번 더 눌러 확인합니다.

크리에이티브 모드에서 코어를 들고 있으면 가까운 설정 트랩을 서버 판정 외곽선과 작은 마커로 볼 수 있습니다. 재사용 JSON 프로필은 아래에 저장됩니다.

```text
config/dochi_warfare/booby_traps/profiles/
```

프로필을 불러오면 현재 편집 초안에 설정을 적용합니다. 서버는 저장 전에 해당 프로필이 선택 블록 유형에 유효한지 다시 검사합니다.
