## 승리 조건과 전장

최대 세 라운드에서 **먼저 두 라운드를 이기는 것**이 목표입니다. 각 플레이어는 전열·후열 두 줄을 사용하며 한 줄에 고정 소켓 9칸이 있습니다. 보드에 남은 유닛의 현재 전력이 내 점수입니다. 방어구·보호막·보급은 점수에 직접 더하지 않습니다. 0.1.5의 시나리오·장소·함정도 소켓을 쓰지만 유닛 전력을 더하지 않습니다.

두 사람이 모두 패스하면 점수를 비교합니다. 높은 쪽이 라운드 승리를 얻으며, 동점이면 양쪽 모두 라운드 승리를 얻습니다. 이 때문에 경기 전체가 무승부로 끝날 수도 있습니다.

## 1. 덱 선택과 손패 교체

진영·덱·리더를 확인하고 시작합니다. 처음 손패는 10장입니다. 코인 토스로 선공을 정하고 첫 손패 교체에서 선공은 최대 3장, 후공은 최대 2장을 바꿀 수 있습니다. 계속하기로 전투를 시작합니다. 교체는 필수가 아닙니다.

다음 라운드에는 덱이 남아 있는 범위에서 최대 3장을 추가로 뽑습니다. 손패 한도는 10장입니다. 꽉 차서 받지 못한 추가 드로우는 그 라운드의 교체 기회에 더해집니다. 기본 교체 기회는 2회입니다. 라운드 승자가 다음 라운드의 선공을 맡습니다.

## 2. 내 차례에 카드 사용

1. 손패에서 카드를 고릅니다. 우클릭으로 상세 능력과 현재 상태를 먼저 확인할 수 있습니다.
2. 유닛은 허용된 빈 소켓을 선택합니다. 전열 위치나 바로 옆의 아군이 중요한 카드도 있습니다.
3. 대상이 필요한 능력은 강조된 합법적인 대상을 선택해 해결합니다.
4. 사용 가능한 명령·리더 능력을 활용한 뒤 **턴 종료**를 누릅니다.

일반적인 차례에는 손패 카드 1장을 사용합니다. 카드가 만들어 낸 소환·추가 사용은 그 능력을 따릅니다. **사용**은 실제 손패 카드를 내는 행동이고 **소환**은 효과로 필드에 등장시키는 행동입니다. 소환은 보통 배치 능력이나 카드를 직접 사용할 때의 연계를 재발동하지 않습니다.

## 3. 명령과 리더 능력

**배치**는 카드를 사용할 때, **명령**은 전장에 있는 카드의 능력을 직접 활성화할 때 발동합니다. 명령은 충전·재사용 대기·보급 비용·봉인 상태를 확인하세요. 열의가 없는 카드는 배치한 차례에 명령을 바로 쓰지 못합니다. 리더 능력은 별도의 사용 횟수를 가지며 손패 카드로 세지 않습니다.

예를 들어 협동 진형 유닛은 같은 열의 바로 양옆에 방어구가 있는 아군을 두면 내 턴 종료에 명령 재충전 또는 대기 감소를 얻습니다. 두 유닛이 같은 열 어딘가에 있는 것만으로는 부족합니다.

## 4. 패스할 때 판단하기

**패스**는 이번 라운드의 남은 차례를 포기하는 행동입니다. 상대는 계속 카드를 낼 수 있고, 나도 다음 차례에 다시 참여할 수 없습니다. 내 차례에 카드나 다른 행동을 하기 전에 선택합니다.

| 상황 | 생각할 점 |
| --- | --- |
| 상대가 이미 패스함 | 필요한 만큼만 앞선 뒤 멈추면 다음 라운드 손패를 아낄 수 있습니다. 턴 종료 효과도 점수에 영향을 줍니다. |
| 점수 차를 메우려면 손패가 많이 필요함 | 이번 라운드를 내주고 다음 라운드에 자원을 남기는 선택을 비교합니다. |
| 명령·성장 카드가 준비됨 | 한 차례 더 진행했을 때 얻을 점수와 상대의 제거 가능성을 함께 봅니다. |

라운드가 바뀌면 보통 전장을 정리하고 남은 손패를 보존합니다. 한 라운드 유지 등 예외는 카드 설명을 따릅니다. 라운드 정리는 일반적인 파괴와 달라 유언을 자동 발동하지 않습니다.

## 자주 만나는 상태

| 상태 | 의미 |
| --- | --- |
| 방어구 / 보호막 | 방어구는 보통 피해를 먼저 흡수하고, 보호막은 피해 1회를 막습니다. |
| 중독 | 중독이 두 번 누적되면 해당 유닛을 파괴합니다. |
| 출혈 / 활력 | 유닛 소유자의 턴 종료에 각각 피해 1 / 전력 +1을 적용하며 지속 횟수를 줄입니다. 출혈은 방어구를 무시합니다. |
| 봉인 / 정화 | 봉인은 명령·지속 능력을 막습니다. 정화는 제거 가능한 상태를 지우며 방어구를 없애는 기능은 아닙니다. |
| 소멸 | 해당 유닛이 전장을 떠날 때 묘지에 남기지 않습니다. 부활·토큰의 반복 사용 제한을 확인하세요. |

## 시간 제한과 나가기

일반 경기는 턴 60초, 손패 교체 20초, 라운드 전환 5초를 사용합니다. 턴 제한을 넘기면 미해결 선택을 처리하고, 카드를 내지 않았다면 손패 1장을 버린 뒤 턴을 넘깁니다. 학습은 시간제한이 없습니다.

Esc로 카드 설명을 먼저 닫을 수 있습니다. 진행 중인 경기에서 나가기를 확정하면 패배로 처리합니다. PvP에서는 접속 종료·사망·차원 이동·테이블에서 64블록보다 멀어지는 경우도 몰수패입니다. 화면을 닫거나 안내를 읽는 동안 일반 경기의 서버 타이머가 멈춘다고 생각하지 마세요.

전장을 회전·확대하거나 3D / 카드 표시 모드를 바꿔도 같은 서버 규칙으로 판정합니다. 다음은 [진영별 운영](#mwent/factions)과 [덱 편성](#mwent/cards-decks)을 확인하세요.

## 배틀 음악

기본 배틀 음악은 플레이어 덱의 진영을 따라 코인 토스·손패 교체부터 이어집니다. 게임 프로필이 음악을 직접 지정하면 그 설정을 우선합니다. 상단 Rulebook 왼쪽의 재생/정지·볼륨으로 조절합니다. 0%는 재생 위치를 유지하고, 정지 후 다시 재생하면 곡을 처음부터 시작합니다. 조절값은 로컬에 저장하며 서버 게임 JSON이나 Minecraft 전체 볼륨을 바꾸지 않습니다.
