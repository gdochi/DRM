## 이 화면은 무엇인가

스폰 컨트롤 화면은 서버의 활성 자연 스폰 설정을 받아 편집하는 **제작자용 에디터**입니다. 플레이어에게 표시되는 런타임 GUI가 아닙니다. 화면에서 바꾼 값은 초안이며, 상단 `저장` 또는 프리셋 작업을 완료해야 서버 설정에 반영됩니다.

## 상단바

| 버튼 | 동작 |
| --- | --- |
| `에디터` | DRM Core가 있을 때 공용 에디터 선택기로 돌아갑니다. |
| `새로 만들기` | 현재 화면에 빈 스폰 세트 초안을 만듭니다. 저장 전까지 활성 서버 설정은 바뀌지 않습니다. |
| `불러오기` | 전체 세트 또는 대상 프리셋을 검색해 불러옵니다. |
| `저장` | 현재 초안을 서버의 활성 설정으로 저장하고 즉시 적용합니다. |
| `다른 이름으로 저장` | `전체 세트`와 `현재 대상 프리셋` 중 저장 범위를 먼저 선택합니다. |
| `초기화` | 마지막으로 서버에서 받은 기준 상태로 현재 초안을 되돌립니다. |
| `닫기` | 에디터를 닫습니다. 저장하지 않은 변경은 적용되지 않습니다. |

## 왼쪽: 엔티티 / 클론 카탈로그

카탈로그는 규칙을 만들 대상을 고르는 영역입니다.

- 일반 등록 `Mob`과 CustomNPCs 저장 클론을 함께 검색합니다.
- 검색어는 ID, 표시 이름, 모드 이름을 찾습니다.
- `mod:<id>` 또는 `support:<state>` 검색을 사용할 수 있습니다.
- `필터`에서는 엔티티/클론, 지원 상태, 설치 모드를 조합합니다.
- 선택한 엔티티는 가운데 미리보기에 렌더됩니다.
- 아래 `원본 스폰: ON/OFF`는 선택한 등록 엔티티의 원본 자연 스폰 정책입니다. 클론에는 해당하지 않습니다.

발사체, 효과, 차량 같은 비-Mob EntityType은 기본 목록에 나오지 않습니다. 보스나 특수 엔티티는 `실험적`으로 표시될 수 있습니다.

## 가운데: 선택 미리보기와 자연 스폰 규칙

가운데 위쪽은 현재 카탈로그 대상의 모델 미리보기입니다. 아래쪽은 규칙 관리자입니다.

| 보기 | 의미 |
| --- | --- |
| `선택 대상` | 현재 카탈로그 대상에 귀속된 규칙만 표시합니다. 기본 보기입니다. |
| `전체 구성` | 모든 대상의 구성된 규칙을 한곳에서 관리합니다. |

`전체 구성`에서 규칙 본문을 누르면 그 규칙을 선택하고 카탈로그도 실제 대상에 맞춰 이동합니다. 다른 대상의 설정이 현재 대상에 복사되거나 상속되는 것은 아닙니다.

규칙 행의 조작 위치는 서로 다릅니다.

| 위치 | 동작 |
| --- | --- |
| 행 왼쪽 체크박스 | 복제, 활성화, 비활성화, 삭제할 규칙을 일괄 선택 |
| 행 본문 | 오른쪽 인스펙터에서 편집할 규칙 선택 |
| 행 오른쪽 스위치 | 해당 규칙 한 개의 활성 상태 전환 |

`규칙 추가`는 현재 카탈로그 대상에 새 프로필을 만듭니다. `복제`, `활성화`, `비활성화`, `삭제`는 체크된 규칙에만 적용됩니다. 삭제는 확인창을 거치며 저장하기 전까지 초안 변경입니다.

## 검색, 필터 및 정렬

규칙 검색은 이름, 프로필 ID, 대상 키, EntityType, 클론 탭/이름과 오류 이유를 찾습니다. `필터 및 정렬`에서는 다음을 선택합니다.

- 상태: 전체, 활성, 비활성, 오류
- 정렬 기준: 우선순위, 이름, 대상
- 방향: 오름차순 또는 내림차순

검색이나 필터 때문에 규칙이 숨은 경우 삭제된 것이 아닙니다. `선택 대상`에 규칙이 있지만 결과가 비었다면 검색어와 상태 필터를 먼저 초기화하세요.

## 오른쪽: 규칙 인스펙터

오른쪽은 현재 선택한 프로필의 실제 값입니다. 영역은 `기본 정보`, `월드 조건`, `스폰 확률과 무리`, `개체 수 제한`, `생명 주기`로 나뉩니다.

차원과 바이옴은 검색 가능한 다중 선택창을 사용합니다. 아무것도 선택하지 않으면 전체 허용입니다. 숫자 필드는 각각 독립된 값이며, 범위를 거꾸로 입력하면 저장 과정에서 안전한 순서로 보정될 수 있습니다.

인스펙터 아래의 EntityType 또는 클론 표시는 **현재 편집 중인 규칙의 실제 귀속 대상**입니다. 카탈로그 미리보기와 이 표시가 다르다면 `전체 구성`에서 다른 규칙을 선택했는지 확인하세요.

## 고급 진단

`고급 진단`은 일반 편집과 분리된 운영 도구입니다.

| 작업 | 월드 영향 |
| --- | --- |
| `현재 위치 검사` | 엔티티를 만들지 않고 현재 위치의 조건과 개체 수 제한을 검사 |
| `몹 1개 생성` | 확인 후 실제 관리 엔티티 한 개 생성 |
| `생성 개체 정리` | 이 모드가 생성하고 추적 중인 시험/관리 엔티티 제거 |

진단은 현재 초안을 서버에서 임시 검사하며 활성 설정 파일을 먼저 덮어쓰지 않습니다.
