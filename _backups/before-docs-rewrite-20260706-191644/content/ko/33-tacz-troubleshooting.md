## 증상별 점검

| 증상 | 가능한 원인 | 점검 |
| --- | --- | --- |
| NPC가 총을 안 쏨 | 타겟 없음, 설정 미저장, 거리 조건 | 타겟과 전투 자세 확인 |
| 재장전 후 멈춤 | 탄약 설정, 모드 호환성 | Reload 옵션과 탄창 모드 점검 |
| 같은 진영에게 피해가 안 들어감 | 필터 또는 우호 판정 | 팩션과 태그 예외 규칙 확인 |
| 총 대신 탄약을 든 것처럼 보임 | 렌더 또는 상태 동기화 문제 | 최신 버전에서 재현 여부 확인 |

## 빠른 진단 순서

1. 새 NPC 하나로 최소 환경에서 재현합니다.
2. 총기 하나, 탄약 하나만 남기고 확인합니다.
3. 타겟 필터를 끄고 기본 적대 대상으로 테스트합니다.
4. 재장전 옵션을 켠 상태와 끈 상태를 각각 비교합니다.
5. 마지막으로 클라이언트 표현 문제인지 실제 전투 로직 문제인지 나눕니다.
