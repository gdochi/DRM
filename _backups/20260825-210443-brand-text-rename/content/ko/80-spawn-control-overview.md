## 정식 이름과 역할

**dochi spawn control**은 Forge 1.20.1용 서버 권한형 자연 스폰 편집 모드입니다. 내부 모드 ID는 `drm_spawn_control`이며, 게임 UI에서는 `스폰 컨트롤`로 표시됩니다.

등록된 일반 `Mob` EntityType과 CustomNPCs 서버 클론에 별도의 자연 스폰 규칙을 만들 수 있습니다. 차원, 바이옴, 높이, 조도, 시간, 플레이어 거리, 확률, 무리 크기, 개체 수 제한과 생명 주기를 서버가 검사한 뒤 엔티티를 생성합니다.

DRM Core가 있으면 공용 에디터 선택기와 DRM UI 정책을 사용합니다. DRM Core가 없어도 전용 키와 자체 화면으로 동작합니다.

## 데이터가 귀속되는 방식

모든 규칙은 월드의 활성 문서 하나에 저장되지만, 각 프로필은 정확히 하나의 대상 키에 귀속됩니다.

| 대상 종류 | 대상 키 예시 | 의미 |
| --- | --- | --- |
| 등록 엔티티 | `entity:minecraft:glow_squid` | 해당 EntityType 전용 규칙 |
| CustomNPCs 클론 | `clone:1:Guard` | 클론 탭 1의 `Guard` 전용 규칙 |

하나의 대상에는 여러 프로필을 만들 수 있습니다. 예를 들어 같은 좀비에 `숲 낮`, `숲 밤`, `동굴 희귀` 규칙을 각각 만들 수 있습니다.

:::warning 대상 간 상속 없음
Glow Squid 규칙이 Frog에 자동으로 이어지지 않습니다. `선택 대상` 보기에서 Frog에 규칙이 없다면 빈 목록과 빈 인스펙터가 보여야 정상입니다. `전체 구성`은 관리 목적으로 다른 대상의 규칙까지 보여 주지만, 행을 선택하면 카탈로그도 그 규칙의 실제 대상으로 이동합니다.
:::

## 원본 스폰과 관리 스폰

각 등록 엔티티에는 원본 자연 스폰 정책이 따로 있습니다.

| 정책 | 동작 |
| --- | --- |
| `원본 스폰: ON` | 바닐라 또는 원본 모드의 자연 스폰을 유지합니다. |
| `원본 스폰: OFF` | `NATURAL`과 `CHUNK_GENERATION` 유형의 신규 스폰을 차단합니다. |

`원본 스폰: OFF`는 명령어 소환, 스포너, 구조물, 번식, 버킷, 스크립트 생성까지 전역 차단하는 기능이 아닙니다. dochi spawn control이 자체 생성하는 엔티티는 관리 스폰 문맥으로 원본 차단기를 통과하지만, 다른 Forge 모드가 스폰을 거부하면 그 결과를 존중합니다.

원본 스폰과 관리 프로필을 모두 켜면 두 경로가 동시에 작동할 수 있습니다. 완전히 대체하려면 먼저 관리 규칙을 시험한 뒤 원본 스폰을 끄세요.

## 지원 범위

| 대상 | 지원 방식 |
| --- | --- |
| 바닐라와 일반 모드 `Mob` | 등록된 EntityType을 전용 어댑터로 생성 |
| CustomNPCs 저장 클론 | 설치된 서버 클론을 전용 클론 어댑터로 생성 |
| Ender Dragon, Wither, Warden | 카탈로그에서 실험적 대상으로 표시 |
| 발사체, 효과, 차량, `MISC` 엔티티 | 기본 카탈로그에서 제외하거나 지원하지 않음 |
| CustomNPCs의 빈 등록 EntityType | 직접 대상으로 쓰지 않고 저장 클론 목록으로 분리 |

미등록 엔티티, 사라진 클론, 별도 어댑터가 필요한 대상은 전체 서버를 중단시키지 않습니다. 문제가 있는 프로필만 비활성화되고 오류 이유가 표시됩니다.

## 서버 권한과 저장

편집기를 열고 저장하려면 OP 2레벨 또는 크리에이티브 권한이 필요합니다. 설정은 클라이언트 로컬 파일이 아니라 현재 월드 아래에 저장되며, 서버가 검증하고 즉시 적용합니다.

```text
<world>/serverconfig/dochi_rpg_maker/spawn_control/spawn_control.json
```

다음 문서에서는 설치, 첫 규칙 제작, 에디터 각 영역, 조건과 제한, 프리셋 공유 및 운영 절차를 순서대로 설명합니다.
