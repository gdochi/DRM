## 액션 찾기

데이사이클에서 시간대를 고른 뒤 액션 추가 또는 기존 액션 유형 변경을 엽니다. 검색어와 분류는 함께 적용됩니다. 전체 분류 검색으로 전환해도 검색어를 유지하며 한국어·영어 동의어와 내부 ID를 찾을 수 있습니다. 여러 단어를 입력하면 모든 단어가 일치하는 항목을 보여줍니다.

이동·대기 / 채취·생산 / 수집·운반 / 휴식·연출 / 상호작용에서 고릅니다. ESC나 바깥 클릭은 선택을 취소합니다. 시간대의 **✓**로 폼을 반영한 뒤 NPC 편집기의 저장까지 마칩니다.

## 일반·군용 스케줄 — 1.20.1·1.21.1

**스케줄 타입**에서 DNPC 일반 스케줄과 등록된 군용 제공자를 고릅니다. 새 NPC는 일반 스케줄이 기본입니다. 이전 NPC의 **이전 AI 호환 모드**는 기존 AI 제어권을 보존하는 선택이며, 일정 활성화는 별도의 **스케줄 활성화** 스위치로 정합니다.

**스케줄 불러오기**는 일반·군용 예시와 제공자의 저장 파일을 한 목록에 표시합니다. 구분과 필요 애드온 필터를 함께 사용하고, 설명과 요구 사항을 읽은 뒤 불러옵니다. 선택은 초안을 바꾸며 최종 저장 전까지 NPC에 적용되지 않습니다.

기존 일반 예시 15종과 군용 9종, 총 24종이 있습니다. DNPC 경계·순찰은 추가 모드 없이 사용할 수 있고, DW 경비·순찰·호위·비전투와 DWE 차량 승무원 예시는 해당 모드와 등록된 API가 필요합니다. Fabric에는 현재 DW 제공자가 없어 DW/DWE 예시가 요구 사항 안내로 표시됩니다.

DW 군용 일정은 **시간대당 액션 한 개**입니다. 일반 일정의 복수 액션·확률과 혼동하지 마세요. 일반·군용의 Rest/Bed에서 거주지와 침대를 지정하며 수면 중 이동과 보행 애니메이션은 멈춥니다. 이 군용 라이브러리 설명은 독립 26.3에 대한 제공자 지원 안내가 아닙니다.

## 탈것 탑승

1. 데이사이클 → 액션 추가 → **이동 → 탈것 탑승**을 선택합니다.
2. 주변 빈 탈것을 자동 선택하거나 🔍로 로드된 실제 개체를 지정합니다.
3. 탐색 중심과 반경을 정합니다. 기본 16블록, 범위 1~32블록입니다.
4. 좌석과 **일정 종료 시 하차**를 설정하고 NPC를 저장합니다.

시도 시간은 기본 600틱, 범위 20~2400틱입니다. 편집·상호작용·외부 AI 제어로 기다린 시간은 제외합니다. NPC가 걸어서 접근한 뒤 원본 탑승 절차를 사용하며 탈것을 생성하거나 먼 거리에서 순간 이동하지 않습니다.

| 대상 | 좌석과 연동 |
| --- | --- |
| 1.20.1·1.21.1 바닐라 탈것 | 보트·수레·말은 **-1** 자동 선택 |
| 호환 SuperbWarfare 차량 | 기존 대상의 실제 좌석 **0~63**, DW/DWE 제어 정책 유지 |
| 26.3 바닐라 탈것 | **-1** 자동 선택 또는 원본 승객 순서. 한 자리 탈것은 -1/0, 앞 좌석을 건너뛰지 않음 |

26.3의 바닐라 탑승은 DRM·DW·DWE 없이 사용할 수 있습니다. 이 기능이 DW/DWE의 26.3 지원을 뜻하지 않습니다.

하차가 필요하면 정차와 안전한 출구를 기다립니다. 안전한 위치가 없으면 탑승을 유지합니다. 전투·외부 명령으로 하차한 회차에는 즉시 재탑승하지 않습니다. 차량의 운전 경로·순찰·무장은 원본 모드 또는 DWE에서 설정합니다.

## 외부 제어와 일정 상점

다른 모드가 NPC를 제어하는 동안 DNPC 작업은 그 이동·표적을 덮어쓰지 않고, 제어권이 돌아오면 기존 작업·고용 처리를 재개합니다. 위치 고정은 기본적으로 유지하며 호환 코블몬 트레이너의 대시·복귀처럼 일시 이동을 허용한 경우만 유예됩니다.

DRM 일정 상점은 영업 종료·비활성화·상점 변경·NPC 제거 시 기존 거래 권한을 회수합니다. 이미 열린 화면이 남아 있어도 만료 거래는 거부됩니다. 다음 영업 시간의 새 상호작용과 일반 상점은 별도입니다.
