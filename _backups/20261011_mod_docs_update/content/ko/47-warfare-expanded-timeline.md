## 제작 순서

1. 편집기 선택 화면에서 기믹 에디터를 엽니다.
2. `Create New`로 빈 문서를 만들거나 `Use Default`로 현재 위치 기준의 기본 폭격 초안을 엽니다.
3. 기준점과 동작 종류를 정합니다. 타임라인에 여러 동작을 배치할 수 있습니다.
4. 각 단계의 실행 틱, 좌표, 지원 대상과 수명을 설정합니다.
5. `Save As`로 이름을 정해 저장합니다.
6. `내 위치에서 실행`으로 저장된 전체 배치를 현재 위치 기준으로 호출합니다.

미저장 변경이 있거나 다른 사용자가 파일을 바꿨다면 먼저 저장하거나 새로고침해야 합니다. 화면의 미리보기는 배치 제작용이며 실제 지형에서의 이동·명중 결과를 대신하지 않습니다.

## 동작 종류

| 동작 | 설정과 결과 |
| --- | --- |
| 폭격 | 기체·폭탄·좌표·진입 방향·고도·투하 방식과 간격을 지정합니다. 원본 자유낙하 무장으로 공격합니다. |
| 차량 지원 | 차량 종류, 대수, 출발점·지원점, 간격, 팩션과 방어 반경을 정합니다. 지상 차량이 이동 후 주변을 방어합니다. |
| 기총 지원 | 항공/지상, 차량과 실제 무장, 진입 방향·거리·고도, 사격 구간, 시간·발사 횟수 상한을 정합니다. |
| NPC 이동 | 클론을 소환해 진격시키거나 구역 안의 기존 DW NPC를 선택해 이동시킵니다. |

기총 지원의 무장 목록은 서버가 검사합니다. 폭탄·로켓·미사일·저속 주포를 기총으로 선택할 수 없습니다. 항공 지원은 공격 후 이탈하고 지상 지원은 지정 거리에서 포탑으로 구간을 쓸어 사격합니다. 원본 RPM·탄약·과열·재장전·안전 판정은 유지됩니다.

NPC 클론은 DW 클론 보관함에서 선택합니다. 구역 선택은 DW AI가 켜진 CustomNPCs를 대상으로 하며 탑승·고용·다른 기믹 이동 중인 NPC는 제외합니다. 적을 만나면 기존 전투가 우선하고 이후 진격을 계속합니다. 경로를 순간 이동으로 통과하지 않습니다. 팩션은 숫자 ID를 사용하며 클론을 참조하는 파일명과 화면 표시 이름을 구별하세요.

## 시간과 기준점

20틱은 정상 20 TPS에서 1초입니다. 폭격의 실행 틱은 **첫 폭탄 투하 시점**이며 지면에 도달하는 시간은 별도입니다. 차량·기총·NPC 지원의 실행 틱은 소환 또는 이동 시작 시점입니다. 기총 사격 시간은 무장 사거리 진입부터 계산하고 수명·이탈이 먼저 오면 종료합니다.

`lifetime_ticks`는 임시 지원의 수명입니다. 소환한 NPC는 수명 종료 때 제거하고, 구역에서 선택한 기존 NPC는 이전 이동 설정을 복구합니다. 실행 중 제작자가 변경한 설정은 덮어쓰지 않습니다. 임시 지원 차량은 탑승·클론 저장·소울스톤 포획이 제한됩니다.

## 운영자 명령

권한 레벨 2가 필요합니다. `my_support`는 먼저 저장한 문서 이름이며 `.json`을 붙이지 않습니다.

```text
/dw callgimmicks my_support
/dw callgimmicks my_support ~ ~ ~
/dw bombard ~ ~ ~ superbwarfare:ju_87 superbwarfare:sc_250 10
```

첫 명령은 저장 좌표에서 실행합니다. 둘째 명령은 저장된 `origin`과 호출 좌표의 차이만큼 목표·출발점·지원점을 함께 옮깁니다. 마지막 예시는 호출 후 10틱에 첫 폭탄을 투하합니다. 차량·폭탄 ID는 설치된 모드의 명령 자동완성에서 확인하세요. 단발 명령은 점과 `area`를 지원하고 선형 배치는 에디터/JSON에서 만듭니다.

## 파일과 참고용 JSON 구조

저장 경로는 `config/dochi_warfare/vehicle_ai/gimmicks/<이름>.json`입니다. 내장 예제는 없는 파일만 설치하며 기존 사용자 파일을 덮어쓰지 않습니다.

현재 문서 스키마는 `dochi.warfare.gimmicks.v6`입니다. 이전 v1~v5도 읽습니다. `origin`은 기준점, `steps`는 단계 목록, `at_tick`은 실행 틱입니다. 단계 하나에는 `bombard`, `vehicle_support`, `fire_support`, `npc_move` 중 한 동작을 넣습니다. JSON을 직접 작성하기보다 에디터에서 저장한 문서를 기준으로 수정하세요.

폭격의 `explosion_damage`와 `direct_damage`는 각각 기본 HP 피해 값입니다. 0은 해당 피해 성분을 0으로 설정하고 빈 입력은 기존 무장 값을 유지합니다. 실제 피해에는 원본 거리 감쇠·방어 규칙이 적용되며 폭발 반경과 지형 파괴를 바꾸지 않습니다.
