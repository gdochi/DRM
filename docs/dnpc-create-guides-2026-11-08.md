# DNPC Create 연계 상세 문서와 영상

> 이 파일은 초기 촬영 15편의 이력이다. 현재 문서에는 설정부터 결과까지 다시 촬영한 12개 강의를 사용한다. 최신 내용과 검증은 [상세 영상 재촬영 기록](dnpc-create-detailed-videos-2026-11-08.md)을 참고한다.

DNPC Create 연계를 네 장으로 나누고 실제 게임 영상 15편, 총 223.83초를 추가했다. 한국어·영어·포르투갈어·스페인어·프랑스어에 새 문서 20개와 기존 편집기·시간표 문서 10곳의 진입 링크를 반영했다.

## 변경 문서

- `151c-npc-core-create-start.md`: 설치·검증 환경, 시간표와 초안 저장, 장치·발 위치 지정, 크랭크·밸브·좌석.
- `151d-npc-core-create-logistics.md`: 실제 사포와 조합법, 주소/UUID 경로, NPC·보관함 배송, 픽업 전 대기와 픽업 후 반송, 주문 창구, Burner 운반 안내.
- `151e-npc-core-create-factory.md`: 네 보관 위치, 재료와 배치 수량, 원본 기계 가공, 예약·타임아웃, 목표 재고 주문과 실제 배송 경로의 구분.
- `151f-npc-core-create-control.md`: 센서 단위, 두 임계값의 상태 유지, 크랭크·밸브·Linked Controller 차이, 순회 점검과 Display Board 예약 줄.
- 각 언어의 `151-npc-core-editor.md`, `151a-npc-core-schedules.md`에서 새 안내로 연결한다. 기존 내비게이션·목차 구조를 그대로 사용한다.

한국어를 가장 자세한 제작 절차로 작성했으며 다른 언어에도 같은 경로·영상·주요 조건과 문제 해결을 제공한다. 촬영 버전은 최소 요구 버전으로 표현하지 않았다. 기존 다른 대상의 검증 자료와 이번 NeoForge 촬영을 구분하고, 26.3에서는 CustomNPCs를 제외한다.

### 촬영 방식과 범위

- 환경은 DNPC 0.1.3 / Create 6.0.10 / NeoForge 1.21.1, 영문 UI다. DRM 0.3.1·GeckoLib·Architectury 등 실제 추가 JAR과 SHA-256은 환경 영수증에 보존한다. 채택한 세 실행의 생산 모드 JAR이 동일함을 확인했다.
- 격리된 예제 월드와 실제 배포 JAR을 사용한다. 문서 촬영 도구가 네이티브 편집 화면의 클릭·문자 입력·스크롤·단축키·블록 선택을 수행한다. 수동 플레이 촬영이나 게임 화면을 모사한 합성 UI로 표현하지 않는다.
- 편집 예제에는 시간대·액션·일부 대상이 미리 준비돼 있다. 장치 선택 영상의 시간표 OFF는 편집 전용 예제임을 명시하고 실제 작업 전 Enable schedule을 안내했다.
- 시간표 실행과 실제 조합법·포장·물류 요청은 DNPC/Create가 처리한다. 동작 중 NPC 위치·기계 결과물을 강제로 만들지 않는다. 반송 예제의 목적지 채우기와 조건 제어 예제의 센서 재고 변경은 문제/반응을 보여 주기 위한 촬영 도구의 입력이며 본문에 밝힌다.
- 소포 배송은 봉인 소포 보관까지다. 주문 예제는 접수와 대기 기록까지이며 수령 통 도착·개봉은 촬영하지 않았다. 창구 영상의 No Packagers Linked는 공급망이 연결되지 않은 별도 메뉴 진입 예제라고 설명했다.
- 움직이는 좌석의 전체 조립·해체·재접속, Linked Controller의 모든 채널 설정, Display Board 출력과 Burner 급유를 이번 영상으로 검증했다고 주장하지 않는다. 해당 기능의 설정은 소스에 근거해 본문에서 설명한다.
- 음악·주크박스 음량 0과 기존 소리 정지를 확인했다. 배포 영상은 무음 MP4·WebM이다.

### 자산과 재현

- 배포 자산: `src/media/guides/create-tutorials-20261108/`, MP4·WebM·PNG 포스터 각 15개.
- 계획과 도구: `scripts/guide-capture/create-tutorials.json`, `GuideCreate.java`, 기존 `GuideCapture.java`의 선택적 호출.
- 채택: 실행 02의 실행 영상 9개, 실행 03의 주소 편집, 실행 04의 장치 편집·창구·가공 편집·가공 실행·자재 주문 5개. 정확한 대응은 `selected-recordings.json`에 있다.
- 원본 타임스탬프와 1280×720 크기를 유지해 20fps / BT.709로 인코딩했다. 보간 프레임은 만들지 않았다. 실행 02의 9개 영상은 안내 자막과 게임 하단 UI가 겹쳐 하단 주석 영역을 다시 그렸다. 이 보정은 게임 작업/수량을 바꾸지 않으며 인코딩 영수증에 기록했다.
- `encode-guide-video.py`는 선택적 자막 영역 보정과 기본 2개 인코딩 스레드를 지원한다. 원본 프레임별 시간·해시, 대표 프레임 12개, 접촉 시트와 양쪽 코덱의 전체 디코딩 결과를 보존한다.
- 샌드박스 로컬 연결 차단으로 실패한 첫 실행은 소유 JVM만 종료했다. 비동기 화면 전환, 실제 Shift 입력과 스크롤 가시 범위, 선택 상태 초기화를 보완한 뒤 실패 범위만 재촬영했다. 실패 실행 전체를 성공 자료로 사용하지 않았다.
- 다른 작업의 게임 실행 중에는 추가 실행을 대기했다. 이후 사용자가 인스턴스 한 개 추가를 직접 지시한 범위에서 최종 3GB 클라이언트 한 개를 추가했고 종료를 확인했다. 다른 게임은 변경·종료하지 않았다.

## 검증

- `npm.cmd run build`: 910개 문서.
- `npm.cmd run verify`: 문서 910개, 기존 이미지 1,667개, 전체 영상 배치 200곳의 경로·환경·자산 검사.
- `npm.cmd run verify:translations`: 번역 546개의 링크·영상·코드·구조 검사.
- `npm.cmd run verify:videos`: 새 영상 15개 × 5개 언어 × 1440px/390px, 150개 화면. 실제 재생·음소거·탐색·일시정지·반복·MP4 대체·바이트 구간 응답·동작 줄이기 확인.
- `node scripts/verify-create-guide-layout.mjs`: 최종 한국어 네 문서의 데스크톱·모바일 8개 배치와 영상 중간 프레임. 가로 페이지 넘침과 브라우저 오류 없음. 본문·캡션·표·영상 화면을 직접 확인했다.
- 최종 촬영 도구 Java 21 컴파일, Python 문법, `git diff --check` 통과. 기존 무검사 리플렉션 컴파일 경고와 Git CRLF 안내는 남는다.
- MP4·WebM 전체 프레임 디코딩, SHA-256, 빌드 후 자산 바이트 일치를 확인했다. 채택 프레임 간격의 중앙값은 약 50ms, 최대는 약 76ms다.
- `preview-server.mjs`는 로컬 미리보기 노출 범위를 **127.0.0.1**로 제한하고 실제 바인딩 주소를 검사한다.

증거는 `docs/evidence/dnpc-create-guides-20261108/`, 백업은 `_backups/dnpc-create-guides-20261108-200614/`다. 최종 해시·영상·설정·서버 결과·로그·대표 화면을 보존한 뒤 이번 작업의 격리 월드 4개, 중간 원본 프레임, 임시 컴파일·FFmpeg 설치본을 정리했다. 결과는 `cleanup.json`에 기록했다.
