## 어떤 도구인가요?

Tooltip Maker는 아이템에 마우스를 올렸을 때 보이는 설명창을 만드는 에디터입니다. 대화창이나 상점창을 꾸미는 GUI Maker와 별도로 엽니다. 이름과 능력치 같은 실제 정보는 마우스를 올린 아이템에서 가져오고, 툴팁 디자인은 그 정보를 어디에 보여줄지 정합니다.

## 처음 만들기

1. **Dochi RPG Maker Core**로 허공을 우클릭합니다.
2. **Visual → Tooltip Maker**를 엽니다.
3. **Load**로 기존 툴팁을 열거나 새 디자인을 만듭니다. 기본 예제를 꾸밀 때는 **Save As**로 복사본을 만드세요.
4. 캔버스의 가로·세로 크기를 정하고 아이템, 글자, 정보 영역, 이미지, 구분선을 배치합니다.
5. 요소를 선택해 Inspector에서 모양을 조정하고 저장합니다.

툴팁 파일은 `config/dochi_rpg_maker/gui`에 저장됩니다. 기본 예제는 `default_tooltip_gui.json`입니다. 다른 GUI와 같은 폴더를 쓰지만, Tooltip Maker의 불러오기 목록에는 툴팁용 파일이 표시됩니다.

## 캔버스와 저장 범위

출력 캔버스는 저장될 툴팁의 영역입니다. 요소를 옮긴다고 캔버스가 저절로 커지지는 않습니다. 더 큰 툴팁이 필요하면 캔버스 크기를 직접 바꾸세요.

배치 중인 요소를 캔버스 바깥에 잠시 둘 수 있습니다. **Save와 Save As에는 캔버스 안에 완전히 들어온 요소만 포함됩니다.** 바깥 요소는 편집 작업 공간에는 남지만 저장되는 툴팁에서는 제외됩니다.

## 아이템 미리보기 조정

| 설정 | 하는 일 |
| --- | --- |
| 아이템 표시 방식 | 정지·회전 아이템, 갑옷 거치대, 플레이어 모델, 모델 표시 안 함 중에서 고릅니다. |
| 모델 표시 | 아이템 표시에서 3D 모델과 2D 인벤토리 아이콘 중 하나를 고릅니다. |
| 아이템 크기 / 모델 배율 | 정해진 아이템 칸 안에서 크기를 조정합니다. |
| 회전 속도 | 회전 속도와 방향을 바꿉니다. |
| X / Y / Z 회전 | 아이템을 바라보는 각도를 조정합니다. |
| 슬롯 배경 | 배경을 켜거나 끕니다. 배경 크기는 아이템 칸을 따라갑니다. |
| 아이템 등장 효과 | 나타나는 효과를 고릅니다. 오른쪽 재생 버튼으로 다시 볼 수 있습니다. |

갑옷 거치대와 플레이어의 착용 모습은 지원하는 장비 칸에 착용할 수 있는 아이템에 적용됩니다. 일반 블록, 재료, 착용할 수 없는 아이템은 아이템 자체가 표시됩니다. 머리에 실제로 착용할 수 있는 블록은 장비처럼 처리됩니다.

3D 미리보기는 모델의 중심과 크기에 맞춰 회전합니다. 그림 주변의 빈 공간 때문에 모드 무기가 너무 작게 보이는 문제도 보완했습니다. TaCZ 총기는 총기 종류와 부착물 정보를 유지해서 표시합니다. 인벤토리 아이콘을 보고 싶다면 2D를 직접 선택하세요.

에디터의 샘플 아이템은 배치를 확인하기 위한 예시입니다. 실제 플레이 중에는 마우스를 올린 아이템의 저장된 정보를 포함해 표시합니다.

## 글자·이미지·등장 효과

이름과 설명, 두 값을 나란히 놓는 영역, 능력치 영역, 구분선으로 정보를 정리할 수 있습니다. 이미지나 잘라낸 텍스처 영역으로 디자인을 꾸밀 수도 있습니다. 글자 크기와 정보 영역의 간격은 아이템 크기와 별도로 조정합니다.

등장 설정으로 배경, 테두리, 글자, 아이템이 나타나는 연출을 조정합니다. 재생 버튼은 누를 때마다 미리보기를 한 번 다시 시작합니다. 무한 반복을 켜는 버튼은 아닙니다.

## 설명이 길 때

실제 툴팁이 화면보다 길면 마우스 휠이나 스크롤바로 아래 내용을 읽을 수 있습니다. 테두리는 그대로 있고 내용만 움직입니다. 화면보다 가로가 긴 툴팁은 화면에 맞춰 축소됩니다.

크리에이티브 인벤토리의 아이템에도 커스텀 툴팁을 사용할 수 있습니다. 크리에이티브 탭 이름이나 일반 버튼 도움말에는 아이템용 디자인이 적용되지 않습니다.
