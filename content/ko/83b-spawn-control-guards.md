0.1.5에서는 자연 스폰 규칙 하나에 여러 종류와 수량을 편성하고, 이미 생성된 구조물마다 등장시킬 수 있습니다. Forge 1.20.1, Fabric·NeoForge 1.21.1과 26.3에 적용됩니다. 일반 몹만 편성하면 DRM이나 NPC 모드가 필요하지 않습니다. 저장한 DNPC는 DRM과 DNPC가 필요하며, CustomNPCs는 26.3에서 사용하지 않습니다.

## 1. 장소 설정 창 열기

기본 **K**로 자연 스폰 편집기를 열어 대상을 고르고 **규칙 추가**로 규칙을 만듭니다. Forge는 **조건 → 배치 조건과 경비대 → 편집**, Fabric·NeoForge는 인스펙터를 아래로 스크롤해 **Locations and guard squad → Edit**를 엽니다.

이 창은 제작자용 설정 도구입니다. **배치 조건 / Locations**와 **편성과 장비 / Squad and equipment** 두 탭에서 초안을 편집합니다. 창의 **Apply** 뒤 메인 화면의 **저장**까지 해야 서버에 적용됩니다. Cancel·Esc는 이 세부 창의 변경을 버립니다.

## 2. 바이옴과 구조물 고르기

배치 조건 탭에서 🔍를 눌러 서버의 바이옴·구조물을 검색합니다. 모드와 데이터팩이 등록한 대상도 포함됩니다.

| 선택 | 사용 예와 의미 |
| --- | --- |
| 포함 바이옴 | `minecraft:plains` 등 선택한 ID/태그 중 하나와 일치 |
| 제외 바이옴 | 포함 목록과 겹쳐도 생성 금지 |
| 포함 구조물 | 예: `minecraft:pillager_outpost`의 실제 생성 지점 |
| 제외 구조물 | 해당 구조물 경계 안에서는 생성 금지 |
| 태그 | `#namespace:tag` 형식으로 등록된 묶음 선택 |

빈 포함 목록은 해당 종류를 제한하지 않으며 제외가 우선합니다. 구조물 선택은 등록된 전체 경계로 판정합니다. 직접 지은 성을 자동 인식하거나 새 구조물을 생성하지 않습니다. 후보 청크와 구조물 시작 정보가 로드되어 있어야 하며 강제로 청크를 로드하지 않습니다.

![배치 조건 탭의 포함·제외 필터와 구조물별 제한.](assets/media/guides/spawn-control-015-fabric263/guard-locations-en.png "Spawn Control 0.1.5 / Fabric 26.3 / DRM 0.3.1. 실제 영어 설정 화면입니다. 이 캡처의 Included structures는 Any이므로 아직 구조물 제한이 적용되지 않습니다.")

## 3. 여러 종류를 한 부대로 편성하기

편성과 장비 탭에서 **Use squad**를 켜고 **Add**로 대상을 추가합니다. 예를 들어 좀비 행의 **Member count**를 2, 스켈레톤 행을 1로 설정하면 합계 3마리의 편성입니다. 저장한 NPC도 기본 EntityType 대신 정확한 복제 템플릿을 고릅니다.

합계는 최대 64개이고 **Member spread**는 1~32블록, 기본 5입니다. 스쿼드를 켜면 기존 최소/최대 무리 수 대신 구성원별 수량을 사용합니다. 한 번의 확률 검사로 전체 편성을 준비하며, 전원의 위치·충돌·조건·개체 상한이 맞아야 함께 추가합니다. 공간이나 상한이 부족하면 일부만 채워 넣지 않고 그 시도를 실패 처리합니다.

이 편성은 자연 스폰 규칙의 기능입니다. 설치형 스포너의 확률형 목록은 그대로 각 소환 대상을 추첨합니다. 순찰·진영·전투 AI는 각 몹이나 NPC 모드에서 설정합니다.

## 4. 구성원 장비 바꾸기

목록에서 구성원을 고른 뒤 오른쪽 머리·가슴·다리·발·양손 슬롯의 🔍로 아이템을 선택합니다. 전체 아이템과 **Player inv**를 사용할 수 있으며 인벤토리 아이템을 소비하지 않습니다.

**Keep**은 원본·템플릿 장비를 유지합니다. 아이템을 고르면 해당 슬롯을 지정한 아이템으로 설정합니다. **Clear**를 켜면 슬롯을 비우고, 끄면 선택해 둔 아이템을 사용하거나 선택이 없을 때 Keep으로 돌아갑니다. 구성원 목록이 비어 있으면 오른쪽은 기본 대상 장비를 편집합니다.

![구성원별 장비 슬롯과 Clear 스위치.](assets/media/guides/spawn-control-015-fabric263/guard-members-en.png "Spawn Control 0.1.5 / Fabric 26.3 / DRM 0.3.1. 구성원 한 명과 머리 슬롯의 Clear를 보여 주는 설정 화면입니다. 전투나 장비 적용 완료를 보여 주는 장면은 아닙니다.")

## 5. 같은 구조물의 중복 부대 막기

**One group per structure instance**는 기본 켜짐이며 포함 구조물이 있어야 작동합니다. 같은 차원·규칙·구조물 종류·시작 청크의 한 지점을 모든 플레이어가 공유합니다. 여러 사람이 접근해도 이 규칙의 부대는 한 개만 배치됩니다. 다른 규칙의 부대는 독립적입니다.

마지막 소유 구성원이 제거된 뒤 **Respawn delay**가 시작되며 기본 1200틱입니다. 일부만 죽었다고 즉시 보충하지 않습니다. 청크 언로드·차원 이동·멀리 유인하는 행동은 점유를 비우지 않습니다. 점유와 대기는 월드 저장 데이터에 남습니다. 포함 구조물이 비어 있으면 이 제한과 대기는 적용되지 않습니다.

## 6. 저장하고 시험하기

Apply로 돌아와 규칙을 켜고 저장합니다. 처음에는 스폰 확률 1, 간격 200틱 정도로 확인하고 부대 전체가 들어갈 개체 상한과 공간을 확보합니다. 차원·시간·조도·플레이어 거리도 계속 적용됩니다. 기본 최소 거리 24블록 때문에 플레이어 발밑의 현재 위치 검사는 거리 조건에 실패할 수 있습니다.

**Advanced Diagnostics**로 실패 이유를 확인하세요. 시험 생성은 확인 후 실제 개체를 만들며 스쿼드가 켜져 있으면 전체 부대를 생성합니다. Forge에서는 **Spawn Squad**로 표시됩니다. 운영 값으로 바꾸기 전에 구조물 경계, 로드 상태, 전원 배치 공간과 상한을 점검하세요. [조건과 개체 수 제한](#dochi-spawn-control/dochi-spawn-control-rules)에서 기본 필드를 확인할 수 있습니다.

## 7. 다른 서버로 옮기기

자연 스폰 문서 스키마는 4이며 기존 스키마 2·3도 읽습니다. 새 프리셋을 구버전 Spawn Control에서 다시 저장하지 마세요. 대상·아이템을 제공하는 모드와 원본 DNPC 템플릿을 함께 준비합니다. 1.20.1 아이템 NBT와 이후 컴포넌트 데이터는 자동 상호 변환하지 않습니다.

JSON과 월드를 함께 백업해야 구조물별 점유와 재생성 대기도 복구할 수 있습니다. 파일 위치와 프리셋 범위는 [공유와 운영](#dochi-spawn-control/dochi-spawn-control-presets-operations)을 참고하세요.
