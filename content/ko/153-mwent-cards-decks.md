## 카드 얻기와 보관

서버가 배포하는 실물 카드와 카드팩을 모읍니다. 상인·상자 획득은 서버 설정에 따라 달라지며 [획득 설정](#mwent/acquisition)에서 운영 방법을 확인할 수 있습니다. 카드를 받는 것과 보관소에 넣는 것은 별도입니다.

빈 마우스 커서로 인벤토리나 상자의 카드 묶음을 우클릭하면 그 수량을 카드 보관소에 넣습니다. 기본 키 **V**로 보관소를 열며 키 설정에서 바꿀 수 있습니다. 보관소에서 카드를 인출해 다시 실물 아이템으로 받을 수 있습니다.

덱 편성은 보관소와 플레이어 인벤토리의 소지 수량을 합산합니다. 상자나 다른 플레이어의 카드는 내 소지 카드에 포함하지 않습니다. 카드를 덱에 넣거나 경기에서 사용했다고 소모하지 않습니다. 준비·경기 중 예약된 카드는 보관소에서 인출할 수 없습니다.

## 일반판과 애니메이티드판

같은 카드에는 일반판과 애니메이티드판이 있습니다. 판본별 실물 아이템과 소유 수량은 구분하지만 덱에서는 같은 카드의 복사 제한을 공유합니다. 움직이는 판본이 전투 수치를 올려 주지는 않습니다.

**희귀도**는 일반·희귀·영웅·전설 네 종류입니다. **브론즈 / 골드 프레임**은 덱의 같은 카드 복사 제한을 결정합니다. 전설이라는 이유만으로 복사 제한을 판단하지 말고 프레임을 확인하세요.

## 내 덱 만들기

![대전 준비의 덱 목록. 왼쪽에 내장 덱과 필터, 오른쪽에 선택한 Companion Chorus의 카드와 장수·편성 비용이 보입니다.](assets/media/guides/minigames-015-neo1211/minigames-mwent-play.png "Minigames 0.1.5 / NeoForge 1.21.1의 시험 플레이입니다. Use this deck은 선택한 덱을 준비 화면으로 가져갑니다. My decks에서 자신의 저장 덱을 찾습니다.")

1. 보관소·카드 백과사전 또는 대전 준비 화면에서 **내 덱 → 새 덱**을 엽니다.
2. 진영을 고르고 리더 능력과 편성 한도를 확인합니다.
3. 같은 진영 또는 중립 카드를 추가하고 이름을 정해 저장합니다.
4. 대전 준비에서 저장 덱을 선택합니다. 부족한 소지 수량이나 미완성 조건이 있으면 먼저 수정합니다.

0.1.6의 대전 준비에서는 [선공 전술 다섯 가지](#mwent/version-0-1-6) 중 하나도 고릅니다. 덱의 손패 카드와 별도이며, 코인 토스에서 선공이 된 쪽에 배치됩니다.

| 조건 | 완성된 덱 |
| --- | --- |
| 장수 | 25~40장 |
| 유닛 | 최소 13장 |
| 편성 비용 | 기본 150 + 선택한 리더의 보너스 이하 |
| 같은 골드 카드 | 최대 1장 |
| 같은 브론즈 카드 | 최대 2장 |
| 소유 수량 | 보관소·인벤토리 합산 수량 이하 |
| 진영 | 선택한 진영 + 중립 |

최대 16개의 덱을 저장합니다. 미완성 덱도 초안으로 보관할 수 있지만 바로 대전할 수 있다는 뜻은 아닙니다. 진영을 바꾸면 편성을 비우고 리더를 다시 고릅니다. 리더만 바꾸면 카드는 남고 새 한도에 맞는지 다시 확인합니다.

## 백과사전과 카드 상세

백과사전은 카드를 주거나 소모하지 않는 열람 화면입니다. 카드를 선택하면 이름·진영·희귀도·전력·편성 비용과 능력을 확인합니다. 전투에서는 우클릭으로 카드 상세를 엽니다. 표시된 숫자가 기본값인지 강화·피해가 반영된 현재 값인지 구분하세요.

미보유 카드도 설명을 읽을 수 있습니다. 선택 모드 카드가 목록에 있다고 해당 모드 없이 쓸 수 있는 것은 아닙니다. 현재 카탈로그는 기본 정의 335종과 선택 모드 정의 89종이며, 실제 사용 가능 여부는 설치된 모드와 모델·아이템에 따라 달라집니다. 사용자 제작 카드 자리 수는 이 숫자에 포함하지 않습니다.

카드별 전력·비용·능력은 [스펙 목록](#mwent/card-catalog), 버전별 추가와 변경 여부는 [버전 이력](#mwent/releases)을 확인하세요.

## DNPC 카드 모델이 안 보이면

0.1.5부터 DNPC Gecko 모델 설정을 읽고 로딩 중 만들어진 임시 미리보기를 다시 생성합니다. 해당 DNPC 모델·에셋·선택 렌더 라이브러리가 준비되어야 하며, 카드 목록에 있다는 것만으로 연동 모드가 설치되지는 않습니다.
