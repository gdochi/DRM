## 게임별 규칙

| 게임 | 플레이 순서 | 제작할 때 확인할 것 |
| --- | --- | --- |
| 몬티홀 | 문 선택 → 꽝 문 공개 → 유지 또는 변경 | 문은 3–8개. 심볼과 승리 보상을 준비합니다. |
| 슬롯 | 참가 확인 → 레버 → 세 릴 정지 | 자동·수동 정지, 심볼 목록, 회전·정지 시간을 정합니다. |
| 기억력 | 처음 카드 공개 → 카드 두 장씩 선택 → 모든 짝 맞추기 | 2–10행·열, 전체 카드 수는 짝수. 각 짝에 서로 다른 심볼이 필요합니다. |

제한 시간은 5–3600초입니다. 기억력의 쉬움·보통·어려움 프리셋은 2×2·6×6·10×10입니다. 10×10에는 서로 다른 심볼 50개가 필요합니다. 심볼 ID 옆 **찾기**에서 DRM 아이템 검색 목록을 사용하세요.

슬롯 자동 정지 시각은 첫 번째 < 두 번째 < 세 번째 순서이며 마지막 정지는 제한 시간 안에 들어가야 합니다. 틱 설정의 20틱은 정상 속도에서 1초입니다.

## 참가비

일반 탭에서 종류·ID·금액을 지정합니다.

| 종류 | ID에 넣을 것 |
| --- | --- |
| `item` | 참가비로 차감할 아이템 ID |
| `drm` | DRM Currency Editor에 등록한 화폐 ID |
| `cobbledollars` | 설치한 CobbleDollars 제공자를 사용하는 설정 |

금액 `0`은 무료입니다. NPC 클릭이나 다시하기만으로 차감하지 않으며 참가 확인에서 시작을 눌러야 결제합니다. 취소는 무료이고 잔액 부족이면 시작하지 않습니다. 참가 확인은 60초 후 만료됩니다. 이미 결제하고 시작한 게임을 닫으면 포기로 처리합니다.

## 점수 단계와 지급 정책

보상마다 필요한 점수와 수량을 정합니다. 만족한 보상 중 무엇을 지급할지는 정책이 결정합니다.

| 정책 | 결과 |
| --- | --- |
| `highest` | 달성한 최고 점수 단계에 속한 보상 전부 |
| `cumulative` | 달성한 모든 단계의 보상 전부 |
| `random` | 달성한 보상 항목 중 무작위 하나 |

아이템 보상은 지정 아이템, 심볼 보상은 슬롯 결과 등 게임에서 선택된 심볼을 사용합니다. 포켓몬 보상은 Cobblemon 설치 후 **포켓몬 설정**에서 종·레벨·이로치·성별·폼·성격·특성·볼·지닌 아이템·추가 속성을 정합니다. 레벨은 1–100이며 파티가 가득 차면 PC로 지급합니다.

게임이 참조하는 아이템·심볼과 포켓몬 보상은 결제 전에 검사합니다. 서버가 점수·정답·결제·지급을 처리하므로 클라이언트가 점수를 제출해 보상을 받는 방식은 아닙니다. 동일 세션의 정산은 한 번만 수행합니다. 아이템 인벤토리가 가득 차면 남은 아이템을 떨어뜨리며, 지급 오류는 알림과 서버 로그를 확인하세요. 자동 재지급은 하지 않습니다.

새 설정을 저장한 뒤 무료 시험 플레이와 실제 참가 확인을 각각 점검하세요. [NPC와 대화 연결](#dochi-minigames/minigames-setup)은 시작 페이지에 있습니다.

## 추가 게임

| 게임 | 플레이와 제작 |
| --- | --- |
| 두더지 | 올라오는 대상과 함정을 구분합니다. 대상·함정 모델, 출현 주기와 노출 시간을 설정합니다. |
| 타이밍 | 성공 구간 안에서 멈춥니다. 라운드 수·속도·구간 축소를 정합니다. |
| 하이로우 | 다음 카드의 높고 낮음을 예측하고 연속 성공 점수를 확정합니다. 같은 카드는 재도전, 오답·시간 초과는 누적 점수 소실입니다. |
| 사격장 | 크기가 다른 표적과 폭발 함정을 겨냥합니다. 총기 모델·탄약·재장전·발사 간격과 점수를 정합니다. |
| MWENT | 카드·진영·리더·덱과 라운드 전략을 사용합니다. [MWENT 안내](#mwent/start)를 확인하세요. |

DRM이 없으면 무료 또는 아이템 참가비·아이템 보상을 사용합니다. DRM 화폐·조건이나 다른 모드의 보상을 선택했다면 해당 제공 모드가 필요합니다.
