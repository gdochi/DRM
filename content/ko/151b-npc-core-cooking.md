## 조리 작업 만들기

기존 Forge 1.20.1·Fabric/NeoForge 1.21.1의 조리 작업입니다. 아래 추가 장치·애드온의 실제 실행 확인은 **NeoForge 1.21.1** 기준이며 26.3 조리 지원으로 확대하지 않습니다.

1. 데이사이클의 채취·생산에서 조리 작업을 선택합니다.
2. 서버 조리법 목록에서 현재 설치된 장치와 실제 레시피를 고릅니다.
3. 재료 공급 보관함, 작업 장치와 완성품 보관함을 지정합니다.
4. 필요한 도구·재료·연료를 넣고 NPC가 장치까지 갈 수 있는 경로를 확보합니다.
5. 반복 여부를 정하고 저장한 뒤 실제 재료 소비와 완성품 납품을 확인합니다.

도구는 재료와 별도로 표시합니다. 기본 반복은 켜짐이며, 끄면 현재 한 배치를 회수·납품한 뒤 완료 상태로 기다립니다. 화면에서 레시피를 선택한 것만으로 결과 아이템을 만들지 않습니다.

## 장치별 범위

| 장치 | 처리 |
| --- | --- |
| Farmer's Delight 도마 | 실제 도구 조건·손질 재료·결과·부산물 사용 |
| 바닐라 화로·훈연기 | 실제 레시피의 재료·연료를 넣고 원본 블록이 가열 |
| Farmer's Pizzeria | 반죽 밀기·토핑·생피자 회수 후 실제 조리 연결 |
| French Delight 치즈틀 | 재료 투입·1,200틱 숙성·회수, 빈 양동이 반환 |
| 바스켓·캐비닛 | 재료·중간재·완성품 운반, 지원 캐비닛 개폐 연출 |

실행 확인에는 Farmer's Pizzeria 1.3.0과 설치된 French Delight·관련 조리 애드온을 사용했습니다. 이 버전은 새 최소 요구 버전이 아닙니다. DNPC는 해당 모드를 필수로 요구하지 않으며, 없는 장치나 레시피가 자동 생성되지는 않습니다.

## 중단·저장과 확인

조리 예약과 아직 회수하지 않은 결과는 저장합니다. 잠깐의 상호작용이나 접근 시간만으로 정상 장치 내용을 실패 처리하지 않으며, 주변에 원래 떨어져 있던 음식은 가져가지 않습니다. 작업 중 외부에서 장치·재료·결과를 바꾸면 다시 조건을 확인합니다.

0.1.2 수정본은 조리 재료·연료 유실, 치즈의 빈 양동이 반환과 피자 작업 초기화 문제를 보완합니다. 벌목·채굴의 대상 선택과 복귀도 개선했습니다. 애드온이 없는 NeoForge에서는 기본 훈연기·배럴로 한 배치 생산을 확인했으며, 다른 로더의 모든 조리 애드온 조합을 실제 시험한 것은 아닙니다.

군용·탑승·상점 시간표는 [시간표 안내](#dochi-npc-core/npc-core-schedules), 저장과 복제의 구분은 [v3 템플릿](#dochi-npc-core/npc-core-templates)을 확인하세요.
