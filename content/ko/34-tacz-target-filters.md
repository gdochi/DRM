## 타겟 규칙을 조심해야 하는 이유

총기 NPC는 대부분의 근접 NPC보다 먼 거리에서 공격할 수 있습니다. 그래서 잘못된 타겟 규칙은 바로 눈에 띕니다. 타겟 규칙은 작게 쌓으세요. 먼저 NPC가 발사하는지 확인하고, 그 다음 엔티티 ID, 태그, 고급 팩션 또는 스탠스 동작을 추가합니다.

## 엔티티 ID 타겟 목록

`Targets` 탭에서는 허용할 타겟 엔티티 ID를 선택할 수 있습니다. 목록에는 검색, 체크된 항목만 보기, 체크되지 않은 항목만 보기, 엔티티 타입 필터, 모드 ID 필터가 있습니다. 특정 몹 그룹만 공격하거나 특정 모드의 엔티티만 공격하게 만들 때 가장 명확한 방식입니다.

| 컨트롤 | 용도 |
| --- | --- |
| Search | `minecraft:zombie` 같은 레지스트리 ID를 검색합니다. |
| View filter | 전체, 체크됨, 체크 안 됨 항목을 나눠 봅니다. |
| Type filter | 넓은 living entity 그룹을 좁힙니다. |
| Mod filter | 선택한 모드 ID의 엔티티만 표시합니다. |
| Select all / none | 현재 필터로 보이는 목록에 일괄 적용합니다. |

타겟 엔티티 목록이 비어 있으면 엄격한 허용 목록이 아니라 일반 동작으로 돌아갑니다.

## 스코어보드 태그 규칙

태그 규칙은 엔티티 스코어보드 태그를 사용합니다.

| 필드 | 동작 |
| --- | --- |
| Required tags | 설정되어 있으면 타겟은 요구 태그 중 하나 이상을 가져야 합니다. |
| Rejected tags | 설정되어 있으면 거부 태그 중 하나라도 가진 타겟은 제외됩니다. |
| Attack same faction by tag | 요구 태그가 맞으면 같은 팩션 CustomNPCs도 공격할 수 있게 합니다. |

태그는 스크립트 이벤트에 특히 유용합니다. 예를 들어 던전 스크립트가 경보 페이즈 동안 플레이어나 NPC에게 `intruder` 태그를 붙이고, 전투가 끝나면 제거할 수 있습니다.

## 팩션과 Advanced 스탠스

Advanced 스탠스 규칙은 타겟 팩션, 타겟 태그, 타겟 엔티티 ID를 조건으로 사용할 수 있습니다. 먼저 `Targets`에서 ID와 태그를 등록한 뒤 `Stance Mode: Advanced`에서 사용하세요.

Advanced 모드는 활성 조건을 하나만 지원합니다. 결과를 예측 가능하게 유지하기 위한 구조입니다. 조건이 맞지 않을 때 일반 `General` 설정으로 돌아가야 한다면 `Default` 동작을 사용하세요.

## 프로필 가져오기와 내보내기

타겟 엔티티 프로필은 아래 위치에 저장됩니다.

```text
config/cnpc_tacz_fire/target_entities/
```

여러 NPC가 같은 타겟 프로필을 공유해야 한다면 `Import`와 `Export`를 사용하세요. 팩션 전투, 보스 페이즈, 맵팩에서는 이름 붙인 작은 프로필 세트를 유지하는 편이 NPC마다 수동 수정하는 것보다 점검하기 쉽습니다.

## 실전 예시

| 상황 | 권장 규칙 |
| --- | --- |
| 좀비 경비 | 엔티티 목록에서 좀비 계열 엔티티 ID를 선택합니다. |
| PvE 보초 | `hostile_to_guard` 같은 스코어보드 태그를 요구합니다. |
| 이벤트 페이즈 | `phase2_target` 요구 태그를 쓰고 페이즈 종료 시 제거합니다. |
| 같은 팩션 결투 | 이벤트 참여자에게만 요구 태그를 붙이고 같은 팩션 태그 공격을 켭니다. |
| 보스의 소환몹 처리 총기 | 소환몹 엔티티 ID만 허용하고 플레이어는 목록에서 제외합니다. |

## 타겟 규칙 디버깅

NPC가 발사하지 않으면 필터를 잠시 제거하고 기본 hostile 타겟으로 테스트하세요. 그 뒤 규칙을 하나씩 다시 추가합니다. 대부분의 타겟 문제는 엔티티 허용 목록, 요구 태그, 거부 태그, 같은 팩션 규칙을 기본 테스트 전에 한꺼번에 섞어서 생깁니다.
