## 뭰트는 어떤 게임인가요?

**MWENT / 뭰트**는 Minecraft의 생물과 병력을 카드로 편성해 대결하는 전략 카드 게임입니다. 앞·뒤 열의 고정 칸에 카드를 배치하고 인접한 아군, 명령, 리더 능력과 남은 손패를 활용해 먼저 두 라운드를 이깁니다. 온라인 **GWENT: The Witcher Card Game**의 진영별 전략에서 영감을 받았으며, 고정 소켓과 Minecraft 전장을 사용하는 독자적인 카드와 규칙으로 플레이합니다.

뭰트는 **Dochi`s Minigames에 포함된 게임**입니다. 이 문서는 플레이와 카드 정보를 따로 찾기 위한 전용 문서이며, 별도 MWENT 모드를 설치하지 않습니다. 공개 버전에는 **0.1.1에서 처음 포함**되었습니다. [미니게임스 설치 안내](#dochi-minigames/minigames-setup)에서 대상 Minecraft와 로더에 맞는 파일을 선택하세요.

## 설치와 문서 기준

서버와 클라이언트 모두 같은 대상의 Minigames 빌드를 사용합니다. 기본 카드 대전·테이블·학습에는 DRM이 필요하지 않습니다. Fabric API 등 플랫폼의 필수 파일은 별도로 설치합니다. DRM은 NPC·대화·통화 연동을 추가하고, 선택 모드 카드는 해당 모드와 실제 자산을 사용할 수 있을 때 활성화됩니다. Minecraft 26.3은 Java 25를 사용하며 CustomNPCs를 지원하지 않습니다.

게임 방법은 **현재 0.1.5 워크스페이스**를 기준으로 설명합니다. 과거 버전은 [업로드 버전 이력](#mwent/releases)에서 확인하세요. 0.1.1~0.1.4는 CurseForge 실제 업로드 파일을 기준으로 비교합니다.

## 처음이라면 배우면서 하기

1. 뭰트 테이블을 우클릭해 **AI 대전 → 배우면서 하기**를 선택합니다. MWENT 시작 화면의 배우면서 하기도 사용할 수 있습니다.
2. 전장·손패·점수·라운드 표시를 확인하고, 카드를 우클릭해 능력을 읽습니다.
3. 실제 카드 배치, 턴 종료, 명령과 리더 능력, 인접 연계와 패스를 차례로 실습합니다.
4. 라운드 전환과 손패 교체까지 연습한 뒤 전체 경기를 진행합니다.

학습에는 소지 카드·참가비·보상·제한 시간이 없습니다. 수업은 자유롭게 선택할 수 있습니다. **이어 배우기**는 첫 미완료 수업을 열며 중단한 수업은 처음 상태에서 재시작합니다. 설명의 이전·다음은 실제 카드와 점수를 되돌리지 않습니다.

## AI 연습과 플레이어 대전

| 플레이 | 시작 방법 |
| --- | --- |
| AI 연습 | 테이블에서 내장 상대를 고르고 자신의 덱을 준비합니다. 현재 내장 상대는 진영마다 2명씩 총 12명입니다. |
| 플레이어 대전 | 두 사람이 같은 테이블에 앉아 덱을 정한 뒤 모두 준비 완료를 누릅니다. 보유 카드로 편성한 덱을 서버가 확인합니다. |
| 관전 | 자리가 찼거나 경기 중인 테이블에 들어가 공개 전장과 점수를 봅니다. 상대 손패와 비공개 덱 순서는 공개하지 않습니다. |

**뭰트 테이블**은 책 2개·초록색 양털 1개·판자 5개로 만듭니다. 제작대 첫 줄은 책 / 초록 양털 / 책, 둘째 줄은 판자 3개, 셋째 줄은 판자 / 빈칸 / 판자입니다. 테이블과 대전에 사용한 카드는 경기 시작만으로 소모되지 않습니다.
