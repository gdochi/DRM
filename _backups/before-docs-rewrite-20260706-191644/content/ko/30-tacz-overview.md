## CNPC TaCZ Fire란

CNPC TaCZ Fire는 **CustomNPCs가 TaCZ 총기를 플레이어처럼 사용**하도록 돕는 애드온 문서 트랙입니다. 사격, 재장전, 자세 전환, 표적 필터링 같은 항목을 중점적으로 다룹니다.

## 핵심 범위

| 기능 | 설명 |
| --- | --- |
| 사격 | 지정한 총기와 탄약으로 NPC가 발사합니다. |
| 재장전 | 탄약 소진 시 재장전 로직을 처리합니다. |
| 타겟 필터 | 태그, 팩션, 엔티티 기준으로 공격 대상을 고릅니다. |
| 자세 전환 | Auto, Ranged, 근접 전환 같은 전투 자세를 설정합니다. |

## 누가 읽으면 좋은가

- 총기 NPC를 활용한 전투 서버 제작자
- 약탈자, 경비병, 보스형 사격 NPC를 만들고 싶은 사람
- TaCZ와 Better Combat, 팩션 규칙을 함께 쓰는 운영자
