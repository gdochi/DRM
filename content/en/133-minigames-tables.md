## Get a table

Eight game-specific tables can be crafted. Check their recipes in the in-game recipe book. Each keeps its own game type.

The Creative **Minigame Table** lets creators switch game types and has no crafting recipe.

## Choose its game

1. Place the table.
2. Edit with permission level 2 or above. **Empty-hand Shift+right-click** edits a configured table.
3. Choose a built-in preset or saved game.
4. Press **Apply to table**.
5. Right-click normally to open the entry screen.

Edit and save the rules in `/minigame editor`. Several tables can share one saved game. A game-specific table cannot run a different game type.

## MWENT matches and spectating

MWENT tables offer player matches, AI matches and spectating. Administrators select the AI-match settings from the table menu; each table has its own selection.

Player matches are free. Paid game profiles are for AI matches. Let participants leave before changing a busy table's settings.
