## What is MWENT?

**MWENT** is a tactical card game using Minecraft creatures and armies. Deploy cards in fixed front/back-row sockets, combine neighbors, Orders and leader abilities, and manage your remaining hand to win two rounds. Its faction strategies draw inspiration from the standalone online **GWENT: The Witcher Card Game**, with original cards and interactions built around Minecraft battlefields and fixed sockets.

MWENT is **included in Dochi`s Minigames**. This dedicated documentation does not represent a separate mod download. Its first public Minigames release was **0.1.1**. Choose the correct Minecraft and loader file using the [Minigames setup guide](#dochi-minigames/minigames-setup).

## Installation and documentation baseline

Install matching Minigames builds on the server and client. Basic battles, tables and lessons work without DRM. Install platform requirements such as Fabric API separately. DRM adds NPC, dialogue and currency integrations. Optional-mod cards require their provider and actual assets. Minecraft 26.3 uses Java 25 and excludes CustomNPCs.

Gameplay guides describe the **current 0.1.5 workspace**. The [release history](#mwent/releases) compares actual CurseForge uploads for 0.1.1–0.1.4; it keeps those historical releases separate from the workspace baseline.

## Learn by Playing

1. Right-click an MWENT table and select **AI Battle → Learn by Playing**, or use Learn by Playing on the MWENT start screen.
2. Identify the battlefield, hand, score and round markers. Right-click a card to inspect it.
3. Practice placement, ending turns, Orders, leaders, adjacency and passing through real actions.
4. Practice a round transition and mulligan, then play a complete match.

Lessons require no owned cards and have no entry fees, rewards or time limit. Select lessons freely. Continue Learning opens the first unfinished lesson; interrupted lessons restart their practice state. Previous / Next revisits explanations without rewinding cards or scores.

## AI practice and player matches

| Mode | Start |
| --- | --- |
| AI practice | Select a built-in opponent at a table and prepare your deck. The current list has two opponents per faction, twelve total. |
| Player match | Two players join the same table, choose decks and both press Ready. The server checks owned-card decks. |
| Spectating | Join a full table or a running match to see the public field and score. Hidden hands and deck order are not revealed. |

Craft an **MWENT table** from two books, one green wool and five planks: book / green wool / book; three planks; plank / empty / plank. Starting a match does not consume the table or cards used in the deck.
