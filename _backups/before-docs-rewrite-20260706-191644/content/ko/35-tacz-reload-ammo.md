## 재장전 설계 기준

재장전은 단순히 탄약을 다시 채우는 동작이 아니라, NPC 전투 리듬을 조절하는 요소입니다. 너무 빠르면 플레이어가 압박을 피할 시간이 없고, 너무 느리면 총기 NPC가 무력해집니다.

| 항목 | 설명 |
| --- | --- |
| Ammo Source | 탄약을 어디서 가져오는지 |
| Magazine | 탄창 모드를 쓰는지 |
| Reload Time | 재장전 중 무방비 시간 |
| Fallback | 탄약이 없을 때 근접 전투로 전환할지 |

## 점검 순서

1. 무한 탄약 상태에서 사격 로직만 먼저 확인합니다.
2. 탄약 소모를 켠 뒤 발사 횟수를 확인합니다.
3. 재장전 애니메이션 또는 대기 시간이 적용되는지 확인합니다.
4. 탄창 모드 사용 시 탄창 아이템과 탄약 아이템을 분리해서 봅니다.
5. 탄약이 없을 때 대기, 도주, 근접 전환 중 어떤 상태로 갈지 정합니다.

## 흔한 문제

- 탄약 아이템을 들고 있는 것처럼 보임
- 재장전 후 사격 상태로 돌아오지 않음
- 탄창 모드와 기본 탄약 로직이 충돌함
- 클라이언트에서는 장전됐지만 서버 판정은 비어 있음
