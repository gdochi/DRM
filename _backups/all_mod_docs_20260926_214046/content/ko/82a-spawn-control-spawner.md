## JSON을 만들고 설치된 스포너에 적용하기

`Spawner Editor`는 제작자용 JSON 에디터입니다. 스포너가 설치되어 있지 않아도 문서를 만들고 편집할 수 있습니다. 편집과 적용에는 크리에이티브 모드 또는 권한 레벨 2가 필요합니다.

1. DRM Core를 들고 허공을 우클릭해 에디터 선택기를 엽니다.
2. `Spawner Editor`를 선택해 새 문서를 만들거나 기존 JSON을 불러옵니다.
3. `Spawn Target`에서 이름과 소환 목록을 정합니다.
4. `Conditions`와 `Spawn Settings`에서 작동 조건, 1회 소환 수, 생성 제한과 배치 범위를 설정합니다.
5. 필요하면 파괴 방식, 효과, 외형을 바꿉니다.
6. `Save As`로 이름을 지정해 저장합니다. 이후 같은 문서의 수정은 `Save`로 저장합니다.
7. `Get Spawner`로 빈 스포너 아이템을 받아 원하는 위치에 설치합니다.
8. DRM Core로 설치된 스포너를 우클릭합니다. `Apply Spawner JSON` 목록에서 저장한 파일을 고르고 `Apply JSON`을 누릅니다.

**JSON 저장과 월드 적용은 별개입니다.** 새로 받은 스포너는 JSON을 적용하기 전에는 작동하지 않습니다. 문서를 수정한 뒤에도 적용할 스포너를 우클릭해 파일을 다시 적용해야 합니다.

파일은 서버의 `config/dochi_rpg_maker/spawn_control/spawners/`에 저장됩니다. 싱글플레이에서는 인스턴스의 게임 폴더가 기준이며 월드마다 따로 문서를 만들지 않습니다. 자세한 경로와 백업은 [공유와 운영](#dochi-spawn-control/dochi-spawn-control-presets-operations)을 참고하세요.

## 화면 구성

왼쪽 패널에서 카테고리를 선택하고 오른쪽에서 값을 편집합니다. JSON 파일 경로는 현재 문서를 알려 주는 라벨입니다. 경로를 바꾸려면 `Save As`를 사용하세요.

| 카테고리 | 설정할 내용 |
| --- | --- |
| `Spawn Target` | 이름, 활성 상태, 엔티티·클론 목록과 각 항목의 확률 |
| `Conditions` | 작동 계기, 간격, 플레이어, 시간·날씨·레드스톤, 공통 조건 |
| `Spawn Settings` | 1회 소환 수, 누적·보유 제한, 위치·지형·조도 |
| `Destruction` | 채집 또는 체력 파괴, 체력, 히트박스와 아이템 드롭 |
| `Effects` | 피격 파티클, 피격·파괴 사운드, 스포너 보스바 |
| `Appearance` | 외형 모델과 크기·회전·위치 조정, 미리보기 |

타입과 모드는 버튼을 눌러 플라이아웃 목록에서 고릅니다. 같은 버튼을 여러 번 눌러 값을 순환시키는 방식이 아닙니다. 긴 목록은 검색하고 마우스 휠이나 스크롤바로 이동합니다. 취소하거나 Esc를 누르면 기존 선택을 유지합니다. `On/Off`는 켜고 끄는 토글입니다.

## 소환 목록과 확률

목록에 항목을 추가하고, 편집할 행을 선택해 대상과 확률을 지정합니다. 사용하지 않는 항목은 삭제하거나 확률을 `0`으로 둡니다. 목록은 최대 64개이며 양수 확률의 항목이 적어도 하나 필요합니다.

| 소스 | 선택할 대상 |
| --- | --- |
| `Entity` | 현재 서버에 등록된 엔티티 ID |
| `CNPC Clone` | CustomNPCs 서버 클론의 탭과 이름 |
| `DW Clone` | Dochi’s Warfare의 저장된 클론 템플릿 |

필요한 모드와 클론이 설치된 서버에서 사용할 수 있습니다. 일반 엔티티만 사용할 때 두 클론 모드가 필수 의존성이 되지는 않습니다.

확률 값은 목록 안에서 비교하는 비율입니다. 값이 높을수록 이번 소환 대상으로 뽑힐 가능성이 높습니다. 항상 가장 높은 항목만 뽑는 것은 아닙니다. 화면에서 합계를 기준으로 계산한 실제 선택 확률을 확인할 수 있습니다.

| 입력 예 | 선택 확률 |
| --- | --- |
| 돼지 70, 소 30 | 돼지 70%, 소 30% |
| 돼지 1, 소 1 | 각각 50% |
| 돼지 10, 소 0 | 돼지만 선택 |

`Entities per attempt`를 `3`으로 두면 한 번의 작동에서 최대 3마리를 시도합니다. 각 마리마다 목록에서 다시 뽑으므로 같은 대상이 연속해서 나올 수 있습니다. 70:30 목록에서 3마리를 뽑는다고 항상 돼지 2마리와 소 1마리가 나오지는 않습니다. 공간 부족이나 생성 제한 때문에 실제 생성 수는 더 적을 수 있습니다.

`Maximum owned entities`는 그 스포너가 만든 개체의 총 보유 제한이고, `Total spawn limit`는 누적 생성 제한입니다. 둘 다 목록 전체에 적용되며 항목별 제한이 아닙니다. 누적 제한 `0`은 무제한입니다.

## 스포너 외형과 미리보기

`Appearance`의 `Model source`는 **Item, Entity, Block** 중 하나입니다. 소환 목록의 대상과 스포너 외형은 독립적입니다. 예를 들어 소환 목록은 좀비로 두고 스포너 외형은 블록으로 표시할 수 있습니다.

`Choose`로 모델 ID를 선택하고 크기, 회전, 수직 위치를 조정합니다. 블록 상태는 `Block properties (JSON)`, 모델 데이터는 `Model NBT (SNBT)`에서 설정합니다. CNPC·DW 클론은 소환 소스이며 별도의 외형 모델 타입이 아닙니다.

미리보기는 에디터 안에서 외형을 확인하는 기능입니다. 월드에 엔티티를 소환하지 않습니다. 모델 변경 응답을 기다리는 동안 마지막으로 성공한 미리보기를 유지하고 최신 요청의 결과로 갱신합니다.

다음으로 [스포너 조건·파괴·효과](#dochi-spawn-control/dochi-spawn-control-spawner-settings)를 설정하세요.
