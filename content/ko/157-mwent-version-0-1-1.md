## 공개 기준

뭰트는 Minigames **0.1.1에 처음 공개**되었습니다. 2026-10-23 CurseForge에 [Fabric 1.21.1](https://www.curseforge.com/minecraft/mc-mods/dochi-s-minigames/files/9299087), [NeoForge 1.21.1](https://www.curseforge.com/minecraft/mc-mods/dochi-s-minigames/files/9299082), [Forge 1.20.1](https://www.curseforge.com/minecraft/mc-mods/dochi-s-minigames/files/9299089)이 업로드되었습니다. 이 버전의 업로드 목록에 26.3 파일은 없습니다.

## 첫 카드 구성

Fabric 1.21.1 업로드 파일에서 읽은 기본 카탈로그는 **263종**, 선택 모드 카드는 **89종**, 합계 **352종**입니다. 일반판·애니메이티드판을 따로 세면 704개 판본입니다. 이후 워크스페이스에서 추가한 0.1.5 카드 72종은 여기에 포함하지 않습니다.

| 선택 모드 묶음 | 카드 정의 |
| --- | --- |
| Cobblemon | 14종 |
| L_Ender's Cataclysm | 16종 |
| Mowzie's Mobs | 16종 |
| Iron's Spells 'n Spellbooks | 43종 |

선택 모드 묶음을 사용할 때만 해당 제공자가 필요합니다. 기본 카탈로그에도 모델 라이브러리 등 실제 자산이 필요한 정의가 있어, 카탈로그 수 전체를 바닐라만으로 사용 가능한 카드 수로 해석하지 않습니다.

## 공개 시점의 플레이 구성

볼카르·아발린·네브라·해무·로덴·모르가의 여섯 진영, 중립 카드, 진영별 리더와 덱을 제공합니다. 카드 배치·명령·패스·라운드 대전, 카드 보관과 판본 구분, 덱 편성·백과사전, 카드팩과 테이블 대전을 포함합니다. 이 페이지는 공개 시점의 기준선이며, 최신 운영 UI와 추가 카드 제작 기능은 [현재 안내](#mwent/start)를 따릅니다.

## 다음 버전과 비교

[0.1.2](#mwent/version-0-1-2)는 이 352종의 카드 정의를 그대로 유지합니다. 0.1.1의 카드 수치·배치·명령·키워드는 [스펙 목록](#mwent/card-catalog)의 0.1.1 표시 카드에서 확인할 수 있습니다. 0.1.5 확장 카드와 구분하세요.
