## 어디에서 설정하나요?

Minigames **0.1.5**은 주민·떠돌이 상인 거래와 자연 생성 상자에 실물 카드·카드팩을 추가합니다. DRM 없이도 동작합니다.

1. Minigames 설정을 열고 **MWENT 편집**을 누릅니다.
2. 왼쪽에서 일반 / 상인 거래 / 상자 보상 / 카드 풀을 고릅니다.
3. 목록에서 규칙을 선택하고 가운데에서 수치·조건을 편집합니다.
4. 오른쪽에서 카드·팩 또는 대상 전리품 테이블을 고릅니다.
5. 상단 **Apply**로 활성 설정에 반영합니다.

월드 접속 중에는 서버 설정을 다루며 관리자 권한 2단계가 필요합니다. 월드 밖에서는 로컬 설정 파일을 편집하여 다음 시작 때 적용합니다. 월드 밖에서는 아이템 선택기가 비활성이고 기존 ID·수치·가중치는 편집할 수 있습니다.

## 세 종류의 규칙

| 분류 | 설정하는 내용 |
| --- | --- |
| 상인 거래 | 직업·레벨, 상품 풀, 결제 아이템, 가격 범위, 수량·재고·경험치 |
| 상자 보상 | 대상·제외 전리품 테이블, 풀, 확률, 추첨 횟수, 수량 |
| 카드 풀 | 자동 카드, 선택 모드 카드, 진영·등급·판본, 지정 카드·팩 가중치와 제외 카드 |

결제는 에메랄드 같은 실물 아이템입니다. 계좌형 DRM·CobbleDollars 결제와 구분합니다. 지정 카드와 제외 카드의 🔍는 MWENT 카드만 보여주며 인벤토리 아이템을 소비하지 않습니다.

## 던전 상자에 카드 추가하기

1. 일반에서 전체 활성화와 자연 생성 상자를 켭니다.
2. 상자 보상에 규칙을 추가하고 그 규칙도 켭니다.
3. 카드 풀을 고르고 확률 `0.2`, 추첨 `1`, 수량 `1~1`로 설정합니다.
4. 대상 전리품 테이블에 `minecraft:chests/simple_dungeon`을 선택하고 Apply합니다.
5. 아직 전리품이 결정되지 않은 던전 상자를 확인합니다.

위 예시는 상자별 20% 확률로 풀에서 고른 카드 또는 팩 하나를 추가합니다. 이미 연 상자는 재추첨하지 않습니다. 가중치는 풀 안의 상품 비율이며 상자 등장 확률과 다릅니다.

`minecraft:chests/village/*`는 바닐라 마을 상자입니다. 포켓몬센터 같은 모드 전리품은 별도 ID를 추가해야 합니다. `minecraft:chests/`만 쓰면 하위 전체가 선택되지 않습니다. 기본 마을 카드 규칙의 18%도 마을 전체가 아니라 대상 상자 하나당 확률입니다.

## 프로필 저장과 활성화

파일은 `config/dochi_minigames/` 아래에 있습니다.

- `acquisition.json`: 서버의 활성 획득 설정
- `acquisition_profiles/<이름>.json`: 전체 규칙을 보관하는 프로필

| 동작 | 의미 |
| --- | --- |
| Load / Save / Save As | 초안 불러오기 또는 프로필 보관 |
| Apply | 검증한 현재 초안을 활성 설정으로 저장·적용 |
| Cancel / Esc | 적용하지 않은 편집기 초안 취소 |

기본 프로필 `default.json`은 없는 경우만 설치합니다. 수정본은 다른 이름으로 저장하세요. 프로필을 불러오거나 저장하는 것만으로 활성 설정을 바꾸지 않습니다.

외부에서 파일을 수정했다면 `/minigame acquisition reload`를 사용합니다. 일반 `/reload`만으로 이 설정 파일을 다시 읽지 않습니다. 오류가 있으면 마지막 정상 설정을 유지합니다. **26.3에서 가격·재고·직업·새 규칙 등 네이티브 거래 정의를 바꾼 경우 월드 재접속 또는 서버 재시작이 필요합니다.**

이미 생성된 거래와 지급한 아이템은 유지합니다. 새 거래는 기존 후보 풀에 추가되므로 주민마다 반드시 나타나지는 않습니다. 설정을 켠다고 새 구조물이나 상자를 생성하지 않습니다. 실물 카드 지급과 카드 보관소 등록도 별도입니다.
