## 두 빠른 설정 도구

`Easy Build`와 `Presets`는 `DW Npc Core` 편집기 상단의 도움말 구역에 있는 제작자 도구입니다. 둘 다 현재 NPC의 전투 동작을 빠르게 구성하지만 사용 방식은 다릅니다.

| 도구 | 적합한 상황 | 결과 |
| --- | --- | --- |
| `Easy Build` | 질문에 답하면서 원하는 행동을 조합할 때 | 선택한 답으로 직접 전투 설정을 구성합니다. 이름 있는 역할 프리셋을 적용하지 않습니다. |
| `Presets` | 검증된 전투 유형을 바로 시작점으로 쓸 때 | Guard Rifleman, Patroller, Assault, Support Gunner, Sniper 중 하나의 전투 원칙을 적용합니다. |

두 도구 모두 결과를 잠그지 않습니다. 적용한 뒤 일반 카테고리에서 모든 값을 다시 조정할 수 있습니다.

## Easy Build 사용 순서

1. `DW Npc Core`로 NPC를 엽니다.
2. 상단의 `Easy Build`를 누릅니다.
3. 원하는 상세 수준을 선택합니다.
4. 질문에 답합니다. 현재 답에 따라 필요한 추가 질문만 나타날 수 있습니다.
5. 결과 화면에서 핵심 특성, 전체 강점, 주의점이나 충돌 경고를 확인합니다.
6. `Apply`를 누릅니다.
7. 일반 편집기로 돌아와 총기와 생성된 값을 확인한 뒤 `Save`합니다.

## 상세 수준

| 수준 | 질문 방식 |
| --- | --- |
| `Beginner` | 7개의 넓은 질문으로 대기 행동, 전투 이동, 거리, 반응, 사격, 생존 방식을 함께 구성합니다. 첫 성향 질문은 뒤의 권장 선택만 바꾸며 NPC 역할을 지정하지 않습니다. |
| `Intermediate` | 대기 이동, 인식, 교전, 재배치 간격, 사격, 명중률 상승, 제압, 엄폐, 탄약 소진 전환을 기능 묶음별로 직접 고릅니다. |
| `Expert` | 거리, 시간, 속도, 버스트, 제압, 엄폐 같은 개별 값을 조정합니다. 관련 기능을 켰을 때만 그 기능의 추가 질문이 나타납니다. |

Easy Build는 이름 있는 전투 프리셋을 기반으로 만들지 않습니다. Beginner의 성향도 `공격적`, `균형`, `신중` 같은 다음 답을 추천할 뿐 실제 설정을 몰래 덮어쓰지 않습니다.

## 유지되는 설정

Easy Build는 행동을 구성하는 도구입니다. 다음 콘텐츠는 유지됩니다.

* 원거리·근접 무기와 무기 풀
* 타겟 엔티티, 팩션, 태그 규칙
* 스킨과 방어구 풀
* 용병 계약
* 수류탄과 전투 FX
* 현재 가상 `Ammo Stock`과 최대 재고

적용 후에는 `Gun`, `Targets`, `Ammo`, `Visual & FX` 같은 카테고리에서 그대로 확인할 수 있습니다.

## 전투 프리셋

`Presets`는 일반 전투 원칙을 한 번에 적용합니다.

| 프리셋 | 시작 성격 |
| --- | --- |
| `Guard Rifleman` | 자리를 지키며 중거리에서 통제된 버스트를 사용하는 경비형 |
| `Patroller` | 구역을 순찰하고 소리를 조사하며 전투 중 이동하는 순찰형 |
| `Assault` | 빠르게 접근하고 이동 사격으로 압박하는 돌격형 |
| `Support Gunner` | 아군과 간격을 두고 중장거리 지속 사격과 제압을 사용하는 지원형 |
| `Sniper` | 긴 감지·사격 거리와 높은 명중률을 사용하는 장거리형 |

프리셋은 인식, 대기 행동, 교전 거리, 전술 이동, 사격, 엄폐, 재장전 반응을 바꿉니다. 무기, 방어구, 스킨, 타겟, 팩션 관계, 수류탄, FX, 용병 계약, `Ammo Stock`은 바꾸지 않습니다.

## 적용 후 점검

프리셋과 Easy Build는 시작점입니다. 적용한 뒤 아래 항목을 확인하세요.

1. 현재 총기가 프리셋의 거리와 사격 방식에 맞는지 확인합니다.
2. `Max Distance`, 감지 거리, 접근·후퇴 거리가 지형에 맞는지 봅니다.
3. `RPM Mode`, 명중률, 버스트 범위가 탄약 재고에 비해 과하지 않은지 확인합니다.
4. 이동과 엄폐를 단순한 지형에서 테스트합니다.
5. 결과가 맞으면 `Save`하고, 필요하면 `Save As`로 전체 NPC 설정 프로필을 보관합니다.
