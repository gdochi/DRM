## 패링 개념

패링은 단순히 공격을 막는 것이 아니라, **정해진 타이밍에 적의 특정 공격을 끊고 상태를 전환하는 시스템**으로 보는 편이 좋습니다.

## 설계 시 고려할 점

| 항목 | 질문 |
| --- | --- |
| 인지 | 어떤 공격이 패링 가능 대상인가? |
| 타이밍 | 어느 프레임 구간에서만 성공하는가? |
| 결과 | 경직, 넉백, 페이즈 중단, 카운터 허용 중 무엇이 발생하는가? |
| 호환성 | Better Combat 또는 특정 애니메이션 모드가 전제되는가? |

## 추천 구현 흐름

1. 패링 가능 공격 태그를 먼저 나눕니다.
2. 적이 현재 공격 모션인지 확인하는 조건을 둡니다.
3. 성공 시 `parried` 같은 상태를 짧게 부여합니다.
4. 경직 패턴이나 후속 카운터 창을 연결합니다.
5. 패링 실패 시에는 기본 피해 처리 또는 블록 처리로 빠지게 합니다.

:::warning 주의
멀티플레이 환경에서는 프리즈 연출보다 **상태 전환과 피드백**을 우선하는 편이 안정적입니다.
:::
