## El 0.1.4 registro y la dirección actual

Esta página registra el flujo de trabajo de creación **0.1.4**. La versión actual marcada BattleWorks es 0.1.6; use [actual setup](#mob-editor/mob-editor-setup) para archivos y preparación de NPC. No lleve el antiguo requisito CustomNPCs a las configuraciones actuales DNPC.

![Una primera barra se guarda en actual BattleWorks.](assets/media/guides/battleworks-016-neo1211/battleworks-first-saved.png "BattleWorks 0.1.6 / NeoForge 1.21.1, Inglés UI. Una ilustración actual de crear un patrón y guardar un archivo separado, no una captura 0.1.4 archivada.")

## Flujos de trabajo realizados

- Prepare modelos NPC y texturas externas en DRM NPC Basic, luego utilícelos en la Biblioteca Hitbox y vistas previas de patrones.
- Añade acciones a las pistas Windup, Action o Recovery seleccionadas. El selector de habilidades enumera las habilidades compatibles de los proveedores instalados y registrados.
- Vista previa comprueba el movimiento, animación y hitboxes. Verifica el objetivo, la colisión y las habilidades externas en una pelea mundial.

Continuar con [setup](#mob-editor/mob-editor-setup), [primer ataque](#mob-editor/battleworks-first-attack) y [habilidades/efectos](#mob-editor/battleworks-skills-effects). Combat JSON sigue siendo `dochi.battleworks.v1`.
