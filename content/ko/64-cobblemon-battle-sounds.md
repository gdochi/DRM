## 기능 구분

`Battle sounds`는 Trainer 배틀의 남은 포켓몬 수에 따라 재생하는 런타임 사운드 규칙입니다.

- `Battle Presentation Maker`의 타임라인 오디오가 아닙니다.
- 배틀 시작 전 연출이 아니라 실제 Cobblemon 배틀 중에 작동합니다.
- `DRM Strategy`, RCT, Cobblemon Strong 중 어느 AI 엔진을 쓰든 동일한 사운드 규칙을 사용합니다.
- Trainer 배틀에만 적용됩니다.

## 편집 절차

1. `Cobblemon Editor`에서 Trainer 문서를 엽니다.
2. Trainer 섹션 상단의 `Battle sounds`를 누릅니다. `Battle Strategy`에서도 현재 라운드를 유지한 채 같은 에디터로 진입할 수 있습니다.
3. 왼쪽에서 `전체 라운드` 또는 특정 라운드를 선택합니다.
4. 남은 포켓몬 수 1–6 중 트리거를 선택합니다.
5. `이 수에서 재생`을 켜고 사운드 ID, 볼륨, 피치를 설정합니다.
6. `재생`과 `정지`로 클라이언트 미리듣기를 확인합니다.
7. `적용`한 뒤 상위 Cobblemon Editor에서 `Save` 또는 `Save As`로 문서를 저장합니다.

`Close`는 에디터의 변경을 적용하지 않고 닫는 동작입니다. 수정 중이거나 잘못된 숫자가 남아 있으면 버릴지 확인합니다.

## 공통과 라운드 모드

| 대상 | 모드 | 동작 |
| --- | --- | --- |
| 전체 라운드 | 공통 | 상속하는 모든 라운드의 기준 |
| 특정 라운드 | `공통 사용` | 현재 공통 규칙을 그대로 사용 |
| 특정 라운드 | `개별` | 해당 라운드의 1–6 규칙을 별도로 사용 |
| 특정 라운드 | `끄기` | 공통 규칙이 있어도 해당 라운드에서는 재생하지 않음 |

라운드를 `개별`로 처음 바꾸면 현재 공통 규칙을 초기 초안으로 복사합니다. 그 뒤의 변경은 해당 라운드에만 적용됩니다.

## 트리거 동작

- 출전 포켓몬과 대기 파티의 살아 있는 포켓몬을 함께 셀니다.
- 배틀이 시작한 뒤 처음 관측한 수도 트리거가 될 수 있습니다. 예를 들어 6마리 트레이너의 `6`을 켜면 배틀 시작 시점에 재생합니다.
- 포켓몬이 기절해 남은 수가 줄어들 때 해당 규칙을 확인합니다.
- 각 수는 한 배틀에서 최대 한 번만 재생됩니다.
- 0마리는 배틀 종료이므로 규칙을 제공하지 않습니다.
- 같은 NPC와 다시 배틀하면 새 세션에서 트리거 기록을 다시 시작합니다.

## 사운드 설정

| 설정 | 범위·의미 |
| --- | --- |
| 사운드 ID | 현재 클라이언트 리소스팩에서 찾을 수 있는 네임스페이스 ID |
| 볼륨 | 0–4. 0은 실제 재생을 하지 않음 |
| 피치 | 0.05–4 |
| `재생 전 기존 소리 정지` | 현재 배틀 음악과 이 규칙으로 시작한 소리를 먼저 정지한 뒤 새 사운드 재생 |

사운드 선택창은 번역된 이름과 ID를 검색합니다. 미리듣기에서 소리가 나지 않으면 잘못된 ID보다 현재 리소스팩에 사운드가 있는지부터 확인하세요. 선택 목록을 보는 동작은 `이 수에서 재생` 스위치를 자동으로 켜지 않습니다.

`Stop`은 이 에디터의 미리듣기만 정지합니다. 실제 배틀의 `재생 전 기존 소리 정지` 정책은 별도 설정입니다.

## 런타임 종료

배틀이 종료되거나 세션이 정리되면 서버가 해당 배틀 사운드를 정지하는 패킷을 클라이언트에 보냅니다. 이 종료 처리는 다른 일반 게임 사운드를 전체 정지하는 기능이 아닙니다.

## JSON 참고

다음은 외부 도구·버전 관리용 참고입니다. Trainer JSON 스키마 22에서 공통 규칙은 `trainerOptions.battleSound.rules[]`, 라운드 설정은 `rounds[].battleSoundOverride`에 저장됩니다. 각 규칙은 `remainingPokemon`, `enabled`, `sound`, `volume`, `pitch`, `stopBeforePlay`를 사용합니다. 에디터에서 저장하는 흐름을 권장합니다.
