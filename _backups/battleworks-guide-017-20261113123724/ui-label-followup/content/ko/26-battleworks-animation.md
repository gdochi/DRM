## 1. 실제 NPC의 모델부터 준비하기

먼저 실제 NPC를 설정합니다. DNPC는 **외형 및 모델**, DRM 모델은 **DRM NPC Basic**과 해당 에셋을 사용합니다. **DRM은 선택 사항**입니다. DRM이 없으면 기본 인간형 휘두르기와 지원하는 선택 애니메이션 제공자를 사용할 수 있고, DRM이 설치되어 있으면 DRM이 애니메이션 재생을 담당합니다.

| 모델·방식 | 사용하는 소스 |
| --- | --- |
| 일반 인간형 | Main-Hand Swing 또는 호환되는 Player Animator / PAL 모션 소스 |
| Better Combat 무기 모션 | 호환되는 Better Combat 리소스와 지원 무기 |
| Gecko 모델 | 설치한 모델 제공자와 애니메이션 파일이 제공하는 실제 클립 |
| DRM 모드 엔티티·Behavior | DRM 연동이 제공하는 클립 또는 의미 매핑 |
| 모양만 시험 | 명시적인 No Animation / None |

사용자 인간형 클립은 자기 네임스페이스로 표시될 수 있으며 Better Combat ID로 제한되지 않습니다. Gecko 클립과 인간형 포즈 레이어는 서로 바꿔 쓸 수 없습니다. CustomNPCs는 26.3 미만의 선택 연동에만 해당합니다.

## 2. 히트박스 라이브러리에서 클립 고르기

1. 패턴의 액션에서 **이 히트박스 편집**을 엽니다.
2. **Pattern:**에서 연결된 사용처를 고르고 Action 등 단계를 선택합니다.
3. **Clips** 위의 소스 설명을 읽고 이름이나 ID로 검색합니다.
4. 호환 클립을 선택한 뒤 Play로 접촉 자세를 확인하고 Stop을 누릅니다.
5. 실제 접촉에 맞춰 패턴의 타격 이벤트를 조정하고 저장·적용합니다.

연결된 패턴 없이 고른 클립은 임시 미리보기입니다. 단계 애니메이션을 저장하려면 원하는 사용처를 선택하세요. 분리 미리보기는 연결 NPC의 외형 복사본, 저장한 미리보기 설정 또는 기본 액터를 사용합니다. 모델이 다르면 실제 NPC를 대상으로 다시 여세요.

![히트박스 라이브러리의 클립 소스·검색·긴 클립 이름.](assets/media/guides/battleworks-017-20261113/animation-clips.png "BattleWorks 0.1.7 / Fabric 1.21.1 / DRM 0.3.2 / DNPC 0.1.4, Better Combat 리소스 설치 환경. 소스 설명은 검색 위에서 줄바꿈되고 긴 클립 이름은 마우스를 올려 확인합니다. 이 정지 화면에는 호환 단계 모션이 지정되지 않아 재생 성공을 보여주는 장면은 아닙니다.")

긴 클립 이름은 한 행을 유지하고 마우스를 올리면 전체 내용을 확인할 수 있습니다. 모델과 목록 사이 경계선을 끌어 폭을 늘리거나 리소스 로딩 뒤 새로고침하세요.

## 3. 애니메이션을 넣는 세 위치

| 위치 | 사용 목적 | 예 |
| --- | --- | --- |
| 단계의 Animation | Windup / Action / Recovery가 시작될 때 모션 연결 | Action에 칼 휘두르기 |
| 타임라인 Animation 액션 | 특정 틱에 별도 모션 시작 | 0틱 준비 모션, 12틱 발사 모션 |
| Skill의 Cast Animation | 스킬 시전 성공마다 모션 요청 | 주문 발사마다 시전 자세 |

처음에는 **Action 단계에 모션 하나**만 넣고 Hitbox의 Event Tick을 맞추는 방법이 쉽습니다.

단계에 애니메이션이 설정되어 있으면 같은 단계 안의 일반 Animation 액션보다 단계 설정이 우선합니다. 타임라인 액션으로 여러 모션을 제어하려면 해당 단계의 애니메이션을 명시적으로 None으로 선택한 뒤 액션을 배치하세요.

## 4. 단계가 바뀔 때의 0.1.5 동작

- 이어지는 단계가 같은 애니메이션 매핑을 사용하면 매번 처음부터 다시 시작하지 않고 연속 구간으로 처리합니다.
- 서로 다른 단계 매핑은 각 단계 진입 시 새 재생 대상으로 처리됩니다.
- 명시적인 액션·시전 모션의 재생 시간이 남아 있으면 Recovery 모션이 그 구간을 바로 잘라내지 않도록 기다릴 수 있습니다.
- 액션의 Duration과 스킬의 Cast Animation Ticks는 작성한 시간을 사용합니다. 무조건 패턴 끝까지 늘리지 않습니다.
- Hitbox를 반복 실행해도 단계 애니메이션이 타격마다 자동 재시작하지 않습니다.

0.1.2 기준의 “첫 단계 모션 하나만 패턴 전체를 소유한다”는 설명을 0.1.5의 제작 규칙으로 사용하지 마세요.

## 5. 재생 속도와 타격 시점 조정하기

1. 먼저 Animation Speed를 `1.0`으로 두고 클립을 봅니다.
2. Hitbox Event Tick을 실제 접촉 자세에 맞춥니다.
3. 빠르게 할 필요가 있을 때 애니메이션 속도를 조금 높입니다.
4. 속도를 바꿨다면 Event Tick과 단계 길이를 다시 맞춥니다.
5. 저장 후 실제 전투에서 비교합니다.

**미리보기 속도**와 **Animation Speed**는 다릅니다. 미리보기 0.5x는 천천히 관찰하는 설정이고, Animation Speed는 저장되어 실제 모션에 영향을 줍니다.

Gecko 클립은 DRM의 렌더 시계를 사용하므로 임의의 틱으로 이동했을 때 모든 클립의 정확한 프레임 탐색을 보장하지 않습니다. Play / Stop / 재시작으로 흐름도 함께 확인하세요.

## 6. None을 선택해도 오류가 나지 않게 하기

애니메이션 없는 판정을 의도했다면 화면에서 None을 직접 선택합니다. JSON에서는 다음 설정에 해당합니다.

```json
{
  "explicitSelection": true,
  "provider": "none",
  "id": "",
  "playback": "once",
  "speed": 1.0,
  "fadeTicks": 0
}
```

이것은 **단계의 animation 객체 예시**이며 전투 문서 전체가 아닙니다. explicitSelection이 없는 오래된 히트박스 단계는 호환 처리 중 기본 팔 휘두르기로 바뀔 수 있습니다.

## 7. 클립 목록이 비었거나 호환되지 않을 때

1. 실제 NPC의 모델과 Clips 위 소스 설명을 확인합니다.
2. Gecko는 모델 `.geo.json`과 애니메이션 `.animation.json`을 구분하고 연결된 애니메이션 에셋을 확인합니다.
3. 인간형 클립은 버전에 맞는 Player Animator / PAL 제공자와 실제 클라이언트 리소스를 확인합니다. Better Combat은 해당 모션을 쓸 때 필요합니다.
4. 비동기 리소스 로딩 뒤 새로고침합니다. ID를 임의로 만들지 말고 현재 모델의 목록에서 선택하세요.
5. DRM이 있으면 모델 매핑과 재생을 확인하고, 없으면 기본 휘두르기부터 시험한 뒤 선택 클립을 추가합니다.

목록에 보인다는 이유만으로 다른 모델에서도 재생할 수 있는 것은 아닙니다. 저장·적용 뒤 실제 NPC와 비교하세요.

## 저장된 모델 설정을 포함한 파일 적용

문서에 `drmNpcModel` 복사본이 있으면 적용 시 모델 설정도 복원될 수 있습니다. 같은 전투를 기존 모델에 적용할 때는 복사본 유무를 먼저 확인합니다. `previewNpcModel`과 `previewTexture`는 미리보기용이며 실제 NPC 적용용 모델 설정과 다릅니다.

마지막에는 미리보기에서 확인한 모션이 **실제 NPC의 공격에서도 재생되는지** 반드시 시험합니다.
