## 1. NPC Basic에서 모델부터 확인하기

BattleWorks는 DRM이 제공하는 모델과 재생 기능을 사용합니다. 모델 파일·텍스처·기본 동작 연결은 **DRM → NPC Basic**에서 먼저 준비합니다.

| 사용하는 모델 / 방식 | 연결할 애니메이션 |
| --- | --- |
| 일반 인간형 CustomNPC | 기본 Main-Hand Swing 또는 설치된 인간형 모션 |
| DRM Gecko 모델 | 해당 모델의 애니메이션 파일에 실제 존재하는 Gecko 클립 |
| DRM 모디드 엔티티 모델 | 해당 DRM 연동이 노출하는 네이티브 엔티티 클립 |
| DRM Behavior | NPC Basic에 이미 연결된 attack 같은 의미별 동작 |
| 애니메이션 없이 판정만 확인 | 명시적으로 No Animation / None 선택 |

Gecko 모델에 인간형 Better Combat 모션을 연결해도 같은 방식으로 움직이지 않습니다. 제공 모드가 없거나 모델과 맞지 않으면 미리보기 경고나 검증 오류가 생길 수 있습니다.

## 2. Hitbox Library에서 클립 고르기

1. 패턴의 Hitbox 액션에서 **Edit this hitbox**를 엽니다.
2. **Pattern:**에서 연결 위치를 고릅니다.
3. 모델 위 단계 선택에서 **Action**을 고릅니다.
4. 모델 옆 **Clips** 목록에서 이름을 검색하고 실제 클립을 선택합니다.
5. **Play**로 재생하고 **Stop**으로 중지합니다.
6. 칼이 닿는 자세와 히트박스 표시를 비교합니다.

**Pattern:**은 히트박스를 쓰는 위치를 고르는 메뉴이고, **Clips**는 애니메이션 목록입니다. 두 메뉴를 혼동하지 마세요.

아직 NPC가 연결되지 않은 미리보기는 문서의 모델 스냅샷을 사용하거나 기본 연습 모델을 보여줄 수 있습니다. 실제 NPC 모델과 다른 경우에는 NPC를 대상으로 다시 열어 확인합니다.

## 3. 애니메이션을 넣는 세 위치

| 위치 | 사용 목적 | 예 |
| --- | --- | --- |
| 단계의 Animation | Windup / Action / Recovery가 시작될 때 모션 연결 | Action에 칼 휘두르기 |
| 타임라인 Animation 액션 | 특정 틱에 별도 모션 시작 | 0틱 준비 모션, 12틱 발사 모션 |
| Skill의 Cast Animation | 스킬 시전 성공마다 모션 요청 | 주문 발사마다 시전 자세 |

처음에는 **Action 단계에 모션 하나**만 넣고 Hitbox의 Event Tick을 맞추는 방법이 쉽습니다.

단계에 애니메이션이 설정되어 있으면 같은 단계 안의 일반 Animation 액션보다 단계 설정이 우선합니다. 타임라인 액션으로 여러 모션을 제어하려면 해당 단계의 애니메이션을 명시적으로 None으로 선택한 뒤 액션을 배치하세요.

## 4. 단계가 바뀔 때의 0.1.3 동작

- 이어지는 단계가 같은 애니메이션 매핑을 사용하면 매번 처음부터 다시 시작하지 않고 연속 구간으로 처리합니다.
- 서로 다른 단계 매핑은 각 단계 진입 시 새 재생 대상으로 처리됩니다.
- 명시적인 액션·시전 모션의 재생 시간이 남아 있으면 Recovery 모션이 그 구간을 바로 잘라내지 않도록 기다릴 수 있습니다.
- 액션의 Duration과 스킬의 Cast Animation Ticks는 작성한 시간을 사용합니다. 무조건 패턴 끝까지 늘리지 않습니다.
- Hitbox를 반복 실행해도 단계 애니메이션이 타격마다 자동 재시작하지 않습니다.

0.1.2 기준의 “첫 단계 모션 하나만 패턴 전체를 소유한다”는 설명을 0.1.3의 제작 규칙으로 사용하지 마세요.

## 5. 재생 속도와 타격 시점 조정하기

1. 먼저 Animation Speed를 `1.0`으로 두고 클립을 봅니다.
2. Hitbox Event Tick을 실제 접촉 자세에 맞춥니다.
3. 빠르게 할 필요가 있을 때 애니메이션 속도를 조금 높입니다.
4. 속도를 바꿨다면 Event Tick과 단계 길이를 다시 맞춥니다.
5. 저장 후 실제 전투에서 비교합니다.

**미리보기 속도**와 **Animation Speed**는 다릅니다. 미리보기 0.5x는 천천히 관찰하는 설정이고, Animation Speed는 저장되어 실제 모션에 영향을 줍니다.

Gecko 클립은 DRM의 렌더 시계를 사용하므로 임의의 틱으로 이동했을 때 모든 클립의 정확한 프레임 탐색을 보장하지 않습니다. Play / Stop / 재시작으로 흐름도 함께 확인하세요.

## 6. None을 선택해도 오류가 나지 않게 하기

애니메이션 없는 판정을 의도했다면 화면에서 None을 직접 선택합니다. JSON에서는 다음 설정에 해당합니다.

```json
{
  "explicitSelection": true,
  "provider": "none",
  "id": "",
  "playback": "once",
  "speed": 1.0,
  "fadeTicks": 0
}
```

이것은 **단계의 animation 객체 예시**이며 전투 문서 전체가 아닙니다. explicitSelection이 없는 오래된 히트박스 단계는 호환 처리 중 기본 팔 휘두르기로 바뀔 수 있습니다.

## 7. 목록이 비었을 때 확인 순서

1. NPC Basic의 모델 타입이 맞는지 봅니다.
2. `.geo.json`은 모델 모양, `.animation.json`은 클립 데이터라는 점을 확인합니다.
3. 모델이 실제 애니메이션 파일을 참조하는지 확인합니다.
4. 제공 모드와 클라이언트 리소스가 있는지 확인합니다.
5. 자산 로딩이 끝난 뒤 목록을 새로고침합니다.
6. 그래도 없으면 그 모델에 DRM이 해당 클립을 노출하는지 확인합니다.

인터넷에서 본 다른 모델의 ID를 추측해서 넣지 말고 현재 NPC의 목록을 사용하세요.

## 모델 스냅샷을 포함한 파일 적용

문서에 `drmNpcModel` 스냅샷이 있으면 적용 시 모델 설정도 복원될 수 있습니다. 같은 전투를 기존 모델에 적용할 때는 스냅샷 유무를 먼저 확인합니다. `previewNpcModel`과 `previewTexture`는 미리보기용이며 실제 NPC 적용용 모델 설정과 다릅니다.

마지막에는 미리보기에서 확인한 모션이 **실제 NPC의 공격에서도 재생되는지** 반드시 시험합니다.
