## Version baseline

0.1.1–0.1.4 refer to **actual CurseForge uploads**. Card comparisons read the final catalog from each uploaded Fabric 1.21.1 JAR. 0.1.5 refers to **sources and production JARs in the current independent 26.3 workspace**, not a claimed public upload. Dates use Korea Standard Time.

Counts represent distinct **card definitions**. Regular and animated prints are not separate combat cards. Definitions for absent optional providers can still exist, so catalog size is different from playable-card availability.

## Read the specifications

The [current catalog](#mwent/card-catalog) lists stable identities, power, provisions and abilities, separating cards present in 0.1.1 from 0.1.5 additions. In 0.1.5, existing power, provisions, frames, rarity and legacy Deploy, Order and keyword definitions remain intact. New default fields for authored abilities are not counted as balance changes to existing cards.

Future entries should distinguish additions, removals, numeric changes, ability changes and appearance changes, recording before → after values. A zero-addition release is explicitly recorded rather than omitted.
