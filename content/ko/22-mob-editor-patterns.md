## 패턴을 먼저 만들기

**Pattern Workbench**의 패턴 목록에서 항목을 직접 선택합니다. **Find pattern**으로 이름이나 ID를 검색할 수 있습니다. 패턴 안에서 단계를 선택한 뒤 세부 액션을 추가합니다.

| 단계 | 역할 | 예시 길이 |
| --- | --- | --- |
| Windup | 공격 준비, 방향 맞추기, 예고 | 6틱 |
| Action | 공격 모션과 실제 판정 | 18틱 |
| Recovery | 회복 동작과 다음 선택 전 빈틈 | 12틱 |

20틱은 정상 틱 속도에서 1초입니다. 위 예시는 전체 36틱이며, Action의 9틱 판정은 전체 타임라인의 15틱 위치에 표시됩니다.

## Timed actions와 이벤트의 의미

**이벤트는 같은 시점에 실행할 액션 묶음**입니다. 애니메이션 목록이나 별도 패턴 목록이 아닙니다. 이벤트의 시점, 반복 간격, 반복 횟수, 확률을 그 안의 액션들이 공유합니다.

예를 들어 `hit` 이벤트의 Action 6틱에 칼날 Hitbox와 칼끝 Hitbox를 함께 넣을 수 있습니다. 타임라인에는 두 액션이 별도 행으로 표시되어 각각 선택할 수 있습니다. 같은 이벤트의 핀을 옮기면 그 묶음의 실행 시점이 함께 바뀝니다. 다른 시점이나 반복 규칙이 필요하면 별도 이벤트 묶음을 사용합니다.

| 설정 | 예시 |
| --- | --- |
| 첫 실행 시점 | Action 6틱 |
| 반복 간격 | 5틱 |
| 실행 횟수 | 3회 |
| 실행되는 시점 | Action 6, 11, 16틱 |

단계가 끝난 뒤의 반복은 실행되지 않습니다. 여러 판정을 넣어도 같은 애니메이션을 반복 재시작시키는 용도로 쓰이지 않습니다.

## 세부 액션 연결

1. 원하는 단계에서 **+ Action**을 누릅니다.
2. Hitbox, Skill, Animation 또는 이동·시선 제어 같은 액션 종류를 선택합니다.
3. Hitbox나 Skill 참조는 **Choose from list**로 선택합니다. 목록의 스킬은 DRM에 노출된 스킬이며 해당 제공 모드가 필요할 수 있습니다.
4. 타임라인의 이름 있는 행을 선택해 해당 액션을 편집합니다.
5. 핀을 드래그해 실행 틱을 바꿉니다. 행이 많으면 스크롤합니다.

## 재사용 히트박스 편집

**Hitbox Library**에서 box, capsule, sphere, cylinder, sweep, polygon 모양을 사용할 수 있습니다. 피해, 모양에 맞는 크기, XYZ 오프셋, 회전과 sweep 구간 등을 조정합니다.

히트박스 정의에는 실행 시점이나 애니메이션이 들어가지 않습니다. 정의를 바꾸면 같은 문서 안에서 그 ID를 참조하는 패턴들이 변경된 모양을 사용합니다. 실제 타격 시점은 패턴의 Hitbox 액션에서 정합니다.

히트박스 화면의 **Pattern:** 선택기는 이 히트박스를 사용하는 패턴·액션 위치를 선택합니다. 모델 옆의 클립 목록과는 별개의 기능입니다. **Edit pattern**으로 해당 패턴에 돌아갑니다.

## 패널과 미리보기 크기

- 세로 구분 막대를 드래그해 목록·중앙 작업 영역·검사 패널의 좌우 폭을 조절합니다.
- 히트박스 화면의 가로 막대로 모델과 타임라인의 상하 높이를 조절합니다.
- 모델과 클립 목록 사이의 세로 막대로 각각의 폭을 바꿉니다.
- 패널 제목의 **방향 화살표**로 접거나 펼칩니다. **Reset panels**는 기본 배치로 되돌립니다.
- Front, Iso, Side는 카메라 방향이고, 모델 도구의 − / +는 확대·축소입니다.

화면 배치는 클라이언트 설정에 저장됩니다. 플레이어별 패널 크기가 NPC 전투 문서를 바꾸지는 않습니다.
