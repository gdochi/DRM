# DNPC Create 설명 영상 재촬영

Create 네 문서의 영상을 설정 작성부터 실행·결과 확인까지 이어지는 **12개 강의, 총 1,297.641초(21분 38초), 148개 단계 설명**으로 교체했다. 한국어·영어·포르투갈어·스페인어·프랑스어의 문서 20개에 같은 영상과 실제 촬영 시각에 맞춘 구간표를 반영했다. 시간표 문서 5개의 실제 UI 명칭도 `Mount vehicle`로 바로잡았다.

장치와 재료만 미리 준비하고 NPC 시간표는 비운 상태에서 시작한다. 반송 강의는 직전 보관함 배송 강의에서 네이티브 편집기로 저장한 설정을 이어 쓴다. 시간표 활성화와 NPC 저장을 모두 촬영한다. 동작을 관찰하는 동안 NPC 위치·작업 결과를 강제로 만들지 않는다.

반송의 목적지 채우기, 조건 제어의 센서 재고 0→6, 좌석 종료의 월드 시각 변경은 재현 도구의 입력으로 명시한다. 자재 주문은 접수·포장까지이며 실제 수령 통 도착·개봉은 별도 경로가 필요하다. 움직이는 좌석의 모든 조립·재접속, Linked Controller 전체 채널과 Burner 급유를 새로 촬영했다고 주장하지 않는다.

## 화면과 원본

- DNPC 0.1.3 + Create 6.0.10 / NeoForge 1.21.1의 실제 배포 JAR을 사용했다. 채택한 실행들의 생산 모드 SHA-256은 동일하며 촬영 도구 JAR은 별도 기록한다. 촬영 버전을 전 환경의 최소 요구 버전으로 바꾸지 않았다.
- 실제 게임 프레임은 1920×1080이다. 원래 시간 간격을 유지한 20fps 영상에 별도 180px 한국어 단계 설명 영역을 추가해 최종 크기는 1920×1260이다. 게임 필드와 설명 영역이 겹치지 않는다.
- 네이티브 클릭·문자 입력·스크롤·월드 선택을 보여 준다. 입력 위치를 표시하고 필드와 실제 보관함·연결 재고를 확대한다. UI를 다시 그려 바꾸거나 보간 프레임을 만들지 않는다.
- 원본 RGB를 제한 범위 BT.709로 변환하고 MP4와 WebM을 제공한다. 무음 영상이며 폰트 파일은 최종 자산에 포함하지 않는다. 인코딩은 2개 스레드로 제한했다.
- 배포 자산은 `src/media/guides/create-lessons-20261108/`의 MP4·WebM·PNG 각 12개다. 각 대표 이미지는 해당 작업의 핵심 설정 또는 실제 주문 화면에서 골랐다.
- 보관함·연결 재고의 실제 화면 13구간을 추가 확대했다. 플레이어 위에도 재생·탐색에 동기화되는 한국어 현재 단계를 표시해 일시정지 중 재생 막대가 설명을 가리지 않게 했다. 작은 화면에서는 이 안내를 일반 문서 글자 크기로 읽을 수 있다.
- **OBS의 설정·프로필·장면·오디오·출력·프로세스를 조작하지 않았다.** Minecraft 프레임버퍼에서 직접 촬영했다. 사용자 런처와 기존 월드를 변경하지 않았다.

## 판정과 수정

채택은 크랭크의 실행 03, 나머지 열 강의의 실행 04, 전광판 강의의 실행 06이다. `selected-recordings.json`과 각 실행 환경·로그를 근거로 한다.

편집기 진입 거리, 비공개 선택기 레코드 접근, 밸브 횟수 변경 후 입력란 갱신을 보완했다. 실패 범위의 원인을 확인한 뒤 순차 촬영했으며 완료된 크랭크는 반복 촬영하지 않았다. 모든 게임은 단일 3GB 상한과 종료 확인 범위에서 실행했다.

전광판은 서버에 문자열이 들어간 것만으로 채택하지 않았다. 첫 화면 검토에서 동력 없이 글자가 확정되지 않는 구성을 제외했고, 축 직결도 받지 않는 실제 보드 구현을 확인했다. 옆 Cogwheel 맞물림으로 수정한 실행 06에서 서버·클라이언트 -64 RPM, 실제 클라이언트 구동 상태, 제목의 문자 전환 완료와 화면의 전체 보고를 확인했다. 제외된 자료는 `rejected-unpowered-board/`, `rejected-direct-shaft-board/`에 구분한다.

`saved-policy-audit.json`은 서버에 저장된 시간표·좌표·수량·초/틱 값·주소·수신자·센서·임계값·보드 예약을 실제 입력값과 대조한 결과다. 네이티브 실행 결과, 원본 프레임 시각·해시, 대표 원본 프레임, 주석·확대 시각, 양쪽 코덱 영수증과 최종 자산 해시를 `docs/evidence/dnpc-create-detailed-20261108/`에 보존한다.

## 문서와 복구

`151c-npc-core-create-start.md`, `151d-npc-core-create-logistics.md`, `151e-npc-core-create-factory.md`, `151f-npc-core-create-control.md`와 각 언어의 `151a-npc-core-schedules.md`를 갱신했다. 보드의 실제 톱니 연결, 상한부터 입력하는 순서, 준비물과 직접 작성한 설정, 접수와 실제 배송의 범위를 설명한다.

백업은 `_backups/dnpc-create-detailed-20261108-221703/`이다. 이전 영상 자산 45개가 백업과 바이트 단위로 일치하고 문서 참조가 사라졌음을 확인한 후 이전 자산 폴더를 교체했다. 모드 구현·배포 JAR 변경이 없으므로 모드 릴리스 체인지로그는 수정하지 않았다.

빌드 910개 문서, 정적 검사 1,667개 이미지·185개 영상 배치, 번역 546개를 통과했다. 새 영상 12편의 5개 언어·데스크톱/모바일 120개 화면에서 실제 재생·탐색·일시정지·반복·MP4 대체를 확인했다. 현재 단계 동기화와 플레이어 바깥 표시, 한국어 문서 8개 배치도 통과했다. 양쪽 코덱 전체 디코딩·최종 36개 자산 해시와 빌드 바이트 일치는 `verification-summary.json`에 기록했다.

2026-11-09 최종 정리: 소유 Minecraft 프로세스 0개를 확인하고 촬영 인스턴스 6개, 임시 원본 전체 프레임, 컴파일·변환·폰트·FFmpeg 설치본과 일회성 작업 파일을 삭제했다. 원본 프레임별 시각·해시와 대표 프레임, 최종 영상·검증 자료, 재현용 촬영 계획·Java/인코딩/사이트 검증 코드와 복구 백업은 보존했다. `cleanup.json`에 삭제한 절대 경로를 남겼다.
