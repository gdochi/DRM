## 기믹 켜기

차량 편집기의 기믹 목록에서 사용할 항목을 켜고 상세 조건을 정한 뒤 저장합니다. 기본값은 모두 OFF입니다. 서버가 해당 차량의 엔진·무장·연막·좌석을 검사해 지원 항목을 표시합니다. `전체 보기`에서는 지원하지 않는 저장 설정도 확인할 수 있지만 편집은 비활성화됩니다.

| 기믹 | 동작과 조건 |
| --- | --- |
| 발사 준비 예고 | 무장별 발사 대기 시작 때 예고를 재생합니다. 조준·탄약·발사 대기 조건을 유지합니다. |
| 피격 후퇴 | 직전 AI 갱신 이후 체력 손실이 기준 이상이면 잠시 뒤로 이동합니다. 바퀴·궤도 차량용입니다. |
| 비상 연막 | 피격, 잔여 체력 또는 후퇴 시작 조건으로 원본 연막을 요청합니다. 항공기 플레어와 다릅니다. |
| 저체력 점사 | 기본 점사가 켜진 무장에서 다음 점사의 길이·휴지를 바꿉니다. 원본 발사 속도는 유지합니다. |
| NPC 전투 하차 | 적이 범위 안에 있고 차량이 10틱 이상 안정적으로 정차하면 선택한 수송 좌석의 NPC를 하차시킵니다. |
| 저체력 이탈 | 저체력 구간에서 표적 반대 방향으로 잠시 이동합니다. |
| 재장전 후퇴 | 승무원 조건을 만족하는 활성 무장이 모두 재장전 중일 때 물러납니다. 사용 가능한 무장의 재장전이 끝나거나 표적을 잃으면 종료합니다. |
| 피격 측면 회피 | 피격 기준을 만족하면 적 방향에 수직인 위치로 이동합니다. |
| 폭격 | 검증된 고정익의 자유낙하 무장으로 `LEVEL`, `DIVE`, `CARPET` 공격을 수행합니다. |

## 체력과 시간 읽기

최대 체력 500에서 **체력 손실 2%**는 직전 갱신 이후 실제 체력이 10 이상 줄었다는 뜻입니다. **잔여 체력 25%**는 현재 체력이 125 이하라는 뜻입니다. 저체력 반응의 재발동에는 기준보다 5퍼센트포인트 이상 회복하는 조건이 적용됩니다.

20틱은 정상 20 TPS에서 1초입니다. 연막 쿨다운 외에도 원본 연막 잔탄과 재장전이 적용됩니다. DWE가 연막 탄약을 채우거나 무적·표적 차단 효과를 추가하지 않습니다.

## 이동과 하차

이동 반응의 동시 발동 우선순위는 피격 후퇴 → 피격 측면 회피 → 저체력 이탈 → 재장전 후퇴입니다. 기존 홈 경계와 경로 탐색을 사용하며 순간 이동하지 않습니다. `STATIONARY에서도 이동`, `HOLD에서도 이동`을 끄면 해당 모드에서 이동 기믹을 차단합니다. `이동 반응 중 발사`가 켜져 있어도 기존 사격·정지·안전 거리 조건은 계속 적용됩니다.

NPC 전투 하차는 바퀴·궤도 차량의 기존 CustomNPCs 승객을 대상으로 합니다. 운전수·포수·무장 좌석·플레이어는 제외합니다. 안전한 하차 위치가 없으면 실행하지 않으며 자동 재탑승이나 새 NPC 생성도 하지 않습니다. 하차 기록은 좌석과 NPC별로 유지됩니다.

## 폭격과 지원 호출의 차이

차량의 폭격 기믹은 이미 있는 AI 기체의 전투 행동입니다. `LEVEL`은 수평 정밀, `DIVE`는 급강하, `CARPET`은 구역 연속 투하입니다. 실제 자유낙하 무장, 탄약, RPM과 원본 비행 물리가 필요합니다.

특정 시점에 지원 기체나 증원을 호출하려면 별도의 [기믹 타임라인](#dochi-warfare-expanded/expanded-support-timeline)을 사용하세요.
