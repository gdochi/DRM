# Dochi's RPG Maker

Dochi's RPG Maker is a Forge 1.20.1 authoring toolkit for building RPG content directly in Minecraft.

Create dialogues, NPC shops, quests, currencies, stat systems, custom interfaces, HUDs, item tooltips, factions, teleporters, popup messages, and NPC model presentations without rebuilding the mod for every content ch

ange.

## Main Features

- Visual editors for dialogues, shops, quests, currencies, stats, items, factions, teleporters, and Remnant Messages
- GUI Maker for custom dialogue, shop, and message screens
- HUD Maker with bars, text, images, item slots, and player head components
- Tooltip Maker with text, stats, images, dividers, scrolling, and 2D or 3D item previews
- CustomNPCs integration for NPC dialogue, shops, stat screens, models, and creator workflows
- Conditions and actions for branching conversations, rewards, commands, shops, quests, and scripted content
- Server-managed JSON content under `config/dochi_rpg_maker`
- In-game editing with reusable protected templates and `Save As` workflows
