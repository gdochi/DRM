## 첫 씬 만들기

Scene Maker는 카메라 이동과 화면 효과를 배치하는 제작 도구입니다. 플레이어에게는 편집용 타임라인이 아니라 저장한 연출 장면이 재생됩니다.

1. DRM 에디터 선택 화면에서 **Scene Maker**를 엽니다.
2. 씬 이름과 길이를 정합니다. 플레이어를 기준으로 연출하려면 **Player**, 월드의 정해진 장소를 쓰려면 **Fixed Position**을 선택합니다. 필요에 따라 디멘션과 기준점을 정합니다. NPC 기준 위치는 제공하지 않습니다.
3. 카메라와 필요한 자막·이미지·소리·페이드·레터박스·흔들림·이벤트를 추가합니다.
4. 카드를 선택해 속성을 바꾸고 **Apply Fields**로 반영합니다. 카드 우클릭으로 분할·삭제 등의 작업을 찾을 수 있습니다. 일부 종류는 분할할 수 없습니다.
5. **World positions**에서 카메라 위치와 이동 경로를 배치합니다.
6. **Play**로 미리 보고 **Save As**로 자신의 씬을 저장합니다. **Run Saved**는 저장된 내용을 재생하므로 수정 후에는 다시 저장하세요.

## 타임라인 보기

빨간 핀은 재생 위치입니다. 직접 잡아 끌 때 재생 위치가 바뀌며, 카드를 선택하는 것만으로는 움직이지 않습니다. 아래 가로 스크롤바는 보고 있는 시간 구간만 옮깁니다. 긴 씬은 이 스크롤바로 살펴보고, −/＋로 배율을 조절하세요. 반복 미리보기는 Loop 스위치로 켭니다.

## 월드에서 핀 옮기기

| 조작 | 하는 일 |
| --- | --- |
| WASD / Space / Shift | 작업 카메라 이동 |
| 빈 곳에서 우클릭 드래그 | 둘러보기 |
| 마우스 휠 | 이동 속도 조절 |
| Ctrl + 휠 | 시야각 조절 |
| 핀 좌클릭 | 해당 위치를 선택만 하기 |
| 핀을 좌클릭한 채 드래그 | 화면 기준으로 핀 옮기기 |
| 드래그 후 마우스 놓기 | 이동 확정 |
| 드래그 중 Esc 또는 우클릭 | 지금 끌던 이동 취소 |
| 핀 우클릭 | 위치 편집 메뉴 열기 |
| 연결선 우클릭 | 경로 편집 메뉴 열기 |
| P / Mark position | 선택한 핀을 작업 카메라 위치에 찍기 |
| N / New point | 현재 카메라 위치에 다음 지점 추가하기 |
| Ctrl + Z | 이 창에서 완료한 편집 되돌리기 |
| Apply | 배치한 위치를 씬에 반영하고 돌아가기 |
| Cancel | 이 창의 변경을 반영하지 않고 돌아가기 |

핀을 끌 때는 화면에서 보이는 좌우·상하 방향으로 이동하며, 처음 잡았을 때의 깊이는 유지됩니다. 다른 방향으로 옮기고 싶다면 놓은 뒤 작업 카메라를 돌리거나 이동해서 다시 잡으세요. 클릭할 때 조금 흔들린 정도로는 핀이 움직이지 않습니다. 드래그 중 작업 카메라는 고정되며, 아직 불러오지 않은 월드 구간에는 핀을 놓을 수 없습니다.

**Move camera here (TP)**는 작업 카메라를 핀 위치로 보내고, **Move point to camera**는 핀을 현재 작업 카메라 위치로 가져옵니다. **Walk in world**에서는 플레이어로 직접 움직이며 위치를 찍을 수 있습니다. 복귀 방법은 화면 안내를 따르세요.

## 곡선 만들기

연결선을 우클릭하거나 핀 메뉴에서 **Edit outgoing path**를 선택합니다. 직선·부드러운 경로를 고르고, 중간 지점을 추가하거나 현재 카메라 위치에 꺾이는 지점을 넣으세요. 추가한 핀을 옮겨 곡선 모양을 다듬을 수 있습니다. 화면의 선은 실제 카메라 재생 경로를 보여 줍니다.

Orbit 방식은 거리와 각도로 돌아가는 경로를 정합니다. Orbit 핀 이동은 전체가 공유하는 회전 거리를 바꿀 수 있습니다. 직선·곡선 편집은 일반 카메라 경로에서 사용합니다.

## 저장한 씬 재생하기

관리자 권한으로 아래 명령어를 사용합니다.

```text
/drm scene
/drm scene <씬파일>
/drm scene <씬파일> play @a
/drm scene <씬파일> stop @a
```

`/drm scene ` 다음에 나오는 추천 목록에서 저장한 씬을 고르세요. `<씬파일>`은 실제 이름으로 바꾸며 꺾쇠까지 입력하지 않습니다. 두 번째는 자신에게 재생, 세 번째는 선택한 플레이어들에게 재생, 네 번째는 해당 플레이어들의 그 씬을 중지합니다.

목록에 없다면 먼저 저장 여부, 기준 위치와 연결된 자료를 확인하세요. 월드 위치 창의 Apply는 편집 내용에 반영하는 단계입니다. 나중에도 재생하려면 돌아온 뒤 씬 파일을 저장해야 합니다.
