## 설정 화면 위치

이 기능들은 제작자 설정이며 플레이어용 런타임 화면이 아닙니다.

* `TACZ NPC Core`로 NPC를 엽니다.
* 전투·인식 설정에서 `Suppressive Fire`와 `Faction Defense`를 설정합니다.
* 별도 `Cover` 카테고리에서 전략 엄폐를 설정합니다.

0.2.2의 엄폐는 실험적 기능입니다. 서버 전역 스위치와 NPC별 스위치가 모두 켜져야 합니다.

```toml
[experimentalCover]
enabled = true
```

```text
Cover > Enable Cover: ON
```

엄폐는 NPC가 `COMBAT` 페이즈일 때만 시작할 수 있습니다. 평시 순찰, 용병 진형 이동, 일반 타겟 획득을 대신하지 않습니다.

## 엄폐 트리거

각 트리거는 NPC별로 따로 켭니다.

| 트리거 | 엄폐를 시작할 수 있는 조건 |
| --- | --- |
| `On Reload` | 관리 중인 재장전이 활성이고 `Reload Left (ms)` 이상의 시간이 남아 있습니다. |
| `On Damage` | 한 번의 실제 최종 피해가 최대 체력 대비 `Damage Ratio` 이상입니다. |
| `On Low Health` | 체력이 `Low Health Ratio` 아래로 내려갑니다. 계속 반복되는 엄폐가 아니라 임계값 반응입니다. |
| `On Repeated Hits` | `Damage Window (ms)` 안에서 충분한 피해 피격 묶음이 발생합니다. |
| `On Grenade Threat` | 주변의 지원되는 LR Tactical 파편 수류탄이 착지했거나, 공중에 있는 파편 수류탄의 신관이 곧 끝납니다. |

연막탄과 섬광탄은 파편 수류탄 엄폐를 발동하지 않습니다. 수류탄 엄폐는 현재 전투 타겟을 유지하면서 폭발 지점을 위협 방향으로 사용합니다.

## 탐색, 이동, 시간 설정

| 설정 | 실제 용도 |
| --- | --- |
| `Search Radius` | 수평 엄폐 탐색 반경입니다. 저장 범위는 3-12블록이며 탐색 작업량에는 내부 한도가 있습니다. |
| `Cover Move Speed` | 엄폐 진입, 피킹, 복귀 중에만 사용하는 CustomNPCs 이동 속도입니다. |
| `Hold Time (ms)` | 피해·반복 피격 엄폐의 최소 대기 시간입니다. |
| `Low-HP Hold (ms)` | 낮은 체력 엄폐에 따로 적용되는 최소 대기 시간입니다. |
| `Cooldown (ms)` | 다음 엄폐 행동을 시작할 수 있을 때까지의 지연입니다. |
| `Max Duration (ms)` | 한 번의 엄폐 행동에 적용되는 강제 종료 시간입니다. |
| `Peek After Cover` | 대기 후 기하 검사를 통과한 사격 측면으로 이동합니다. |
| `Max Peek Cycles` | 엄폐 한 번에서 허용할 피킹 이동 횟수이며 0-4입니다. |

엄폐 탐색은 제한된 후보 지형과 일반 NPC 길찾기를 검사합니다. 0.2.2는 외부에서 엄폐 경로가 지워져도 고정된 중단 횟수만으로 실패시키지 않고 다시 경로를 얻을 수 있습니다. 이동 진행도와 페이즈 제한 시간은 계속 최종 실패 기준으로 사용됩니다.

엄폐 이동은 별도 재장전 애니메이션을 만들지 않습니다. 재장전은 TACZ의 실제 총기 스택과 재장전 상태로 계속 처리되며 NPC에게 실제 탄약이나 탄창 아이템을 장착하지 않습니다.

## 실제 동작 흐름

일반적인 엄폐 행동은 아래 순서로 진행됩니다.

1. 전투 중 설정된 트리거가 유효해집니다.
2. 서버가 현재 위협 방향을 기준으로 제한된 반경 안의 도달 가능한 단단한 엄폐물을 찾습니다.
3. NPC가 `Cover Move Speed`로 엄폐 지점에 들어갑니다.
4. 트리거별 최소 시간 동안 대기하며 `Max Duration` 제한도 계속 계산됩니다.
5. 피킹이 켜져 있고 지형이 유효하면 시야가 나오는 사격 측면으로 이동합니다.
6. 페이즈가 끝나거나, 경로가 실패하거나, `Max Duration`이 지나면 일반 전투로 돌아가거나 안전하게 중단합니다.

항상 유효한 엄폐 지점이 나오는 것은 아닙니다. 열린 지형, 막힌 방, 안전하지 않은 발판, 너무 작은 반경, NPC가 통과할 수 없는 경로에서는 엄폐가 시작되지 않는 것이 정상일 수 있습니다.

## 제압 사격

`Suppressive Fire`는 마지막으로 본 위치를 사용하는 정책이며 숨은 타겟 추적이 아닙니다.

* NPC가 전투 중 타겟을 실제로 본 적이 있어야 합니다.
* 마지막으로 보인 위치에 실제 TACZ 탄환을 발사합니다.
* `Suppression Time Ms` 동안만 허용됩니다.
* 숨은 타겟의 현재 위치로 조준점을 갱신하지 않습니다.
* 최종 발사, 탄약 재고, 총기 모드, 재장전, 사선 규칙은 그대로 적용됩니다.

처음에는 짧은 기본 시간으로 테스트하세요. 제압 시간을 길게 두면 유한 탄약을 빠르게 낭비하고 숨은 타겟을 계속 추적하는 것처럼 보일 수 있습니다.

## 팩션 방어

`Faction Defense`를 켜면 피해를 받은 TACZ Fire NPC가 `Faction Alert Radius` 안의 같은 팩션 TACZ Fire 아군에게 공격자를 알립니다. 수직 공유 거리에는 제한이 있으며, 지원 NPC도 발사 직전에는 최종 시야가 필요합니다.

이 지원 동작은 우호 공격 규칙을 전부 무시하지 않습니다.

* 명시적 선택 규칙과 태그 규칙이 계속 적용됩니다.
* 수동적이거나 관계없는 엔티티는 타겟이 되지 않습니다.
* 용병 소유자 보호와 소유자 공격 허용 횟수가 계속 적용됩니다.
* 같은 팩션 보복에는 실제 적대 관계 또는 서버가 짧게 허용한 반응 권한이 필요합니다.

## 권장 조정 순서

1. 열린 지형에서 일반 `Ranged` 또는 `Auto` 전투를 확인합니다.
2. 엄폐 없이 이동과 재장전을 확인합니다.
3. 먼저 `On Reload` 같은 트리거 하나만 켭니다.
4. `Search Radius`를 작게 두고 도달 가능한 단단한 벽이 있는지 확인합니다.
5. 대기 시간과 쿨다운을 조정합니다.
6. 진입·복귀 경로가 작동한 뒤 피킹을 추가합니다.
7. 피해, 반복 피격, 낮은 체력, 수류탄 트리거를 하나씩 추가합니다.
8. 효과를 구분할 수 있도록 제압 사격과 팩션 방어를 마지막에 추가합니다.

엄폐가 실패하면 NPC 하나, 타겟 하나, 트리거 하나, 단순한 벽 하나로 먼저 테스트하세요. 엄폐 지형 문제를 타겟, 진형, 순찰, 탄약 문제와 분리할 수 있습니다.
