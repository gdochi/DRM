## 라운드별 전투 두뇌

Trainer의 `Battle Strategy`는 현재 라운드에 저장됩니다. 라운드를 복제하면 AI 설정도 함께 복제되고, 다른 라운드로 이동하면 해당 라운드의 설정을 편집합니다.

| Engine | 동작 범위 | 선택 모드 |
| --- | --- | --- |
| `DRM Strategy` | 기술·교체 평가, 전략 계획, Trainer Items, 기믹 | 없음 |
| `RCT` | RCT API의 기술·교체 판단 | RCT API 0.15.1-beta+ |
| `Cobblemon Strong` | Cobblemon의 강한 기본 AI | 없음 |

RCT 또는 Cobblemon Strong 엔진은 DRM 전략 계획, DRM Trainer Items, DRM 기믹 정책을 사용하지 않습니다. 이 세 기능이 필요하면 `DRM Strategy`를 선택하세요.

RCT API가 없거나 호출할 수 없으면 서버는 안전한 AI로 대체하고 로그와 사용자 메시지에 이유를 남깁니다. 선택 모드를 설치하지 않은 서버에서 RCT 엔진을 기본값으로 배포하지 마세요.

## DRM Strategy 설정

0.1.4의 DRM AI는 몇 단계짜리 성향 선택 대신 다음 여섯 값을 각각 0–100으로 조절합니다.

| 값 | 높일 때 달라지는 점 |
| --- | --- |
| 판단력 | 후보를 더 정밀하게 비교하고 좋은 행동을 놓칠 가능성이 줄어듭니다. |
| 배틀 지식 | 피해량과 상대 정보를 더 정확하게 판단합니다. |
| 공격 성향 | 공격 기술과 빠른 마무리를 더 선호합니다. |
| 방어 성향 | 회복, 방어, 장막과 생존 운영을 더 선호합니다. |
| 변칙 성향 | 상태 이상, 랭크 변화, 설치기와 교란 기술을 더 선호합니다. |
| 교체 성향 | 상성과 전황에 따른 자발적 교체를 더 적극적으로 검토합니다. |

`초보`, `표준`, `숙련`, `보스` 빠른 설정으로 시작한 뒤 각 값을 다시 바꿀 수 있습니다. 기존 문서의 AI Skill, Temperament, Knowledge는 가까운 새 값으로 자동 변환됩니다.

화면의 `AI 배틀 프로필`은 현재 설정을 난이도, 정보 활용, 성향, 교체 운용, 일관성으로 요약하고 강점·주의점·추천 조치를 보여 줍니다. 수치가 높다고 무조건 좋은 설정은 아닙니다. 예를 들어 교체 성향만 높고 배틀 지식이 낮으면 불필요한 교체가 늘 수 있습니다.

### Strategy Plan

DRM AI에는 18개의 전략 모듈이 있으며 검색형 도움말에서 목적과 조건을 확인할 수 있습니다. 파티 분석 결과에 맞춰 기술 사용과 교체 점수를 계산하므로, 단순히 모듈을 많이 켜는 것보다 파티 역할에 맞는 소수의 계획을 선택하는 편이 예측하기 쉽습니다.

AI가 사용할 수 없는 행동을 골라도 배틀을 멈추거나 턴을 헛되이 넘기지 않고 서버 기본 행동으로 이어갑니다. 복잡한 파티에서는 한 번에 비교할 후보 수를 조절해 판단이 지나치게 길어지지 않도록 했습니다.

## 랜덤 파티 생성기

`Random Party`는 현재 라운드의 생성 프로필을 저장하고 파티를 만듭니다.

| 그룹 | 설정 |
| --- | --- |
| 크기·레벨 | 파티 1–6마리, 레벨 1–100 |
| 도감 범위 | 1–9세대, 타입 다중 선택 |
| 진화 단계 | Any, Base, Middle, Final |
| 희귀도 | Legendary, Mythical 허용 여부 |
| 중복 | 같은 종 중복 허용 여부 |
| Shiny | 확률 |
| IV | Random 또는 Perfect |
| EV | None, Balanced, Physical, Special |
| 자동 설정 | Nature, Ability, Moves |
| 재현성 | Fixed Seed |

현재 설치된 Cobblemon 레지스트리에서 조건을 만족하는 후보를 찾습니다. 필터를 너무 좁혀 목표 파티 수를 만들 수 없으면 일부 슬롯이 비거나 생성이 거부될 수 있습니다. 타입·세대·진화 단계 필터를 하나씩 풀어 확인하세요.

`Fixed Seed`는 같은 모드·데이터팩·레지스트리 구성에서 재현 가능한 구성을 만들 때 사용합니다. 모드팩의 포켓몬 목록이 바뀌면 같은 시드라도 결과가 달라질 수 있습니다.

## RCT 데이터팩 포터

RCT API가 설치되어 있으면 `General`의 RCT 포터에서 활성 데이터팩의 `rctmod/trainers` JSON을 검색해 여러 파일을 선택할 수 있습니다. 0.1.4에서는 검색어와 페이지 이동으로 큰 데이터팩 목록을 나눠 볼 수 있으며, 같은 스캔 결과를 다시 열 때 재사용합니다.

- 최대 512개 항목을 표시합니다.
- 출력 폴더는 `config/dochi_rpg_maker/cobblemon/trainers/radical_ported/`입니다.
- 선택한 같은 이름의 출력 파일만 덮어씁니다.
- 원본 RCT 데이터팩 파일은 수정하지 않습니다.
- 변환 뒤 DRM Editor에서 파티, AI, 조건과 기믹을 다시 검토합니다.

포터는 형식 변환 도구이며 모든 RCT 전용 스크립트 동작을 복제하는 도구가 아닙니다.

## General Inventory

Trainer 전체에서 공유하는 최대 64종의 등록 아이템입니다. 키 아이템은 보유 조건으로 사용되며 소비되지 않습니다.

Mega Showdown 기본 키 아이템:

| 기믹 | 기본 아이템 ID |
| --- | --- |
| Mega | `mega_showdown:mega_bracelet` |
| Dynamax | `mega_showdown:dynamax_band` |
| Z-Move | `mega_showdown:z_ring` |
| Tera | `mega_showdown:tera_orb` |
| Omni | `mega_showdown:omni_ring` |

서버팩이 아이템 태그나 ID를 바꿨다면 현재 Mega Showdown 설정을 기준으로 확인하세요.

## Trainer Items

라운드별 가상 배틀 가방입니다.

- 최대 16종
- 종류당 수량 1–99
- 실제 NPC 인벤토리에서 꺼내지 않음
- 배틀마다 새로 생성되고 전투 종료 뒤 초기화
- DRM Strategy 엔진에서만 사용

지원 역할은 회복, 상태 치료, 기절 회복, PP 전체 회복, 능력치 강화입니다.

`아이템 빠른 설정`은 `아이템 사용 안 함`, `아껴 쓰기`, `일찍 쓰기`, `직접 설정`을 제공합니다. 빠른 설정을 고른 뒤에도 다음 값을 따로 바꿀 수 있습니다.

| 설정 | 범위와 의미 |
| --- | --- |
| 아이템을 더 자주 쓰기 | 0–100. 0이면 사용하지 않고, 높을수록 기술·교체보다 아이템을 더 자주 검토합니다. |
| 이 HP 아래에서 회복 | 0–100%. 현재 HP가 기준보다 낮을 때만 회복 아이템을 검토합니다. |
| 이 턴까지 강화 아이템 사용 | 0–10. 0이면 강화 아이템을 사용하지 않습니다. |
| 기절 회복 아이템 쓰기 | Revive 계열 허용 여부 |
| 상태 회복 아이템 쓰기 | 독·잠듦·마비 등 상태 치료 허용 여부 |
| PP 회복 아이템 쓰기 | PP가 줄어든 기술이 있을 때 회복 허용 여부 |

AI는 현재 HP, 상태, 남은 파티와 아이템 가치를 함께 평가합니다. “아이템을 넣었으니 반드시 첫 턴에 사용한다”는 의미가 아닙니다. 한 기술을 직접 지정해야 하는 Ether류처럼 목표 기술 선택이 필요한 아이템은 자동으로 사용하지 않습니다.

## Trainer Gimmick

라운드별 종류:

- `None`
- `Mega`
- `Dynamax`
- `Z-Move`
- `Tera`
- `Omni`

정책은 `Disabled`, `Ace Only`, `Smart`입니다. DRM Strategy가 일반 인벤토리의 키 아이템, 파티 상태, 현재 전투를 보고 실행 시점을 정합니다.

포켓몬별 준비도 함께 필요합니다.

- Mega/Z-Move: 알맞은 지닌 도구
- Tera: `Tera Type`
- Dynamax: `Dynamax Level`
- Gigantamax: `Gigantamax Factor`

기믹 데이터만 저장해도 Mega Showdown이 없는 서버에서 기능이 생기지는 않습니다. 서버와 클라이언트에 호환 버전을 설치하고 실제 배틀에서 각 기믹을 시험하세요.

## 권장 난이도 제작 순서

1. `표준` 빠른 설정과 기본 파티로 AI 동작을 확인합니다.
2. 여섯 능력치 중 한두 개와 전략 계획 하나만 바꿔 기술·교체 변화를 봅니다.
3. 회복 아이템 한 종류를 넣고 사용 시점을 확인합니다.
4. 마지막으로 키 아이템과 포켓몬별 기믹 값을 추가합니다.
5. RCT 또는 Cobblemon Strong과 비교할 때는 같은 파티·레벨·배틀 설정을 사용합니다.
