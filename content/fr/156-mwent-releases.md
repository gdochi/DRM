MWENT utilise les numéros de version de Minigames. Choisissez une version pour consulter ses ajouts, comparaisons et caractéristiques des cartes.
## Modifications des cartes par version
| Version | Modifications des cartes |
| --- | --- |
| [0.1.6](#mwent/version-0-1-6) | 72 nouvelles cartes : 60 de faction et 12 de siège. Caractéristiques et cinq tactiques d’ouverture. |
| 0.1.4 | Aucune définition de carte ajoutée, supprimée ou modifiée dans le catalogue publié pour Fabric 1.21.1 par rapport à 0.1.3. |
| 0.1.3 | Aucune définition de carte ajoutée, supprimée ou modifiée dans le catalogue publié pour Fabric 1.21.1 par rapport à 0.1.2. |
| [0.1.2](#mwent/version-0-1-2) | Aucun ajout ni changement d’équilibrage par rapport à 0.1.1 dans les catalogues publiés pour Fabric 1.21.1. |
| [0.1.1](#mwent/version-0-1-1) | Début public : 263 définitions de base et 89 optionnelles, soit 352 au total, dans le catalogue publié pour Fabric 1.21.1. |
