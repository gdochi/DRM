# 문서 사이트 UI 개편 — 2026-11-01

## 반영 범위

- 상단 본문 검색: 현재 모드 또는 전체 모드, 항목별 미리보기와 해당 위치 이동, 한국어 별칭과 영문 UI 이름 검색, 키보드 이동.
- 개별 문서가 보이는 접이식 분류 목록과 모드 선택. 각 모드의 기본 진입점을 첫 사용법으로 지정.
- PC 우측 페이지 목차와 현재 항목 강조. 작은 화면에는 접이식 목차와 문서 목록을 제공.
- 이전·다음 문서와 페이지 수를 본문 하단에 함께 배치.
- 인게임 원본 이미지를 문서 안에서 확대·이동. 원본 크기, 전체 보기, 마우스 끌기, 터치 확대·이동, 원본 링크, 닫은 뒤 위치와 초점 복귀.
- 목적별 홈 입구 6개와 모드별 용도 설명. 기존 배포 링크 유지.
- 문서 경로, 설명 기준 버전, 변경 기록 표시, 실제 수록 화면의 Minecraft·로더 정보 제공.
- 테마 변경·언어 메뉴 열기·번역 전환 시 읽기 위치 유지. 잘못된 주소는 문서 없음 화면으로 안내.
- MWENT 카드 목록에 이름·설명 필터 추가.

모드 소스와 배포 JAR는 수정하지 않았다. 캡처 환경은 `src/guide-environments.json`의 확인된 기록을 사용하며 지원 환경 전체를 뜻하지 않는다. 스크린샷 원본은 변경하지 않았다.

- `npm run build`: 한국어 186개, 영어 186개 문서 빌드.
- `npm run verify`: 372개 문서, 12개 모드, 이미지 706개 배치, 원본 이미지 일치, 문서 경로·배포 링크·첫 사용법 링크·캡처 크기 검증 통과.

- 검색 범위·결과 이동·키보드 조작, 테마·언어 전환 위치 유지, 이미지 원본 크기·드래그·터치 핀치·닫기, 잘못된 주소, 카드 필터 검증 통과.

재현 가능한 브라우저 검증은 `scripts/verify-reader-ui.mjs`에 있다. Playwright 경로는 `DOCHI_PLAYWRIGHT_MODULE`, Chrome 경로는 `DOCHI_CHROME`으로 지정할 수 있다. 로컬 최종 화면과 상세 결과는 `build/task/reader-ui/`에 보존한다.
