## Combat Rules의 구성

| 페이지 | 편집하는 내용 |
| --- | --- |
| Manager | 패턴 선택 점수 보정, 공통 쿨다운, 콤보 깊이와 회복 대기 |
| Combat | 기본 공격 억제, 타겟 탐색, 패턴 사이 추적과 시선, 전투 시작·종료 대기 |
| Phase | 체력 비율로 진입하는 페이즈와 전환 패턴 |
| Death | 사망 후 타임라인, 액션 실행 시점과 시체 이동 잠금 |
| Parry | 패링 관련 문서 설정. 아래 0.1.0 지원 범위를 확인하세요. |

패턴의 히트박스 피해와 CNPC 기본 공격을 동시에 사용하면 별도 피해가 겹칠 수 있습니다. Battleworks 패턴으로 공격을 구성할 때는 기본 공격 억제를 켜서 사용합니다.

## 공통 기능

선택 연동인 **Iron's Spells 'n Spellbooks**에는 지원되는 주문 투사체를 반사하는 연결이 있습니다. 모드가 없거나 지원 대상이 아닌 투사체에는 같은 결과를 보장하지 않습니다. 모든 모드의 모든 투사체에 적용되는 범용 패링으로 취급하지 마세요.

플레이어 락온과 히트박스 디버그 표시도 공통 전투 설정의 영향을 받습니다. 이 설정 파일은 `config/dochi_rpg_maker/settings/battleworks_global_rules.json`이며, 기본값은 마법 패링 켜짐, 락온 켜짐, 히트박스 디버그 꺼짐입니다. 히트박스 디버그 표시는 추가 공격 판정을 만들지 않습니다.

## 0.1.0의 패턴별 패링 제한

**Parry** 페이지의 입력 창, 체간, 리포스트 배율 같은 세부 값은 현재 문서에 저장되지만 Battleworks 패턴 런타임에 연결되어 있지 않습니다. 패턴의 `parryable`이나 체간 피해 값만 설정한다고 자동으로 체간 감소·근접 패링·리포스트 전투가 완성되지는 않습니다.

따라서 0.1.0 콘텐츠를 만들 때는 이 값을 전투 성립의 필수 조건으로 사용하지 마세요. 공통 주문 투사체 반사와 패턴별 체간 시스템은 별개의 범위입니다.

## 사망 연출

Death를 켜면 사망 시점부터 별도 타임라인의 액션을 실행할 수 있습니다. 길이 안에 실행 시점과 반복을 배치하고, 필요하면 수평 이동 잠금으로 시체가 미끄러지는 것을 막습니다. 피해를 발생시키는 액션이나 스킬을 연결했다면 일반 공격과 마찬가지로 대상·제공 모드 조건을 확인합니다.

## 콘텐츠 확인 순서

한 번의 공격, 추적, 여러 판정, 페이즈, 사망 연출 순으로 확인합니다. 패링 세부 항목에 앞서 공격 판정과 재사용 대기가 실제 서버에서 의도대로 실행되는지 확인하면 문제를 좁히기 쉽습니다.
