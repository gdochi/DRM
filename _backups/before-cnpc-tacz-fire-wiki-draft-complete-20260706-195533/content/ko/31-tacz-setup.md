## 기본 구성

| 항목 | 역할 |
| --- | --- |
| CustomNPCs | NPC 본체 |
| TaCZ | 총기 및 탄약 시스템 |
| CNPC TaCZ Fire | NPC 총기 사용 애드온 |
| 선택 모드 | TACZ Magazines, Better Combat, 팩션/총기 관련 모드 |

## 첫 세팅 체크리스트

1. 테스트 NPC 한 개로 시작합니다.
2. 사용할 총기, 탄약, 사격 거리, 재장전 여부를 정합니다.
3. 타겟 필터가 필요한지 먼저 결정합니다.
4. 근접 fallback 무기가 필요한지도 확인합니다.

## 최소 검증 순서

- 총기 장착이 정상 표시되는지 확인
- 사격 애니메이션과 발사 빈도 확인
- 탄약 소진 시 재장전 확인
- 같은 팩션 또는 제외 대상에게 오발하지 않는지 확인
