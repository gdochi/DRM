## 언제 아이템이 떨어지나요?

Real Armor 0.1.5의 **갑옷 드롭 에디터 / Armor Drop Editor**에서 방어구마다 떨어질 아이템을 정합니다. NPC가 공격받아 **방어구 내구도가 실제로 줄었을 때** 판정하며, 방어구가 깨지는 마지막 공격도 한 번 판정합니다. NPC를 처치하지 않아도 아이템이 떨어집니다.

처음에는 등록된 규칙과 적용된 세트가 없습니다. [방어구 설정](#dochi-real-armor/dochi-real-armor-setup)에서 **Enable armor calculation**, 사용하는 NPC 연동, **Damage armor items**를 켜고 NPC에게 방어구를 입혀 주세요. DRM은 선택 사항이며, Real Armor만으로도 에디터를 엽니다.

## GUI로 첫 드롭 만들기

아래 예제는 **철 흉갑이 손상될 때 철 조각을 100% 확률로 1–3개** 떨어뜨리는 세트입니다.

1. 월드에 접속한 상태에서 Real Armor의 **Config → Armor Drop Editor**를 엽니다. DRM이 설치돼 있으면 공용 에디터 선택기의 **Armor Drop Editor**에서도 들어갑니다. 멀티플레이 편집은 권한 레벨 2 이상이 필요합니다.
2. **Create New**로 새 초안을 만듭니다. **Use Default**도 빈 초안으로 시작하고, **Load Existing**은 저장한 세트를 불러옵니다.
3. 왼쪽 **Armor rules → Add**를 누르고 아이템 선택기에서 **Iron Chestplate**를 검색·선택한 뒤 선택기의 **Apply**를 누릅니다.
4. 가운데 **Drop items → Add**에서 **Iron Nugget**을 검색·선택하고 선택기의 **Apply**를 누릅니다.
5. 오른쪽 **Drop** 탭에서 **Enable drop**을 켜고 **Drop chance (%)**를 **100**, **Minimum quantity**를 **1**, **Maximum quantity**를 **3**으로 정합니다. **Armor** 탭의 **Enable rule**도 켜 둡니다.
6. 상단 **Save As**에서 세트 이름을 **iron_salvage**로 정하고 **Save**를 누릅니다. 서버가 저장을 확인할 때까지 기다립니다.
7. 에디터의 **Apply**를 눌러 세트를 활성화합니다. 상단에 편집 중인 세트와 적용된 세트가 표시되는지 확인합니다.

![Real Armor의 실제 GUI에서 철 흉갑 규칙과 철 조각 드롭을 추가하고 확률·수량을 입력한 뒤 Save As와 Apply를 사용하는 영상.](assets/media/guides/armor-drops-015-20261108/armor-drop-editor.mp4 "Real Armor 0.1.5 / NeoForge 1.21.1의 GUI 설정 예제입니다. 아이템 선택기의 Apply로 선택을 확정하고, Save As → Save로 세트를 저장한 다음 에디터의 Apply로 월드에 적용합니다.")

아이템 선택기는 **All items**, 크리에이티브 분류, **Player inv**를 지원합니다. 이름·인챈트 등 데이터가 있는 아이템은 **Player inv**에서 선택하세요. 선택해도 인벤토리의 원본 아이템은 소모되거나 이동하지 않습니다. 선택기의 **Cancel**은 해당 선택을 취소합니다.

왼쪽은 방어구 규칙, 가운데 아래는 **Item / Chance / Quantity** 드롭 목록, 오른쪽은 선택한 항목의 설정입니다. 가운데 갑옷 거치대는 정적인 미리보기이며 월드에 아이템을 생성하지 않습니다.

## 확률과 수량 정하기

| 항목 | 동작 |
| --- | --- |
| Drop chance (%) | 아이템별 0–100% 확률. 0은 떨어지지 않고 100은 항상 성공 |
| Minimum / Maximum quantity | 성공 시 최소~최대 사이의 정수 수량을 같은 확률로 선택. 각각 1–64이며 최소 ≤ 최대 |
| Enable rule / Enable drop | 해당 방어구 규칙 전체 또는 드롭 항목 하나를 켜거나 끔 |
| Horizontal spread / Upward speed | 떨어지는 아이템의 수평 퍼짐과 위로 튀는 속도. 각각 0–2 |

드롭은 **각 항목을 독립적으로** 판정합니다. 철 조각 100%와 에메랄드 25%를 함께 넣으면 철 조각은 매번, 에메랄드는 별도의 25% 확률로 떨어집니다. 확률의 합을 100%로 맞출 필요가 없습니다. 방어구 하나에 최대 16개 드롭을 등록합니다.

한 번에 내구도가 여러 점 줄어도 손상된 방어구 한 개당 각 드롭을 한 번씩 판정합니다. 여러 방어구의 내구도가 실제로 줄었다면 각각 판정합니다. 생성된 아이템은 NPC의 해당 장비 부근에 떨어져 주울 수 있고, 아이템 고유의 최대 스택 수에 맞춰 나뉩니다.

## 저장·불러오기와 적용 구분하기

| 조작 | 결과 |
| --- | --- |
| Save / Save As | 이름 있는 세트를 저장. 현재 월드에 적용된 드롭 규칙은 유지 |
| Load / Load Existing | 저장한 세트를 편집 초안으로 열기. 자동 적용되지 않음 |
| Apply | 저장한 세트로 현재 월드의 활성 규칙 전체를 교체 |
| Unapply | 적용을 해제. 저장한 세트와 편집 초안은 유지 |

**한 월드에는 한 세트만 활성화됩니다.** 다른 세트를 적용하면 이전 세트와 합쳐지지 않습니다. 적용 중인 이름으로 다시 저장해도, **Apply를 다시 누르기 전에는 이전에 적용된 내용**이 계속 사용됩니다. 변경 표시가 남아 있으면 먼저 저장한 뒤 적용하세요.

활성 세트와 해제 상태는 서버를 재시작해도 유지됩니다. 권한 부족·잘못된 값·동시 편집 충돌·저장 실패가 나오면 기존 적용 규칙은 유지되므로, 상태 메시지를 확인하고 현재 서버 상태를 다시 불러와 수정합니다.

## 저장 위치와 점검

파일은 **현재 서버 월드**에 속합니다. 싱글플레이 예시:

```text
saves/<world>/serverconfig/dochi_real_armor/
  armor_drops.json
  armor_drop_presets/
    iron_salvage.json
```

전용 서버에서는 같은 구조가 서버 월드 폴더 안에 있습니다. 세트 이름은 영문자·숫자·밑줄·하이픈으로 1–64자를 사용합니다. 아이템 데이터의 저장 방식은 Minecraft 버전에 따라 다르므로, 다른 버전으로 옮길 때 데이터 호환성을 확인하세요.

| 증상 | 확인할 항목 |
| --- | --- |
| 저장했는데 아무것도 떨어지지 않음 | 에디터의 Apply와 적용된 세트 이름, 규칙·드롭 스위치, 실제 방어구 아이템을 확인 |
| 맞아도 드롭이 없음 | 내구도 소모가 켜져 있고 장비 내구도가 실제로 줄었는지 확인. 파괴 불가 장비와 방어를 무시하는 피해는 드롭 조건을 충족하지 않을 수 있음 |
| Apply를 누를 수 없음 | 초안을 먼저 저장하고 서버의 저장 확인을 기다림 |
| 편집이 읽기 전용임 | 월드 접속·OP 권한·서버 응답·서버의 세트 적용 기능 지원을 확인 |
| 미리보기에서 아이템이 안 나옴 | 미리보기는 정적인 표시. 실제 드롭은 서버에서 장비 내구도가 줄 때 생성 |

Curios 장신구는 별도의 내구도 처리를 사용합니다. 이 기능의 방어구 드롭 대상으로 간주하지 마세요.
