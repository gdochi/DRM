## GUI가 하는 일

GUI는 대화, 상점, HUD 같은 화면을 정의합니다. 실제 동작은 대화나 상점 런타임이 처리하고, GUI는 어디에 무엇을 보여줄지 결정합니다.

| 구성 | 설명 | 예 |
| --- | --- | --- |
| Canvas | 전체 화면 기준 정보입니다. | 이름, 타입, 배경 |
| Component | 화면에 배치되는 요소입니다. | 텍스트, 이미지, 버튼, 슬롯 |
| Runtime Path | 게임에서 찾을 리소스 경로입니다. | 리소스팩 이미지 |
| Layer | 앞뒤 순서입니다. | 배경 0, 버튼 10 |

## 제작 순서

1. GUI 타입을 먼저 정합니다.
2. 배경과 기준 해상도를 정합니다.
3. 텍스트, 이미지, 버튼, 슬롯을 배치합니다.
4. 선택지나 상품 목록처럼 런타임이 채우는 영역을 남깁니다.
5. Export 후 대화나 상점 JSON에서 연결합니다.

:::tip 추천
상점용 화면은 Dialogue GUI와 섞지 말고 Shop GUI 타입으로 따로 저장하세요.
:::
