#### Fabric 1.21.1

* Added Ctrl+S shortcuts to existing editor and configuration save actions.
* Added Fabric 1.21.1 support for NPC combat, editors, and DNPC integration.

* Fixed missing NPC reload animations after joining or returning to tracking range.
* Fixed NPC miniguns stopping after exhausting virtual ammunition.
