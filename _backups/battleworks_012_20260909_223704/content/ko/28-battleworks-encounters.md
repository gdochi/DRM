## 0.1.1 전투 제작 안내

### 스킬과 이동

스킬 목록의 모드 필터로 원하는 마법을 찾습니다. 스킬 액션 하나에는 마법 하나만 지정합니다. 연사 중 모션을 바꾸려면 발사별 액션을 나누고 서로 다른 모션을 선택합니다. 마법 자체의 재사용 대기시간도 고려하세요.

걷기는 길찾기를 사용합니다. 대시는 한 번 힘을 주어 이동하며 중력과 충돌의 영향을 받습니다. 텔레포트는 안전한 목적지가 있을 때 이동합니다. 추격·측면 이동·후퇴를 연결하되 근접 타격 순간과 긴 시전, 후딜에는 반격할 틈을 남깁니다.

### 확률과 패시브

액션의 **Chance (%)**에 숫자를 입력합니다. 비우거나 생략하면 100%입니다. 이벤트 확률은 묶음 전체에 적용되고 액션 확률은 각각 따로 계산됩니다. 대사와 소리를 함께 내보내려면 팝업 정의의 시작 사운드를 사용하세요.

패시브 패턴은 근거리 피해, 원거리 피해, 일반 피해 또는 체력 저하에 반응합니다. 확률·재사용 대기시간·전투당 한 번 여부와 다른 패턴 실행 중 처리 방식을 설정합니다.

### 대사와 BGM

Command 액션의 **Edit command / arguments**에서 명령을 편집합니다. `@npc`, `@target`, `{player}`, `{uuid}`를 사용할 수 있습니다. Popup Maker의 시작 사운드는 팝업이 표시될 때 받는 플레이어에게 직접 재생됩니다. 공유 팝업인 `combatv1.json`을 바꾸면 다른 사용처에도 적용됩니다.

**Combat Rules → BGM**에서 활성화하고 사운드와 볼륨을 선택합니다. 현재 플레이어 타겟에게 반복 재생하며 타겟을 잃으면 종료합니다. 보스 BGM이 활성화된 동안 마인크래프트 기본 음악은 멈추고, 종료 후 원래 음악 재생 정책으로 돌아갑니다. 게임의 음악 볼륨이 0이면 보스 BGM도 들리지 않습니다.

OGG 파일명 대신 등록된 사운드 ID를 사용하며, 해당 리소스팩이 플레이어에게 있어야 합니다.

### 적용

히트박스 피해량은 Hitbox Library에서 조정합니다. 마법 피해량은 해당 모드·마법 레벨·지원 옵션에 따라 달라집니다.

전투 JSON은 `config/dochi_rpg_maker/mobs/`에 저장합니다. 수정한 파일은 기존 NPC에 다시 적용해야 합니다. 별도로 제공되는 불·얼음·엘리멘탈·번개·Arkel 보스 파일과 음악·팝업 자료는 모드 업데이트만으로 자동 설치되지 않습니다.
