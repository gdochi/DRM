## First checks

| Symptom | Check |
| --- | --- |
| GUI does not open | JSON path, HTML file, permissions, logs |
| Image is missing | Runtime resource path and client resource pack |
| Choice is hidden | Conditions |
| Shop export fails | Required IDs, item values, prices |
