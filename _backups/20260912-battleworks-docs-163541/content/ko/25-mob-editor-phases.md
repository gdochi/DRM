## 실행 가능한 패턴 정하기

패턴을 선택하고 Core와 Score 속성에서 사용 조건과 선택 점수를 조정합니다. 사용 중지된 패턴이나 조건에 맞지 않는 패턴은 일반 선택 대상에서 제외됩니다.

| 조건 | 확인할 내용 |
| --- | --- |
| 거리와 높이 | 최소·최대 거리와 허용 높이 차이 |
| 체력 | NPC와 타겟의 최소·최대 체력 비율 |
| 페이즈 | 패턴을 사용할 최소·최대 페이즈 |
| 시야와 타겟 | 시야 필요 여부, 타겟 필수 여부 |
| 재사용 대기 | 해당 패턴의 쿨다운 |

체력 비율은 0~1 값입니다. 0.5는 최대 체력의 50%를 뜻합니다. 예를 들어 근접 공격의 최대 거리를 2.7로 정했다면 타겟이 그 안에 있어야 패턴을 시작합니다. 실제 히트박스 크기와 이 시작 조건은 별도로 맞춰야 합니다.

## 선택 점수와 전투 간격

**Combat Rules → Manager**에서 공통 선택 규칙을 편집합니다. 실행 가능한 후보는 우선순위와 점수, 선택 범위와 가중치에 따라 선택됩니다.

- 패턴 Score의 기본 점수와 선호 거리로 사용 빈도를 조절합니다.
- 같은 패턴·최근 패턴·같은 역할 반복에 대한 점수 배율을 조절합니다.
- 이동 패턴의 사용 시급도와 정지 패턴 연속 사용에 대한 배율을 조절합니다.
- 패턴별 쿨다운, 공통 쿨다운, 패턴 후 회복 대기는 별도 시간입니다.

점수를 높여도 거리나 페이즈 조건을 무시하지 않습니다. 시작 조건에 맞는 패턴이 하나도 없으면 재시도 대기 후 다시 검사하며, 추적 설정이 켜져 있으면 그 사이에도 접근합니다.

## 콤보

패턴의 Combo 속성에서 다음 패턴 ID, 연결 확률, 지연을 설정합니다. 콤보 깊이 상한은 Manager에서 정합니다. 후속 패턴도 실제로 존재하고 실행 조건을 만족해야 연결됩니다.

**Pattern Graph**는 패턴과 콤보 연결을 살펴보는 도구입니다. 임의의 스크립트 흐름을 모두 그래프로 표현하는 기능은 아닙니다.

## 체력 페이즈

**Combat Rules → Phase**에서 페이즈를 추가합니다.

| 예시 | Phase Index | Enter Health Ratio |
| --- | --- | --- |
| 시작 | 1 | 1.0 |
| 강화 | 2 | 0.6 |
| 최종 | 3 | 0.3 |

페이즈는 한 전투 안에서 도달한 가장 높은 번호를 유지합니다. NPC가 회복해도 이전 페이즈로 돌아가지 않습니다. `Transition Pattern`을 연결하면 해당 페이즈 진입 시 전환 패턴을 사용할 수 있습니다. 연결된 패턴의 타겟·거리·체력 조건도 확인합니다.

타겟을 잃은 상태가 Combat Reset Delay만큼 지속되면 전투 상태가 초기화됩니다. 현재 살아 있는 NPC의 체력은 바뀌지 않으므로 재전투 시 체력이 이미 낮다면 그에 맞는 페이즈에 다시 진입할 수 있습니다.
