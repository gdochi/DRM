## Global
### Added
* Added independent text boxes to the Dialogue GUI Editor for displaying NPC names and custom text. Supports multiple text boxes, duplication, and saving.
* Added an optional API for addon integration, allowing access to and creation of NPC clone templates from mods such as DNPC.
### Improved
* Improved keybind category sorting to keep Dochi's mod categories grouped together.
## Fabric 1.21.1 & 26.3
### Fixed
* Fixed an issue where Creative Tab search failed when used alongside mods such as Axiom.
* Fixed camera jitter when tracking moving entities or using previews in the Scene Maker.
## Fabric 1.21.1
### Added
* Added the ability to delete trainer battle records through the Admin menu (Cobble NPC integration).
* Added manual cleanup of battle records for despawned trainers.
## Fabric 1.21.1
### Fixed
* Fixed a crash when using NPC model animations without CNPC installed.
### Improved
* Improved Creative Tab integration by registering DRM tools directly under the DNPC and CNPC tabs.
