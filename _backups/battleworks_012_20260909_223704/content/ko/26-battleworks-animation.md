## 모델은 NPC Basic에서 설정

DRM의 **NPC Basic**에서 NPC 타입, 모델, 텍스처, 애니메이션 파일을 지정합니다. Battleworks는 그 NPC가 가진 애니메이션을 전투 패턴에서 선택합니다. 애니메이션 JSON을 NPC 전투 스펙으로 적용하지 않습니다.

| DRM NPC 타입 | 클립 목록의 출처 |
| --- | --- |
| 일반 NPC | Better Combat이 제공하는 일반 인간형 모션 목록 |
| Gecko NPC | 해당 NPC에 지정한 애니메이션 파일 안의 클립 |
| 모디드 엔티티 모델 | DRM 연동으로 노출된 해당 엔티티의 네이티브 애니메이션 |

모디드 엔티티라고 해서 모든 모드의 숨겨진 애니메이션을 자동 열거할 수 있는 것은 아닙니다. 사용 중인 DRM 연동이 노출하는 목록을 사용합니다. GeckoLib·Better Combat·Player Animator 등은 해당 표현을 사용하는 경우에만 필요한 선택 연동입니다. 선택 모드 없이도 히트박스 편집과 애니메이션 없는 패턴을 작성할 수 있습니다.

## Hitbox Library에서 재생

1. 히트박스를 선택하고 **Pattern:**에서 미리 볼 사용 위치를 고릅니다.
2. 모델 위 단계 선택에서 **Action** 등 클립을 지정할 단계를 고릅니다.
3. 모델 옆 **Clips** 목록에서 이름을 검색하고 클립을 선택합니다.
4. 모델 아래 **Play**를 누릅니다. **Stop**으로 중지하고 다시 Play하면 새로 시작합니다.
5. 타임라인에서 판정 시점과 모델 자세를 맞춥니다.

아직 어떤 패턴에도 연결하지 않은 히트박스도 클립 미리보기를 사용할 수 있습니다. 저장할 전투 타이밍은 패턴에 연결한 뒤 편집합니다.

## 애니메이션과 판정의 관계

히트박스는 판정 모양과 피해량을 정의합니다. 실제 전투와 에디터 미리보기의 애니메이션은 모두 DRM의 기존 재생 기능을 사용하며, `/drm playani`와 같은 재생 경로를 따릅니다.

첫 근접 공격은 **Action**에 클립을 지정하고 타격 시점을 모션에 맞추세요. 반복 타격마다 단계 애니메이션을 다시 시작하지 않습니다.

스킬 액션에는 개별 시전 모션을 지정할 수 있습니다. 시전에 성공하면 단계의 일회성 애니메이션과 별도로 지정한 모션을 시작합니다. 시전마다 모델에 맞는 다른 클립을 사용하고 다음 시전까지 모션이 진행될 시간을 확보하세요.

## 목록이 비거나 움직이지 않을 때

- NPC Basic의 모델 타입과 실제 사용하는 애니메이션 파일을 확인합니다.
- 모델 파일인 `.geo.json`과 클립을 담은 `.animation.json`을 구분합니다.
- 자산 로딩이 끝난 뒤 목록 옆 새로고침을 사용합니다.
- 선택 연동 모드가 설치되어 있고 현재 모델에 맞는지 확인합니다. Gecko 클립을 일반 NPC용 인간형 모션으로 대신 재생하지 않습니다.
- **Pattern:** 선택 창은 히트박스를 쓰는 패턴 목록입니다. 애니메이션은 모델 옆 Clips에서 고릅니다.
- Play는 에디터 미리보기입니다. 실제 NPC 공격을 바꾸려면 문서를 저장·적용한 후 전투에서 확인합니다.

모델 스냅샷이 있는 문서는 적용 시 DRM 모델 설정도 복원할 수 있습니다. 스냅샷이 없는 이전 문서와 Jar Fist 샘플은 대상 NPC의 기존 모델 설정을 유지합니다.
