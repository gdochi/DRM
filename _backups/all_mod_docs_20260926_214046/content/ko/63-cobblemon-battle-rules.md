## 어디서 편집하나요?

`Cobblemon Editor`에서 Trainer 또는 Pokemon Itself 문서를 연 뒤 `Rounds` 영역의 `배틀 룰 편집`을 누릅니다. 배틀 룰 화면은 제작자용 하위 에디터이며 독립 JSON을 저장하지 않습니다. `완료`로 돌아온 뒤 상위 Cobblemon Editor의 `Save` 또는 `Save As`로 Trainer/Pokemon Itself 문서를 저장해야 합니다.

화면 상단에는 DRM Core의 공유 Back/Forward 화살표가 항상 표시됩니다. 이동 기록이 없으면 숨지 않고 비활성화됩니다. 잘못된 숫자나 아이템 ID가 있으면 초안을 잃지 않도록 이동·완료를 막습니다.

## 공통 규칙과 라운드 규칙

왼쪽에서 `공통 규칙` 또는 1–16 라운드를 직접 선택합니다.

- 공통 규칙은 `공통 규칙 사용` 상태의 라운드에만 적용됩니다.
- 라운드를 개별 규칙으로 바꾸면 그 라운드의 전체 배틀 설정을 별도로 관리합니다.
- 다시 `공통 규칙 사용`을 선택하면 해당 라운드의 개별 덮어쓰기를 제거합니다.
- 한 라운드를 바꾸는 동작은 다른 개별 라운드를 덮어쓰지 않습니다.

## Battle setup

### 배틀 형식

| 형식 | 동작 |
| --- | --- |
| `상속` | Rounds의 기존 형식을 사용 |
| `Singles` | 양쪽 1마리씩 출전 |
| `Doubles` | 양쪽 2마리씩 출전 |
| `Triples` | 양쪽 3마리씩 출전 |
| `Lead Duel` | 선봉 한 마리로만 진행하는 Singles |

Doubles와 Triples는 양쪽에 전투 가능한 포켓몬이 필요한 수만큼 있어야 시작합니다. Lead Duel은 배틀용 임시 파티만 1마리로 제한하며 저장한 원본 파티를 삭제하지 않습니다.

Pokemon Itself는 상대가 한 마리이므로 Singles만 사용하며 트레이너 선봉 설정을 표시하지 않습니다.

### 레벨

| 모드 | 의미 |
| --- | --- |
| `원본 유지` | 문서에 저장한 레벨을 사용 |
| `플레이어 파티 평균` | 현재 플레이어 파티 평균에 -99–99 Offset을 더한 값으로 상대 파티 평균을 맞춤 |
| `고정` | 1–100 레벨로 전투용 포켓몬을 맞춤 |

고정 레벨은 Trainer만 바꾸거나 양쪽 배틀용 파티를 모두 맞출 수 있습니다. 플레이어의 원본 파티 레벨은 변경하지 않고 배틀용 임시 복사본에만 적용됩니다.

### 배틀 기믹 허용

Mega, Tera, Dynamax 허용은 플레이어와 NPC 양쪽의 서버 규칙입니다. 허용을 켰다고 기믹이 생기지는 않습니다. 실제 발동에는 호환 애드온, 라운드의 NPC 기믹 장비·키 아이템, 포켓몬의 지닌물건·속성 조건이 별도로 필요합니다.

`Trainer Gimmick`은 NPC의 장비이고, 배틀 룰은 양쪽에 적용되는 허용 정책입니다. 장비가 있어도 규칙에서 금지하면 NPC는 그 기믹을 선택하지 않습니다.

## Items

| 설정 | 동작 |
| --- | --- |
| 아이템 허용 | 끄면 배틀 중 규칙 대상 아이템 전체를 금지 |
| 금지 아이템 | 번역 이름 또는 레지스트리 ID로 검색해 개별 금지 |
| 사용 횟수 | 양쪽 사용 주체별 배틀당 0–999회, 또는 제한 없음 |
| 최소 턴 | 설정한 턴 이상에서만 사용 |
| 대상 HP 상한 | 대상의 현재 HP 비율이 설정값 이하일 때만 사용 |
| 지닌물건 허용 | 끄면 지닌물건이 있는 참가 포켓몬 때문에 배틀 시작을 거부 |

금지 목록은 최대 128개입니다. 우측 카탈로그에서 행을 누르면 즉시 금지 목록에 추가되고, 다시 누르거나 가운데 목록에서 해제하면 허용됩니다. 미설치 모드의 기존 ID도 아이콘 없는 항목으로 보존하므로 의도하지 않은 자동 삭제를 하지 않습니다.

배틀 가방 아이템, 부활, 포획 아이템은 소비 전에 서버가 다시 검사합니다. 포획 투척은 허용된 시도부터 횟수에 포함되며, 여러 상대가 활성 상태면 HP 조건을 모두 만족해야 합니다. Creative 플레이어도 횟수 제한을 따릅니다.

## Legendary Pokémon

전설 포켓몬 허용을 끄면 양쪽 참가 파티를 시작 전에 검사하고 전설 포켓몬이 있으면 배틀을 거부합니다. 판정은 Cobblemon의 `isLegendary()` 분류를 따릅니다. 환상 포켓몬 전체가 자동으로 포함되는 별도 규칙은 아닙니다.

## Leads

플레이어와 Trainer 선봉을 각각 선택합니다.

- `현재 선택`: 원래 선봉 선택을 유지
- `무작위`: 플레이어는 건강한 파티에서, Trainer는 생성된 파티에서 무작위 선택
- `슬롯 지정`: 1–6번 슬롯을 선봉으로 사용

존재하지 않는 슬롯, 기절한 플레이어 선봉, 형식에 필요한 인원 부족은 배틀 시작 전에 거부됩니다.

## Pokemon Itself의 Encounter 규칙

Pokemon Itself에서는 자연 드롭과 포획 허용을 같은 화면에서 편집합니다. 드롭을 끄면 애드온이 시작한 해당 전투의 자연 드롭을 허용하지 않습니다. 포획을 금지하면 배틀 룰의 아이템 허용 여부와 무관하게 해당 조우에서 포획할 수 없습니다.

## 문제 해결

| 증상 | 확인할 것 |
| --- | --- |
| 규칙이 바뀌지 않음 | `완료` 후 상위 에디터에서 `Save`했는지, 현재 라운드가 공통 규칙을 상속하는지 확인 |
| 배틀 시작이 거부됨 | Doubles/Triples 인원, 지정 선봉, 지닌물건, 전설 제한을 확인 |
| 기믹이 안 나옴 | 호환 애드온, NPC 기믹 장비, 일반 인벤토리 키 아이템, 포켓몬 속성/지닌물건, 배틀 룰을 모두 확인 |
| 아이템이 거부됨 | 전체 허용, 개별 금지, 횟수, 턴, 대상 HP 조건은 AND로 모두 만족해야 함 |

## JSON 참고

다음 필드는 직접 작성을 권장하는 절차가 아니라 외부 도구·버전 관리용 참고입니다. Trainer JSON 스키마 22의 공통 설정은 `trainerOptions.battleConfig`, 라운드 개별 설정은 `rounds[].battleConfigOverride`에 저장됩니다. 덮어쓰기가 없는 라운드는 공통 설정을 사용합니다.
