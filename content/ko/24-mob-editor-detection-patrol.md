## 탐지 로직 기준

탐지는 단순 거리 판정보다 **거리 + 각도 + 시야 상태**를 함께 봐야 합니다. 플레이어가 거의 붙어 있는데도 NPC가 인식하지 못한다면 먼저 Detect Angle과 전방 벡터 계산을 확인합니다.

| 항목 | 설명 | 점검 포인트 |
| --- | --- | --- |
| Detect Range | 탐지 거리 | 너무 짧거나 높이 차이를 무시하는지 확인 |
| Detect Angle | 전방 기준 탐지 각도 | 근접 플레이어가 각도 밖으로 빠지는지 확인 |
| Line of Sight | 시야 차단 | 블록, 높이, 투명 블록 처리 확인 |
| Alert State | 전투 전환 상태 | 이미 다른 상태에 잠겨 있는지 확인 |

## 순찰 이동 원칙

순찰 중인 NPC는 벡터로 끌려가는 것처럼 보여서는 안 됩니다. 이동은 실제 걷기 상태와 연결되어야 하며, 애니메이션도 이동 속도와 일치해야 합니다.

1. 경로 목표점을 정합니다.
2. 이동 벡터를 계산합니다.
3. NPC 회전을 이동 방향으로 맞춥니다.
4. 걷기 애니메이션을 재생합니다.
5. 목표점 도착 시 대기/경계 상태로 전환합니다.

## 원형 감시와 이동 방향

원형 감시는 **제자리 경계 상태에서만** 사용합니다. NPC가 이동 순찰 중이면 항상 이동 방향을 바라봐야 합니다.

:::warning 주의
이동 중 원형 감시가 동시에 작동하면 회전값을 서로 덮어쓰면서 NPC가 옆이나 뒤를 보는 문제가 생길 수 있습니다.
:::
