## 현재 워크스페이스 기준

2026-10-30 독립 Minecraft 26.3 / Fabric·NeoForge 소스와 0.1.5 배포 JAR을 기준으로 작성했습니다. 과거 공개 이력은 [CurseForge 버전 목록](#mwent/releases)과 구분합니다.

기본 정의는 **263 → 335종**, 선택 모드 정의는 **89종 유지**, 합계는 **352 → 424종**입니다. 일반판·애니메이티드판은 총 848개입니다. 기존 카드의 전력·편성 비용·프레임·희귀도·기존 배치·명령·키워드는 유지하며 신규 ID 1700~1759, 1800~1811을 추가했습니다.

## 추가 규칙

- 시나리오는 조건에 맞는 카드 사용으로 장을 진행하고, 장소는 지속 명령을, 함정은 숨겨진 반응을 제공합니다. 이 카드는 소켓을 쓰지만 유닛 점수를 더하지 않습니다.
- 장막·면역·파열·주입, 한 라운드 유지, 계수·타이머와 라운드 진화를 지원합니다.
- 생성 후보 선택, 덱·묘지에서 사용, 회수·재사용, 손패·덱 강화, 기본 전력 변경, 결투·격돌, 유언·배치 재발동을 지원합니다.
- 시작 덱·손패·최고 전력·상위 3장 전력·보급 소비 등 조건, 선택 비용, 선공 보너스 4종을 제공합니다.
- 사용자 카드 제작기는 위 능력과 조건·대상·작동·비용을 편집합니다. 저장만으로 카드를 지급하지 않습니다.

각 진영에 10종씩 추가합니다. 아래는 실제 저장 정의의 전력·비용과 능력 요약입니다.

모바일에서는 표 안을 좌우로 스크롤해 능력 열까지 확인하세요.
