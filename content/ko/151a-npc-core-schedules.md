## 낮에는 일하고 밤에는 쉬게 하기

1. NPC 편집기의 **데이사이클**을 엽니다.
2. 시간대를 추가하고 ‘낮 근무’처럼 이름을 씁니다.
3. 시작·종료 시각을 입력하고 할 일을 고릅니다.
4. 시간대 옆 **✓**로 내용을 반영합니다.
5. 밤 시간대를 하나 더 만들어 **Rest / Bed**를 고르고 쉴 곳이나 침대를 지정합니다.
6. **스케줄 활성화**를 켜고 NPC를 저장합니다.

| 하루 시각 | 입력할 틱 |
| --- | --- |
| 오전 6시 | 0 |
| 낮 12시 | 6000 |
| 저녁 6시 | 12000 |
| 밤 12시 | 18000 |

액션 추가 목록에서는 ‘벌목’, ‘운반’, ‘탑승’처럼 검색할 수 있습니다. 분류와 검색을 함께 사용합니다.

## 예시 시간표 불러오기

**스케줄 불러오기**에서 원하는 예시를 고른 뒤 장소·대상만 내 월드에 맞게 바꿉니다. ‘일반/군용’과 ‘필요 애드온’ 필터로 찾습니다.

1.20.1·1.21.1에서는 DW 경비·순찰·호위 예시와 DWE 승무원 예시도 있습니다. DW는 Forge·NeoForge용이며, 차량 예시에는 DW·DWE·SuperbWarfare가 필요합니다. 사용할 수 없는 예시는 필요한 모드를 표시합니다. DW 군용 일정은 시간대마다 액션 하나를 사용합니다.

기존 NPC의 **이전 AI 호환 모드**는 예전 행동을 유지하는 선택입니다. 일반 시간표로 바꿀 때는 **스케줄 타입**과 활성화 스위치를 함께 확인합니다.

## 보트·말·차량에 태우기

1. 시간대의 액션을 **이동 → 탈것 탑승**으로 정합니다.
2. 주변 빈 탈것을 자동으로 찾게 하거나 🔍로 특정 탈것을 고릅니다.
3. 탐색 중심과 반경을 정합니다. 기본 반경은 16블록, 범위는 1~32블록입니다.
4. 좌석을 고릅니다. 일반 보트·수레·말은 **-1** 자동 선택으로 시작합니다.
5. **일정 종료 시 하차** 여부를 정하고 저장합니다.

NPC는 탈것까지 걸어가서 탑니다. 기본 시도 시간은 600틱이며 20~2400틱으로 바꿀 수 있습니다. 탈것이 멀거나 다른 차원에 있으면 탑승하지 않습니다.

기존 버전의 SuperbWarfare 차량은 실제 좌석 번호 0~63을 고를 수 있습니다. 26.3은 바닐라 탈것용이며 앞 승객 자리를 건너뛰지 않습니다. DW/DWE의 26.3 차량 기능은 제공하지 않습니다.

하차할 때는 탈것이 멈추고 안전한 자리가 생길 때까지 기다립니다. 운전 경로·순찰·무장은 DWE나 해당 탈것의 설정에서 정합니다.

## 영업 시간이 있는 상점

DRM 상점을 일정에 연결하면 정해진 시간에만 거래할 수 있습니다. 영업이 끝났다면 전에 열어 둔 상점 화면에서도 거래가 되지 않습니다.
