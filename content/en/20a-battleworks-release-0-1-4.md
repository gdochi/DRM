## The 0.1.4 record and current guidance

This page records the **0.1.4 authoring workflow**. The current checked BattleWorks version is 0.1.6; use [current setup](#mob-editor/mob-editor-setup) for files and NPC preparation. Do not carry the old CustomNPCs requirement into current DNPC setups.

![A first slash saved in current BattleWorks.](assets/media/guides/battleworks-016-neo1211/battleworks-first-saved.png "BattleWorks 0.1.6 / NeoForge 1.21.1, English UI. A current illustration of creating a pattern and saving a separate file, not an archived 0.1.4 capture.")

## Workflows carried forward

- Prepare NPC models and external textures in DRM NPC Basic, then use them in Hitbox Library and pattern previews.
- Add actions to selected Windup, Action or Recovery tracks. The skill picker lists supported skills from installed and registered providers.
- Preview checks movement, animation and hitboxes. Verify targeting, collision and external skills in a world fight.

Continue with [setup](#mob-editor/mob-editor-setup), [first attack](#mob-editor/battleworks-first-attack) and [skills/effects](#mob-editor/battleworks-skills-effects). Combat JSON remains `dochi.battleworks.v1`.
