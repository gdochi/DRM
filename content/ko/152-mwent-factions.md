## 진영 고르기

처음에는 덱 선택 화면에서 기본 덱 하나를 고르고 오른쪽 카드 구성을 살펴보세요. **Use this deck**을 누르면 카드 수량·리더·선공 전술을 조정하는 편성 화면으로 넘어갑니다. 덱 이름만 보고 고르기 어렵다면 아래 표에서 원하는 행동을 찾은 뒤 그 진영의 기본 덱으로 시작하면 됩니다.

![아발린의 Companion Chorus 기본 덱과 진영·전략·모드 필터.](assets/media/guides/minigames-016-neo1211/mwent016-faction-select.png "Minigames 0.1.6 / NeoForge 1.21.1 영문 화면. 왼쪽 All factions로 진영을 좁히고 오른쪽에서 구성 카드를 확인합니다. 자물쇠가 있는 선택 모드 덱은 이 실행에 해당 모드가 없어 선택할 수 없습니다.")

한 덱은 선택한 진영과 중립 카드로 편성합니다. 기본 프리셋은 진영당 4개씩 총 24개이며, 각 진영에는 리더 능력 3개가 있습니다. 아래 연계는 0.1.1 업로드부터 포함된 기본 전략입니다. 0.1.5의 시나리오·장소·함정과 공성 카드는 [0.1.5 변경 내역](#mwent/version-0-1-5)을 확인하세요.

| 진영 | 주요 연계 | 상대할 때 |
| --- | --- | --- |
| 볼카르 제국 / Volkar Empire | 방어구를 두른 아군 사이에 명령 유닛을 배치합니다. 협동 진형·군수 보급·재정비로 명령을 반복하고 병기를 보호합니다. | 핵심 명령을 봉인하고 양옆 진형을 끊습니다. |
| 아발린 / Avalin | 서로 다른 부류를 직접 사용해 조화를 키우고, 공생을 준비한 뒤 자연 카드를 사용합니다. 치유·활력·보살핌·개화로 아군을 성장시킵니다. | 성장원을 일찍 제어하고 짧은 라운드로 압박합니다. |
| 네브라 / Nevra | 첩보원을 상대 전장의 빈 소켓에 배치하고 첩보·암호망·제어를 연결합니다. 상대 쪽에 둔 첩보원은 상대 점수가 됩니다. | 첩보 대상과 연계원을 정리하고 내 칸이 차는 상황을 관리합니다. |
| 해무 부족 / Mistwake Clans | 자해·부상·치유를 엮고 피의 갈증과 광폭 조건을 맞춥니다. 부활, 서리와 비를 활용하는 덱도 있습니다. | 치유 전에 제거하거나 묘지의 핵심 카드를 견제합니다. |
| 로덴 연맹 / Roden League | 교역·수송대로 보급을 벌고 유료 명령에 지출합니다. 현상금 회수와 비축으로 다음 행동을 준비합니다. | 수입원을 제거하고 비축 문턱 아래로 소비를 유도합니다. |
| 모르가 군락 / Morga Brood | 포식과 유언을 연결합니다. 유닛이 죽은 정확한 칸의 잔해를 수확하고, 인접한 빈 칸에서 군체를 부화시킵니다. | 유언을 봉인하고 필요한 잔해·빈 소켓의 연결을 끊습니다. |

## 점수와 별도로 관리하는 자원

로덴의 **보급은 0~9**입니다. 전력 점수에 합산하지 않으며, 다음 라운드에는 절반을 내림해 남깁니다. 전장 보급과 덱의 **편성 비용 한도**는 서로 다른 수치입니다.

모르가의 잔해는 점수를 주거나 소켓을 점유하는 유닛이 아닙니다. 실제 유닛의 파괴로 남으며 토큰은 잔해를 다시 만들지 않습니다. 라운드 정리 때는 잔해도 사라집니다.

아발린의 서로 다른 부류는 이름이 다른 카드를 뜻하지 않습니다. 같은 부류의 다른 이름 카드를 사용했다고 새로운 부류로 계산하지 않습니다. 볼카르의 인접은 같은 열의 바로 옆 **고정 소켓**을 뜻합니다.

## 첫 덱에서 확인할 것

성장원과 그 조건을 충족할 카드, 보급 생산과 지출, 부활과 묘지 대상처럼 서로 이어지는 카드를 함께 넣습니다. 명령 카드만 모으거나 조건을 충족할 수 없는 카드를 넣으면 숫자상 합법인 덱이라도 연계가 잘 나오지 않습니다.

리더를 바꾸면 사용할 수 있는 편성 비용 한도도 달라집니다. [카드·덱 안내](#mwent/cards-decks)와 [카드 스펙 목록](#mwent/card-catalog)에서 실제 수치와 연계를 확인하세요.
