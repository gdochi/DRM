# DWE 0.3.2 타임라인 튜토리얼 갱신

개편된 실제 월드 GUI에 맞춰 타임라인 안내를 세 페이지로 확장하고, 한국어·영어·포르투갈어·스페인어·프랑스어에 반영했다. 관련 설치·호환성·차량 AI·서버 정책 연결까지 총 45개 문서를 갱신했다.

## 문서와 영상

- 기존 경로 `expanded-support-timeline`은 유지한다. 화면·점·선·영역 폭격·시간·중심점을 다룬다.
- `expanded-support-actions`는 차량 증원·기총·NPC Area/Clone의 준비와 설정을 다룬다.
- `expanded-support-run`은 Save As·Load·실제 Simulation·명령 호출·문제 해결·JSON 참고를 다룬다.
- 영상은 10편, 총 **409.089초(6분 49초)**, **46개 단계**다. 세 튜토리얼과 서버 정책 연결에 언어별 11곳, 총 55곳 배치했다.
- 실제 1920×1080 프레임에 별도 180px 한국어 설명 영역을 붙여 1920×1260으로 제공한다. 게임 필드를 덮지 않는다. 클릭 포인터와 일부 속성 확대, 플레이어 바깥의 현재 단계 설명을 제공한다.
- MP4·WebM·PNG 포스터 각 10개는 `src/media/guides/dwe-tutorials-20261109/`에 있다. 원본 타임스탬프를 유지한 20fps, BT.709 제한 범위, 무음 영상이다.

## 실제 확인 범위

촬영은 DWE 0.3.2·DW 0.3.2·DRM 0.3.2·DNPC 0.1.4 / NeoForge 21.1.259 / Minecraft 1.21.1과 실제 TACZ 1.2.0·SuperbWarfare 0.8.9.1 배포 JAR로 수행했다. 모든 JAR 경로·해시는 실행별 `environment.json`에 있다. 촬영 버전을 최소 요구 버전으로 바꾸지 않았다.

촬영 도구가 제품 Screen의 클릭·드래그·문자 입력·스크롤·키 경로를 조작했다. 텍스트 필드 비우기는 위젯의 setValue를 사용한 뒤 charTyped로 입력한다. 수동 플레이 녹화로 표현하지 않으며 가짜 GUI·생성 이미지·보간 프레임을 사용하지 않았다. 도로와 기본 배우는 독립 촬영 월드에 미리 준비했다. 사용자 월드·런처·OBS는 변경하지 않았다.

작성 결과 JSON의 시각·수량·좌표·피해·수명과 본문 값을 대조했다. `tutorial_support`의 서버 디스크 JSON이 저장·재로드 문서와 일치한다. 차량 시뮬레이션은 160개 표본에서 임시 차량의 실제 이동 약 35.38블록, Stop 이후 임시 배우 0개, 관찰한 도로 블록 보존을 확인했다. 이 도로 관찰을 모든 블록·모든 외부 모드의 보호 검증으로 확대하지 않는다.

폭격·기총·NPC 영상은 작성 과정이다. 실제 폭격 명중·기총 피해·NPC 이동 완료를 보여 준다고 표현하지 않는다. 실제 플레이 확인은 차량 시뮬레이션에 한정한다. 다른 로더의 기존 검증은 DWE 소유 보고서와 구분하며, 이번에 세 로더를 새로 모두 실행했다고 주장하지 않는다.

## 구버전 안내 수정

- DWE는 0.3.2 기준으로 갱신하고 Fabric 1.21.1을 설치 안내에 포함했다.
- DW 필수 여부와 실제 API 호환성 검사를 설명하며 같은 DW/DWE 버전 번호를 요구하는 문구를 제거했다.
- 연결된 DW 설치 문서의 오래된 TACZ 1.2 미만 제한을 현재 배포 메타데이터와 맞췄다. Fabric의 TACZ Refabricated, Fabric API·Forge Config API Port, Player Animator 선택 여부를 구분했다.
- 예전 차량 팩 0.3.1 검증 이력·스크린샷의 실제 촬영 버전은 보존했다. 이를 0.3.2/Fabric의 모든 기종 재검증으로 바꾸지 않았다.
- 첫 투하와 명중, 초와 틱, 첫 실제 발사부터의 사격 시간, 수명, 상대 Load와 절대 위치 유지, 시뮬레이션과 실제 호출을 분리해 설명했다.

## 검증과 보존

- 빌드 920개 문서, 정적 검사 1,657개 이미지·240개 영상 배치, 번역 552개 통과.
- 새 영상 10개와 5개 언어의 PC·모바일 110개 배치에서 자동 재생·탐색·정지·반복 경계·MP4 대체·바이트 범위·동작 줄이기 검사 통과.
- 튜토리얼 세 경로의 최종 30개 언어/화면 배치와 이전·다음 이동, 영상 30개 자산 해시·빌드 바이트 일치 검사 통과. 새 영상 두 코덱은 전체 프레임 디코딩을 통과했다.
- 근거는 `docs/evidence/dwe-tutorials-20261109/`의 실행 환경·로그·원본 대표 프레임·전체 프레임별 해시·단계/확대 시각·인코딩 영수증·실제 JSON·서버 기록·브라우저 결과다.
- 채택은 workspace/files의 실행 02, 나머지 8편의 실행 03이다. 첫 실행의 샌드박스 로컬 통신 실패와 실행 02의 촬영 도구 숫자 입력 실패를 기록했다. 제품 코드 오류로 표현하지 않는다. 이미 완료된 workspace/files는 반복 촬영하지 않았다.
- 게임은 한 번에 하나, 힙 3GB 상한으로 실행했고 각 실행 종료 후 다음 작업을 진행했다. 실제 게임 실행은 3회(초기 실패 포함)이며 수정이 필요한 범위만 다시 촬영했다.
- 백업: `_backups/dwe-tutorials-20261109-230123/`.
- 모드 구현·배포 JAR 변경이 없는 문서 작업이므로 모드 릴리스 체인지로그는 갱신하지 않았다. 동시 작업에서 변경된 게시 릴리스 자료는 이 작업의 산출물로 취급하거나 되돌리지 않았다.
- 종료 대조에서 공유 루트의 DRM 0.3.2 JAR 해시가 촬영 당시와 달라져 별도 기록했다. 이 작업에서는 원본 JAR을 바꾸지 않았으며 변경 주체를 추정하지 않는다. 영상은 실행별 환경에 기록한 촬영 당시 해시를 기준으로 한다. DWE·DW를 포함한 나머지 촬영 입력 10개는 현재 파일과 일치한다.
- 임시 촬영 월드·모드 복사본·대량 원본 프레임·컴파일 출력·FFmpeg 설치본의 정리 결과는 `cleanup.json`에 기록한다. 재현용 촬영·인코딩·검증 코드는 남긴다.
