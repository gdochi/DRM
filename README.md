# DRM Docs

This repository stores the source for the Dialogue Editor wiki/manual.

## Layout

- `wiki/dialogue-editor-wiki.md` - canonical English source page
- `wiki/i18n/dialogue-editor-wiki.en_us.json` - English locale strings
- `wiki/i18n/dialogue-editor-wiki.ko_kr.json` - Korean locale strings
- `wiki/assets/dialogue-editor/` - screenshots, diagrams, and other images

## Editing Notes

- Keep file paths relative so the wiki can be moved without rewriting links.
- Use descriptive image names such as `dialogue-editor-node-tree.png`.
- PNG, JPEG, GIF, and SVG are all fine for embedded wiki images.
- The included SVG assets are placeholders that show how image slots are wired.
