뭰트는 Minigames와 같은 버전 번호를 사용합니다. 아래에서 버전별 카드 추가·수정 비교와 스펙을 확인하세요.
## 버전별 카드 변경
| 버전 | 카드 변경 사항 |
| --- | --- |
| [0.1.6](#mwent/version-0-1-6) | 진영 카드 60종과 공성 카드 12종, 총 72종 추가. 카드별 스펙과 선공 전술 5종 안내. |
| 0.1.4 | Fabric 1.21.1 업로드 카탈로그를 0.1.3과 비교했으며 카드 추가·삭제·정의 변경 없음. |
| 0.1.3 | Fabric 1.21.1 업로드 카탈로그를 0.1.2와 비교했으며 카드 추가·삭제·정의 변경 없음. |
| [0.1.2](#mwent/version-0-1-2) | Fabric 1.21.1 업로드 카탈로그를 0.1.1과 비교했으며 카드 추가·밸런스 변경 없음. |
| [0.1.1](#mwent/version-0-1-1) | 첫 공개. Fabric 1.21.1 업로드 카탈로그 기준 기본 263종·선택 모드 89종, 총 352종. |
위 비교는 기록된 로더·마인크래프트 버전 범위를 유지합니다. 각 상세 문서에 원본 파일과 스크린샷의 버전을 표시했습니다.
