### 0.3.2 Change Log
#### NeoForge 1.21.1
##### Added
* Added Ctrl+S shortcuts to existing editor and configuration save actions.
* Added TaCZ 1.2.0 support while preserving existing TaCZ integrations.
##### Fixed
* Fixed the Controls category to display Dochi`s Warfare in every language.
* Fixed ammo loss when reloading NPCs after their first ammunition resupply.
* Fixed missing NPC reload animations after joining or returning to tracking range.
* Fixed NPCs stopping short of cover, exit, and return positions.
* Fixed NPC muzzle effects when custom hand layers bypass vanilla rendering.
* Fixed disappearing NPC guns after runtime entity data reloads.
