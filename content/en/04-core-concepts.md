## Terms

| Term | Meaning |
| --- | --- |
| GUI | A screen layout shown to the player. |
| Dialogue | NPC conversation flow. |
| Shop | Products, prices, stock, currency, and access rules. |
| Condition | A rule that decides visibility or access. |
| Action | A command, reward, state change, or navigation result. |
| StoredData | Persistent state attached to a player, NPC, or world. |
