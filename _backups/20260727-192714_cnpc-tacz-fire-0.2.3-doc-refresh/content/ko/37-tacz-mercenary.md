## 서로 다른 화면 구분

용병 워크플로는 제작자 도구와 플레이어 런타임 화면을 분리합니다.

| 화면 또는 아이템 | 사용자 | 용도 |
| --- | --- | --- |
| `Mercenary Core`와 `Mercenary Contract Settings` | 크리에이티브 모드 제작자 | 관리 중인 TACZ Fire NPC 하나의 서버 판정 고용 조건을 편집합니다. |
| `Mercenary Contract` 확인 화면 | 플레이어 | 결제 전 비용, 기간, 용병 슬롯, 소유자 공격 조건을 확인합니다. |
| `Mercenary Status` 지휘 HUD | 활성 계약이 있는 플레이어 | 용병 상태 확인, 선택, 명령, 소환, 복귀, 계약 해제를 수행합니다. |

`Mercenary Core`는 `TACZ NPC Core` 총기 편집기의 일부가 아닙니다. 별도 편집기를 열며 관리 중인 TACZ Fire CustomNPCs만 받습니다.

## 제작자 설정

1. `TACZ NPC Core`로 NPC의 총기 전투를 먼저 설정하고 테스트합니다.
2. 크리에이티브 모드에서 `Mercenary Core`를 듭니다.
3. 관리 중인 TACZ Fire NPC를 우클릭합니다.
4. 계약 조건을 설정하고 `Save`를 누릅니다.

| 계약 필드 | 의미 |
| --- | --- |
| `Hire available` | 일반 플레이어 상호작용으로 계약 제안을 요청할 수 있게 합니다. |
| `Cost item ID` | 고용 비용 아이템의 레지스트리 ID입니다. |
| `Cost item count` | 플레이어가 확인할 때 제거할 개수입니다. 크리에이티브/운영자 제작 권한은 비용을 면제할 수 있습니다. |
| `Hire duration (seconds)` | 전체 활성 계약 시간입니다. |
| `Summon windup (seconds)` | 보관된 용병이 배치되기 전 0-60초 지연입니다. |
| `Recall windup (seconds)` | 배치된 용병이 보관되기 전 0-60초 지연입니다. |
| `Faction hostility / hits` | 소유자의 피해 공격이 몇 번 누적되면 주변 같은 팩션 NPC가 소유자를 적대할지 정합니다. 계약은 유지됩니다. |
| `Automatic contract break / hits` | 계약과 소유자 보호를 끝내는 별도 공격 횟수입니다. |
| `Hit reset window (seconds)` | 1-10초 범위의 연속 소유자 공격 판정 시간입니다. 이 시간 동안 추가 피해가 없으면 횟수가 초기화됩니다. |

팩션 적대와 자동 계약 해제는 서로 독립적입니다. 하나를 켠다고 다른 하나가 자동으로 켜지지 않습니다.

## 플레이어 고용

고용 가능한 NPC와 일반 상호작용을 합니다. `TACZ NPC Core`, `Mercenary Core`, CustomNPCs 편집 아이템을 들지 마세요. 해당 아이템은 자체 편집 동작을 유지합니다.

게임을 멈추지 않는 확인 화면에서 NPC, 가격, 계약 기간, 용병 슬롯, 소유자 공격 조건을 보여 줍니다. 플레이어가 확인하면 서버가 제안 유효 시간, 거리, 아이템 비용, 현재 계약 조건, 소유권, 용병 한도를 다시 검사합니다.

플레이어 한 명은 활성 계약을 최대 5개까지 가질 수 있습니다. 비용은 서버 확인이 성공한 뒤에만 지불되며 수동으로 해제한 계약은 환불되지 않습니다.

## 계약 상태와 시간

| 상태 | 시간 처리 |
| --- | --- |
| 배치, 따라가기, 진형, 위치 고정, 전투 | 활성 계약 시간이 계속 흐릅니다. |
| 복귀 중 | 복귀 준비 시간에도 활성 계약 시간이 흐릅니다. |
| 보관됨 | 계약 시간이 멈춥니다. |
| 소환 중 | 배치가 끝날 때까지 계약 시간이 멈춥니다. |
| 청크가 로드되지 않은 배치 상태 | 계약은 배치 상태로 유지되며 HUD에는 로드되지 않음으로 표시됩니다. |

복귀는 보관 전에 현재 NPC 상태를 저장합니다. 소환은 안전한 공간을 찾았을 때만 소유자 주변에 저장된 NPC를 복원합니다. 필요한 저장 데이터나 안전 공간이 없으면 대체 NPC를 임의로 만들지 않고 명령을 거부합니다.

## 런타임 HUD 열기

기본 `J` 키를 누르고 있는 동안 용병 지휘 HUD가 표시됩니다. HUD가 열린 상태에서 `Left Alt`를 누르면 카메라 조작을 놓고 버튼을 클릭할 수 있습니다. `Left Alt`를 놓으면 카메라 조작으로 돌아가고, `J`를 놓으면 HUD가 닫힙니다.

HUD는 최대 5개의 소유 계약을 보여 주며 아래 정보를 표시합니다.

* 계약 상태와 남은 시간
* 이동 모드와 진형 슬롯
* 사격 모드와 전투 태세
* 배치, 소환, 복귀 상태
* 현재 소유자 공격 횟수, 팩션 적대 임계값, 계약 해제 임계값, 초기화까지 남은 시간

용병을 개별 체크할 수 있습니다. 선택한 용병 또는 명령을 받을 수 있는 전체 용병에게 일괄 명령을 보내며, 적용 수와 건너뛴 수가 결과로 표시됩니다.

## 이동과 전투 명령

| 명령 | 동작 |
| --- | --- |
| `Follow` | 고정 진형 슬롯 없이 소유자를 따라갑니다. |
| `Rear Form` | 소유자 뒤쪽 진형 슬롯을 사용합니다. |
| `Front Form` | 앞쪽 진형 슬롯을 사용합니다. |
| `Hold` | 현재 위치를 고정 지점으로 저장합니다. |
| `Regroup` | 현재 이동 작업을 지우고 Follow로 돌아갑니다. |
| `Hold Fire` | 해제할 때까지 사격과 타겟 획득을 멈춥니다. |
| `Fire At Will` | 사격과 타겟 획득을 다시 허용합니다. |
| `Defensive Posture` | 실제 전투와 유효한 위협에 반응합니다. |
| `Aggressive Posture` | 소유자의 유효한 위협 관계와 NPC 타겟 규칙으로 확인된 적을 선제적으로 교전합니다. |
| `Summon` | 설정된 준비 시간 뒤 보관된 용병을 배치합니다. |
| `Recall` | 설정된 준비 시간 뒤 배치된 용병을 보관합니다. |

공격적 태세는 주변 모든 엔티티를 공격하게 만드는 권한이 아닙니다. 명시적 타겟 선택, CustomNPCs 팩션 적대, 우호 플레이어 보호, 태그, 서버가 허용한 반응 규칙이 계속 후보를 필터링합니다.

## 소유자 공격과 계약 해제

소유자 공격은 실제 피해가 들어간 경우에만 계산됩니다. 같은 틱의 다중 피해는 한 번으로 계산되며 설정한 무피해 시간이 지나면 횟수가 초기화됩니다.

* `Faction hostility / hits`는 팩션 반응을 시작합니다. 주변 같은 팩션 NPC가 소유자를 적대할 수 있지만 용병 계약은 유지됩니다.
* `Automatic contract break / hits`는 계약과 소유자 보호를 끝냅니다. 환불은 없습니다.
* 두 임계값을 동시에 넘으면 두 결과가 함께 안내됩니다.

실시간 HUD에 현재 횟수와 두 임계값이 표시되므로 플레이어는 다음 공격 전에 위험을 확인할 수 있습니다.

## 계약 해제와 만료

계약 해제는 확인을 한 번 더 요구하며 환불되지 않습니다. 보관된 NPC는 해제 전에 복원하며, 복원에 실패하면 NPC 유실을 막기 위해 해제를 취소합니다.

활성 계약 시간이 0이 되면 계약이 자동 만료됩니다. 계약 중인 NPC가 제거되어도 계약이 종료되고 소유자에게 안내됩니다.
