## 증상별 확인

| 증상 | 가능한 원인 | 해결 |
| --- | --- | --- |
| GUI가 안 열림 | JSON 경로 오류, HTML 누락, 권한 부족 | 경로와 런타임 로그를 확인합니다. |
| 이미지가 깨짐 | 리소스팩 경로 불일치 | GUI Runtime Path와 실제 리소스 위치를 맞춥니다. |
| 대화 선택지가 안 보임 | 조건이 항상 실패 | 조건을 하나씩 끄고 테스트합니다. |
| 상점 Export 실패 | 필수 ID, 아이템, 가격 누락 | 상단 오류와 상품 상세를 확인합니다. |
| 서버에서만 실패 | 클라이언트 모드나 리소스팩 누락 | 서버/클라이언트 구성을 비교합니다. |

## 빠른 분리법

1. 새 테스트 월드에서 같은 파일을 실행합니다.
2. 조건과 액션을 잠시 제거합니다.
3. 기본 GUI로 바꿔서 화면 문제인지 데이터 문제인지 나눕니다.
4. JSON을 새 파일명으로 Export해서 캐시 문제를 피합니다.
5. 마지막으로 서버 로그와 클라이언트 로그를 같이 봅니다.
