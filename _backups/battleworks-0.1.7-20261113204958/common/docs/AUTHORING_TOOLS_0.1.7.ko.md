# BattleWorks 0.1.7 편집 도구

대상은 Forge 1.20.1, Fabric·NeoForge 1.21.1, Fabric·NeoForge 26.3이다. 기존 JSON은 새 기능을 켜지 않아도 이전 설정으로 읽힌다.

## 편집과 템플릿 선택

- 상단 **Undo / Redo**, `Ctrl+Z`, `Ctrl+Y` 또는 `Ctrl+Shift+Z`로 문서 편집을 되돌린다. 기존 뒤로/앞으로 화면 이동과 별개다. 불러오기 전후의 문서와 파일 연결도 함께 복원한다. 이미 서버에 적용·저장한 결과를 자동으로 취소하지는 않는다.
- 임시 기록은 현재 편집 화면에서 최대 64개, 총 약 4Mi 문자로 제한된다. 닫기·재접속 후 기록을 복구하는 기능은 아니다.
- 소환 작용의 템플릿 입력 옆 **🔍**는 서버의 실제 제공자 목록을 검색한다. 이름·ID로 찾고 목록에 마우스를 올려 외형을 미리 본다. 선택 전에는 입력 초안과 원본 NPC가 바뀌지 않는다.
- 목록 API가 없는 제공자에서는 기존 템플릿 ID 직접 입력을 사용할 수 있다.

## 테스트 배틀 제거

2026-11-08부터 테스트 배틀 탭, 이 공격 시험, 임시 배우·더미 생성과 관찰 복귀 단축키를 제거했다. 편집기 안의 장면·히트박스·파티클 미리보기는 유지한다. 이전 버전이 월드에 저장한 테스트 배우는 로드 후 정리한다.

## 히트박스 지면 예고

패턴 단계의 예고 설정에서 **히트박스 연결**을 켜고 히트박스를 지정하거나 자동 선택을 사용한다. 자동 선택은 현재 단계 이후의 다음 일반 히트박스 작용을 찾는다. 박스·구·원기둥·캡슐의 수평 투영을 NPC 위치·회전·오프셋에 맞춰 지면에 표시한다. **진행 표시**는 접촉 시점까지 안쪽 윤곽을 확장한다.

예고는 시각 효과이며 피해 판정을 추가하지 않는다. 지면이 없는 점과 로드되지 않은 청크는 건너뛴다. 저장 위치에 별도로 실행되는 히트박스·외부 스킬 전체 범위까지 자동 추정하지는 않는다. 기존 문서에서는 기본적으로 꺼져 있다.

## 전장 범위와 복귀

**전투 규칙 → 전장**에서 중심의 월드 좌표, 수평 반경, 상하 반높이를 지정하고 활성화한다. 범위는 원통형이다. 현재 위치를 중심으로 가져오는 버튼도 제공한다.

NPC가 범위를 벗어나거나, 설정에 따라 대상이 이탈하면 실행 중 전투를 중단하고 BattleWorks 관리 소환·투사체·이동 상태를 정리한다. 로드된 안전한 중심 인근을 찾으면 NPC를 복귀시키고 선택에 따라 체력을 회복한다. 안전한 자리가 없으면 강제로 블록 내부로 이동시키거나 청크를 로드하지 않는다. 플레이어는 이동시키지 않는다. 기본 설정은 비활성화다.
