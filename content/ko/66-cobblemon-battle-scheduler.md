## 무엇을 연결하나요?

배틀 스케줄러는 **NPC 클론 소환 → 등장 장면 → 배틀 프레젠테이션 → Cobblemon 배틀 → 기존 보상·진행 처리 → 결과 장면 → 배우 정리·퇴장**을 연결합니다. Minecraft 1.21.1의 Fabric·NeoForge Cobblemon Editor 0.2.4에서 사용할 수 있습니다. RCT는 필수가 아닙니다.

클론은 NPC 객체와 외형을 제공하고 Trainer 또는 Pokemon Itself JSON은 배틀 설정을 제공합니다. Scene Maker 장면은 등장·결과 연출, Battle Presentation Maker는 배틀 진입 연출입니다. 저장한 클론 원본은 스케줄러 실행 중 바꾸지 않습니다.

## 첫 보스전 만들기

1. CNPC 서버 클론과 정상 작동하는 Trainer 또는 Pokemon Itself 배틀 JSON을 준비합니다.
2. DRM 애드온 에디터 목록에서 **배틀 스케줄러**를 엽니다.
3. **배우**에서 클론을 고르고 **기존 설정 사용** 또는 **새 JSON 적용**을 선택합니다. 기존 클론에 배틀 연결이 없다면 새 JSON을 적용하세요.
4. **구역**에서 방 ID·영역·배우 위치·플레이어 위치·퇴장 위치와 방향을 정합니다. 현재 위치를 가져오면 해당 월드도 기록합니다.
5. **연출**에서 등장 장면, 프레젠테이션, 승리·패배·도주 장면을 연결합니다. 장면은 선택 사항이고 프레젠테이션을 비우면 배우 배틀 설정의 연결을 사용합니다.
6. **정책**에서 명령/영역/둘 다 호출, 입장 정책, 이탈 취소, 재사용 대기, 시작 제한 시간과 진행 기록 기준을 정합니다.
7. **미리보기**에서 재생·정지와 승리·패배·도주 선택으로 연결을 확인합니다. 참조 파일을 고쳤다면 다시 읽기를 사용합니다.
8. 검증 후 `Save As`로 사용자 파일을 저장하고 실행으로 실제 소환·배틀을 시험합니다.

미리보기는 참조 파일·클론 외형·장면·프레젠테이션을 재생합니다. 실제 소환, 배틀 승리, 보상 지급은 실행 시험으로 확인하세요. 미리보기 카메라와 실제 영역의 청크가 로드되어 있어야 합니다.

## 월드에서 영역 선택

**구역 → Select area**에서 월드의 박스를 직접 이동하거나 모서리를 드래그해 범위를 정한 뒤 Apply합니다. Esc는 취소하며 블록을 변경하지 않습니다. 영역 최대 좌표는 범위에서 제외됩니다. 배우와 참가자의 시작 위치는 영역 안에, 퇴장 위치는 사용할 수 있는 장소에 정하세요.

Mods Config의 **Show scheduler areas**를 켜고 크리에이티브에서 DRM Core를 들면 주변 64블록 내 최대 16개의 영역 가이드를 볼 수 있습니다. 초록은 ON, 회색은 OFF, 주황은 사용 중입니다. 편집 권한이 필요하며 장면·배틀 중에는 표시하지 않습니다. 이 설정은 로컬 표시이며 영역 실행을 켜는 스위치와 다릅니다.

## 자동 영역 입장 켜기·끄기

저장 파일의 영역 감시 ON/OFF는 서버에 즉시 적용하고 재시작 뒤에도 유지합니다. OFF는 새 자동 입장을 중단하지만 진행 중 배틀과 명령 Start는 막지 않습니다. 실행 자체를 중단하려면 Cancel을 사용하세요. 편집 초안을 저장해도 운영 스위치는 초기화되지 않습니다.

```text
/drm battle_scheduler area on "boss_room.json"
/drm battle_scheduler area off "boss_room.json"
/drm battle_scheduler area status "boss_room.json"
```

문서 자체가 활성화되고 호출 방식이 Area 또는 Both이며 영역 범위도 활성화되어야 자동 입장합니다. 플레이어가 영역에 들어올 때 검사하며 안에 머무는 동안 반복 소환하지 않습니다.

## 실행과 대화 연결

관리자 명령은 플레이어 한 명을 대상으로 합니다. 플레이어가 직접 실행하면 대상 인자를 생략할 수 있습니다.

```text
/drm battle_scheduler start "boss_room.json" PlayerName
/drm battle_scheduler cancel PlayerName
```

DRM 대화·퀘스트 명령에서는 `PlayerName` 대신 `{player}`를 사용합니다. **명령 복사**도 이 형식을 만듭니다. `@player`는 표시 텍스트용이며 명령의 대상 인자가 아닙니다. 대화 액션 **배틀 스케줄러**에서 서버 JSON을 골라 연결할 수도 있습니다. 성공하면 대화를 닫고 실패하면 유지합니다.

## 예약과 정리

같은 플레이어, 같은 월드·방 ID, 같은 월드의 겹치는 영역은 동시에 실행할 수 없습니다. 다른 JSON이 같은 방을 가리켜도 결과 장면과 정리가 끝날 때까지 예약합니다. 단독 입장은 다른 참가자가 있는 방에서 시작을 거부하고, 관전 허용은 구경을 허용하면서 배우에게 별도 배틀을 거는 것을 막습니다.

취소·이탈·접속 종료·사망·소환 실패·시작 시간 초과 시 실행 장면과 소환한 배우를 정리하고 예약을 해제합니다. 일반 NPC는 제거하지 않습니다. 시작할 때의 참조 설정을 고정하므로 진행 중 파일 편집은 다음 실행에서 확인하세요.

## 파일과 문제 해결

| 내용 | 경로 |
| --- | --- |
| 스케줄러 JSON | `config/dochi_rpg_maker/cobblemon/battle_schedulers/` |
| 자동 영역 입장 운영 상태 | `config/dochi_rpg_maker/cobblemon/battle_scheduler_area_state.json` |

스케줄러 스키마는 참고용으로 `dochi.cobble.battle_scheduler.v1`입니다. 진행 기록은 소환 NPC의 임시 UUID와 분리되어 유지하며 다른 파일로 Save As하면 별도 진행 ID를 만듭니다. 실행이 거부되면 편집 권한, 클론·배틀 JSON 연결, 청크, 겹치는 방 예약과 재사용 대기를 확인하세요.
