## Dochi's Cobblemon Editor
### 0.3.0 Change Log
#### Global
##### Added
* Added eleven Cobblephone themes, including Ditto, Jigglypuff, Piplup, and Bulbasaur with a printed rear bulb.
* Added opening animations, 45-degree inventory previews, and handheld grips using player skins and sleeves.
* Added bright phone LCDs and glass reflections without requiring external shaders.
* Added persistent trainer contacts with transparent upper-body portraits, battle records, favorites, and call history.
* Added immediate contact registration when players accept the contact exchange dialogue choice.
* Added choice-based calls for casual conversations, rematches, and regional hints.
* Added incoming rematch, story, and casual calls with missed-call records and callbacks.
* Added NPC phone settings, custom call dialogues, and dialogue actions for exchanging contacts.
* Added eleven Pokémon-themed pixel UI skins matched to the held Cobblephone.
* Added compact phone controls, shadow-free text, and scrollable profiles across Minecraft GUI scales.
* Added world-wide phone skin settings for administrators, including DRM skins, resource-pack skins, and color profiles.
* Added player settings for Silent mode and Casual calls.
* Added a standalone Cobblephone Editor with branching replies, bulk editing, and interactive call previews.
* Added direct conversation editing, phone JSON assignment, and formatted multiline descriptions in NPC contact profiles.
* Added Cobblephones to DNPC and CustomNPCs creative tabs when those optional mods are installed.
