## 선택지 글자 크기 바꾸기

다이얼로그 노드의 **Choices**를 엽니다. **Choice text px (0 = GUI)**에서 그 노드의 선택지 글자 크기를 정합니다. **0**은 연결된 GUI의 설정을 그대로 사용한다는 뜻입니다. 양수를 넣으면 해당 노드에 그 크기를 적용합니다.

여러 대화에서 공통으로 쓸 크기는 **GUI Maker**에서 대화 레이아웃을 열고 **Choice** 요소의 **Text size (px)**로 정합니다. 글자 크기는 6~32 GUI 픽셀입니다. Minecraft의 GUI 배율에 따라 실제 화면에서 보이는 크기는 달라집니다.

## 긴 문장이 잘리지 않게 하기

선택지마다 문장 길이가 다르면 버튼 너비를 자동으로 설정하세요. 현재 화면에 표시되는 문장 길이를 계산해서, 줄을 바꾸기 전에 쓸 수 있는 가로 공간을 먼저 사용합니다. 긴 문장은 선택지 영역의 안쪽 너비까지 늘어나고, 짧은 문장은 필요한 만큼만 차지합니다.

그래도 여러 줄이 필요하면 버튼 높이가 늘어납니다. 선택지가 많아 영역을 넘으면 스크롤할 수 있습니다. 버튼을 아담하게 만들려면 최소 높이를 자동 값인 **0**으로 둡니다. 기본 상태에서는 글자 위아래에 **각각 약 5 GUI 픽셀**의 여유가 붙습니다. 직접 더 큰 최소 높이를 지정했다면 그 값이 적용됩니다.

리소스팩으로 번역하려면 선택지 문구를 번역 키로 지정하고 언어 파일에 해당 키를 넣으세요. 버튼 크기는 키의 철자 수가 아니라 실제 번역된 문장을 기준으로 계산합니다.

## 선택지를 펄스로 강조하기

1. **Dialogue Editor → Choices**에서 강조할 선택지를 고릅니다.
2. **Pulse highlight**를 켭니다.
3. 아래 항목을 조정합니다.

| 설정 | 뜻 |
| --- | --- |
| Total ticks | 모든 펄스가 끝날 때까지의 전체 시간입니다. 20틱은 1초입니다. |
| Pulse count | 그 시간 동안 진해졌다 연해지는 횟수입니다. |
| Color (RGB) | 색상 입력칸, 색상 미리보기, 팔레트로 색을 고릅니다. |
| Intensity | 0~100 사이의 강조 강도입니다. 좌우 화살표나 가운데 숫자 입력칸으로 바꿉니다. 0이면 효과가 보이지 않습니다. |

예를 들어 **60틱 / 3회**는 3초 동안 세 번 강조한다는 뜻입니다. 강도를 바꾸면 효과가 더 진하거나 연해집니다. 선택한 색이나 글자 크기는 바뀌지 않습니다.

펄스는 그 선택지가 실제로 처음 보일 때 시작합니다. 대사 타이핑이 끝나기를 기다리는 선택지나 스크롤 아래에 숨은 선택지는 미리 재생 시간이 줄어들지 않습니다. 스크롤했다 돌아오는 것만으로 끝난 효과가 다시 시작되지는 않습니다. 대화 장면을 다시 열면 새로 재생됩니다.

## 기존 대화는 어떻게 되나요?

예전 대화에는 펄스가 자동으로 추가되지 않습니다. 강조하고 싶은 선택지에서만 켜면 됩니다. 꺼도 지정했던 값은 나중에 다시 쓸 수 있도록 유지됩니다. 편집을 마치면 대화를 저장하세요.
