## Scope

DRM documentation covers the runtime systems, editor workflows, data files, and server operation notes used by the Dochi RPG Maker toolchain.

| Area | What it covers |
| --- | --- |
| Runtime | GUI, dialogue, shops, conditions, and actions in game. |
| Editors | GUI Maker, Dialogue Editor, NPC Shop, and related tools. |
| Data | JSON files, resource paths, IDs, and stored state. |
