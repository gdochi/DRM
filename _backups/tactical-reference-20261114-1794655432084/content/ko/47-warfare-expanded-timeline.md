## 이 순서대로 따라오세요

이 화면은 **제작자용 Gimmick Editor**입니다. 실제 월드를 보면서 지원 위치를 놓고, 아래 타임라인에서 언제 시작할지 정합니다.

| 순서 | 여기서 할 일 |
| --- | --- |
| 1. 이 페이지 | 화면 익히기 → 점·선·영역 폭격 → 시간과 중심점 |
| 2. [차량·기총·NPC 지원](#dochi-warfare-expanded/expanded-support-actions) | 출발·도착점, 지원 차량·무장, NPC 공급원 설정 |
| 3. [저장·실행과 문제 해결](#dochi-warfare-expanded/expanded-support-run) | 저장·불러오기 → Simulation → 실제 호출 |

영상 10편을 이 세 페이지의 작업 단계 옆에 나누어 배치했습니다. **DWE 0.3.2 / NeoForge 1.21.1의 실제 화면**으로, 영어 UI와 한국어 단계 설명을 함께 보여 줍니다. 무음 영상이므로 잠시 멈추고 같은 항목을 찾아 입력해도 됩니다. Forge·Fabric도 같은 편집 흐름을 사용하며 영상의 실제 촬영 환경은 NeoForge입니다.

먼저 [설치와 첫 차량 설정](#dochi-warfare-expanded/expanded-overview)을 확인하고 운영 권한이 있는 월드에 들어갑니다. 편집기 선택 화면에서 **Gimmick Editor → Create New**를 엽니다. **Use Default**는 현재 플레이어 위치 기준의 점 폭격 한 개가 있는 초안을 엽니다. 처음에는 빈 문서에서 한 개만 만들어 보세요.

## 1. 작업 화면 익히기

| 위치 | 역할 |
| --- | --- |
| 상단 | 새 문서, Load, Save, Save As, Reset, 제목, Simulation, 좌표 방식과 Center |
| 왼쪽 | 배치 도구와 이벤트 선택·복제·삭제 |
| 가운데 월드 | 실제 블록 표면에 위치와 이동 경로 배치 |
| 오른쪽 속성 | 선택한 이벤트의 기체·차량·시간·수량. Advanced에서 정밀 좌표와 추가 값 확인 |
| 아래 Timeline | NPC, 차량·기총, 폭격의 시작 시점을 종류별 행에서 확인·이동 |

![새 문서, 패널 접기·크기 조절, 월드 카메라를 차례로 익힙니다.](assets/media/guides/dwe-tutorials-20261109/dwe-workspace.mp4 "01 · 오른쪽 패널 접기와 복원, 분할선 드래그, 카메라 이동·회전·확대. DWE 0.3.2 / NeoForge 1.21.1.")

패널 모서리의 화살표로 접고 다시 펼칩니다. 패널 사이 분할선을 드래그하면 폭과 높이를 조절합니다. 속성이 아래에 더 있으면 **오른쪽 패널 안에서 휠**을 굴립니다.

월드 위 휠은 확대·축소, 가운데 버튼 드래그는 시점 이동, 오른쪽 버튼 드래그는 회전입니다. **F**는 선택한 이벤트나 편집 중인 중심점을 바라봅니다. WASD는 플레이어 이동과 시점 추적, Jump·Sneak는 카메라 높이 조절에 사용합니다. 위쪽 속도 −/+는 카메라 이동 속도이며 이벤트 실행 속도가 아닙니다.

## 2. 첫 점 폭격 만들기

목표는 **“지면 한 곳에, 호출 후 2초에 첫 폭탄 투하”**입니다.

1. 왼쪽 **Point bombing**을 누릅니다.
2. 가운데에서 불러온 지면의 블록 표면을 한 번 클릭합니다. 목록과 아래 폭격 행에 이벤트가 생기는지 확인합니다.
3. **Select / move**로 돌아가 표식이나 목록의 이벤트를 선택합니다.
4. 오른쪽에서 **Aircraft / Payload**를 확인합니다. 선택기는 서버가 제공하는 실제 기체·폭탄 목록입니다. 비어 있으면 설치·지원 조합부터 확인하세요.
5. **Start (seconds) 2**, **Altitude 96**, **Lifetime (seconds) 30**을 넣습니다.
6. **Advanced**에서 좌표와 추가 값을 확인합니다. **Basic**으로 돌아올 수 있습니다.

![점 폭격을 배치하고 시작 2초·고도 96·수명 30초를 입력합니다.](assets/media/guides/dwe-tutorials-20261109/dwe-point.mp4 "02 · 마지막 Advanced의 Explosion damage 20은 기본 폭발 피해 20 HP 예제입니다. 명중·실제 피해를 측정하는 영상은 아닙니다.")

**2초는 첫 투하 시각입니다.** 땅에 닿는 시각은 고도와 원본 무기 물리에 따라 늦어집니다. Lifetime은 임시 지원의 수명입니다.

점 폭격에서는 개수와 간격 항목이 비활성일 수 있습니다. 여러 번 떨어뜨릴 계획이면 선·영역 도구를 사용하세요. 표식은 작성한 목표·방향을 보여 주며 실제 탄착은 원본 물리의 영향을 받습니다.

## 3. 선과 영역 폭격 만들기

1. **Line bombing**을 골라 지면에서 통로의 시작부터 끝까지 드래그합니다.
2. 오른쪽에서 발수와 투하 간격을 정합니다. 예제는 **4발, 0.5초 간격**입니다.
3. **Area bombing**으로 두 번째 통로를 그립니다. 영역은 길이에 더해 폭을 갖습니다.
4. **Select / move**에서 길이·폭·방향 핸들을 드래그하거나 **Advanced → Width / Heading**을 입력합니다.

![선 폭격의 4발·0.5초 간격과 영역 폭격의 폭·방향을 설정합니다.](assets/media/guides/dwe-tutorials-20261109/dwe-corridors.mp4 "03 · 별도 선·영역 이벤트입니다. 영역 예제는 Width 24, Heading 0입니다. 배치·설정을 보여 주며 폭격 실행 장면은 아닙니다.")

첫 투하가 2초라면 4발은 **2.0 → 2.5 → 3.0 → 3.5초**에 투하합니다. 명시한 발수는 기체 한 대 기준이며 영역에는 여러 비행 줄이 사용될 수 있습니다. 발수를 정하면 원본 기체 속도와 간격으로 통로 길이가 계산되어 길이 입력이 잠길 수 있습니다. 빈 발수는 원본 탑재량을 사용합니다.

Heading은 **0 남쪽, 90 서쪽, −90 동쪽**입니다. 숫자를 외우기보다 월드의 접근 방향 표식을 확인하세요.

## 4. 여러 이벤트 시간 맞추기

**시간 변경과 목록 순서 변경은 다른 작업입니다.**

- Basic의 초 입력은 **0.05초 단위**입니다. Advanced와 저장 파일은 정수 틱이며 정상 20 TPS에서 **20틱 = 1초**입니다.
- 아래 이벤트 마커를 좌우로 드래그하면 시작 시각이 바뀝니다. 눈금자 클릭은 새 배치의 기준 시점을 고릅니다.
- Timeline의 −/+는 보이는 시간 범위입니다. 실제 실행 속도는 바꾸지 않습니다.
- 왼쪽 행 드래그는 기존 시간 슬롯을 유지하며 목록 순서를 바꿉니다. 시각 변경은 마커나 숫자로 하세요.
- **Duplicate** 후에는 겹친 위치와 시각을 확인합니다. 체크박스는 여러 이벤트를 한꺼번에 삭제할 때 사용합니다.

![차량 2초·폭격 5초를 만들고 시간 범위를 넓혀 마커 이동과 복제·실행 취소를 확인합니다.](assets/media/guides/dwe-tutorials-20261109/dwe-timing.mp4 "04 · 시작 시각 입력, 타임라인 마커 드래그, Duplicate와 Ctrl+Z / Ctrl+Y.")

**Ctrl+Z / Ctrl+Y**는 배치 편집의 실행 취소·다시 실행입니다. 드래그 중 **Esc**를 누르거나 허용 영역 밖에 놓으면 그 드래그를 취소합니다. 같은 틱에는 최대 16개 이벤트가 시작할 수 있으므로 많은 증원은 시각을 나누세요.

## 5. 중심점과 상대좌표

처음에는 **Relative coordinates**로 열립니다. 정밀 좌표의 0, 0, 0은 상단 **Center**에 지정한 중심입니다.

| 작업 | 상대좌표 모드 | 절대좌표 모드 |
| --- | --- | --- |
| 표시 방식만 전환 | 배치 그대로 | 배치 그대로 |
| Center 변경 | 모든 출발·도착·목표를 함께 이동 | 월드 위치를 유지하며 기준점만 변경 |
| 정밀 좌표 입력 | 중심에서 떨어진 거리 | 월드 좌표 |

![상대 모드의 전체 이동과 절대 모드의 기준점 변경을 비교합니다.](assets/media/guides/dwe-tutorials-20261109/dwe-center.mp4 "05 · Center X를 8로 바꾸고 되돌립니다. Absolute coordinates에서 같은 중심 변경을 하면 경로는 유지됩니다.")

**Center → X/Y/Z**로 입력하거나 **Use player position**을 사용합니다. 월드에서 중심을 클릭·드래그할 수도 있습니다. 상대 모드에서는 경로와 목표가 모두 함께 움직이므로 **마커 하나를 고치는지 전체 배치를 옮기는지** 먼저 확인하세요.

상대 모드로 파일을 불러오면 현재 중심에 맞춰 전체 배치를 옮겨 엽니다. 저장된 월드 위치를 유지하려면 **먼저 Absolute coordinates로 바꾸고 Load**하세요. 중심 정보가 없는 구버전 파일은 첫 이벤트 목표를 기준점으로 읽습니다.
