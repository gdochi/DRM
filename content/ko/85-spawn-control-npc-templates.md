## NPC를 먼저 저장하세요

DNPC에서 외형·장비·행동을 완성하고 **NPC에 저장 → 복제 템플레이트로 저장**을 누릅니다. [템플릿 저장 방법](#dochi-npc-core/npc-core-templates)을 참고하세요.

이 연결에는 **DNPC와 DRM**이 필요합니다. Entity 목록의 기본 DNPC를 고르면 꾸며 둔 경비병이 아니라 기본 NPC가 나옵니다. **NPC 복제 템플레이트**를 골라야 저장한 모습을 사용합니다.

## 특정 장소에서 등장시키기

1. **Spawner Editor → 소환 목록**에서 항목을 추가합니다.
2. 종류를 **NPC 복제 템플레이트**로 정합니다.
3. 저장한 NPC를 목록에서 고릅니다.
4. 조건·수량을 정하고 **Save As**로 저장합니다.
5. 설치한 스포너를 DRM 코어로 우클릭해 해당 파일을 적용합니다.

[스포너 설치 순서](#dochi-spawn-control/dochi-spawn-control-spawner)를 함께 보세요. 이 방식은 기존 버전과 26.3에서 사용할 수 있습니다.

## 주변에 자연스럽게 등장시키기 — 1.20.1·1.21.1

기본 **K**의 카탈로그에서 **NPC 복제: 이름**을 찾습니다. 해당 항목에 **규칙 추가**를 누르고 바이옴·시간·등장 수를 정해 저장합니다.

기본 NPC와 저장한 템플릿은 서로 다른 등장 대상으로 다룹니다. 26.3에서는 위 배치형 스포너 방식을 사용하세요.

## 목록에 없거나 모습이 다를 때

| 상황 | 해결 |
| --- | --- |
| 예전 템플릿이 없음 | NPC에 불러온 뒤 복제 템플릿으로 다시 저장 |
| 이름은 있는데 생성 실패 | 서버에 템플릿 파일과 DNPC·DRM이 있는지 확인 |
| 고쳤는데 예전 장비가 나옴 | 템플릿을 다시 불러오고 스포너에 재적용 |

생성한 NPC의 부활은 Spawn Control이 관리합니다. 저장한 NPC의 자체 부활을 중복으로 실행하지 않습니다.
