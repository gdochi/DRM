## 지원 도구 고르기

[첫 타임라인](#dochi-warfare-expanded/expanded-support-timeline)의 화면 조작을 익힌 뒤 진행하세요. 이 도구들은 한 문서에 함께 넣을 수 있습니다.

| 도구 | 월드에서 하는 동작 | 시작 시각 |
| --- | --- | --- |
| Vehicle support | 출발점에서 지원 지점까지 드래그 | 차량 생성·이동 시작 |
| Fire support | 목표를 누르고 접근 방향으로 드래그 | 지원 차량·기체 생성 |
| NPC deployment | 출발점에서 목적지까지 드래그 | 클론 생성 또는 기존 NPC 선정·이동 |

처음에는 한 종류 한 개로 시험한 뒤 조합하세요. 완성 후에는 [저장·시험·실제 호출](#dochi-warfare-expanded/expanded-support-run)로 이어갑니다.

## 1. 차량 한 대 증원하기

1. 빈 문서에서 **Vehicle support**를 선택합니다.
2. 통과할 수 있는 지면에서 출발점을 누르고 목적지까지 드래그합니다.
3. **Select / move**로 전환하고 이벤트를 선택합니다.
4. 오른쪽 차량 선택기를 확인합니다. 예제는 기본 **M1A2 한 대**입니다.
5. 시작 **3초**, 대수 **1**, 간격 **12**, 방어 반경 **24**, 수명 **60초**를 입력합니다.
6. **Advanced**에서 출발·도착 좌표가 다른지 확인합니다. 월드 핸들이나 좌표 입력으로 고칩니다.

![차량 경로와 3초 시작·1대·간격 12·방어 반경 24·수명 60초를 설정합니다.](assets/media/guides/dwe-tutorials-20261109/dwe-vehicles.mp4 "06 · 차량 경로 작성입니다. 실제 임시 차량 생성·이동·중지는 저장·실행 페이지의 10번 영상에서 확인합니다.")

| 항목 | 입력 전에 알아둘 점 |
| --- | --- |
| Count | 한 이벤트에 1~8대. 먼저 한 대로 경로 확인 |
| Spacing | 출발·도착에 같은 대형 오프셋 사용 |
| Faction | 숫자 팩션 ID. 기존 관계로 적대 판단 |
| Guard radius | 도착 뒤 주변을 방어하는 범위 |
| Lifetime | 생성부터 세는 수명. 이동 중에도 시간이 흐름 |

도착 뒤에는 주변을 방어합니다. 지상 차량은 실제로 지나갈 길이 필요합니다. 지원 헬기는 지면에서 생성해 원본 비행 AI로 이륙하며 목적 Y는 비행 높이 요청입니다. 고정익은 폭격·기총 지원을 사용합니다.

## 2. 기총 지원 만들기

1. **Fire support**로 목표를 누르고 드래그해 접근 방향을 정합니다.
2. 오른쪽에서 **지상/항공 방식 → 차량 → 실제 무장**을 확인합니다. 방식을 바꾸면 기본 차량·무장도 바뀌므로 다시 확인합니다.
3. 예제는 발사 횟수 **20**, 사격 시간 **3초**, 거리 **48**, 좌우 사격 구간 **16**입니다.
4. 시작 **5초**, 수명 **30초**로 설정합니다.
5. 항공 지원이면 고도를 지정하고 실제 지형의 진입·사격·이탈을 시험합니다.

![기총 지원 방향과 발사 횟수·시간·거리·사격 구간을 설정합니다.](assets/media/guides/dwe-tutorials-20261109/dwe-fire.mp4 "07 · 지상 기총 지원 설정입니다. 항공 방식·다른 무장 선택·실제 발사 결과를 보여 주는 영상은 아닙니다.")

**시작, 사격 시간, 수명은 별개입니다.** 시작 시각은 소환 시점이며 사격 시간은 **첫 실제 발사부터** 계산합니다. 시간과 발사 횟수 중 먼저 상한에 닿으면 사격을 끝냅니다. 지형·사거리·안전한 이탈 지점·수명 때문에 더 일찍 끝날 수도 있습니다.

서버가 제공하는 기총·기관포만 고릅니다. 폭탄·로켓·미사일·저속 주포는 제외됩니다. 원본 RPM·탄약·과열·재장전·안전 판정은 유지됩니다. 항공은 공격 후 이탈하고 지상은 지정 위치에서 포탑으로 구간을 쓸어 사격합니다.

## 3. 기존 NPC 이동시키기

| 공급원 | 준비와 결과 |
| --- | --- |
| Area | 실행 시 출발점 주변 구 안의 DW AI가 켜진 NPC 선정 |
| Clone | DW 클론 보관함에 저장한 NPC 복사본 생성 |

1. **NPC deployment**로 출발점부터 목적지까지 드래그합니다.
2. **Source**를 확인합니다. 영상은 클론이 없는 월드여서 **Area**로 시작합니다.
3. 수량 **4**, 반경 **16**, 간격 **2**, DW 속도 **5**를 입력합니다.
4. 시작 **2초**, 수명 **30초**를 넣습니다. 팩션을 지정하면 선정·생성 조건에도 영향을 줍니다.
5. **Advanced**에서 출발점·목적지를 확인하고 저장합니다.

![기존 NPC 영역 선정의 경로·수량·반경·간격·속도·시간을 작성합니다.](assets/media/guides/dwe-tutorials-20261109/dwe-npcs.mp4 "08 · Area 설정 작성입니다. 실제 이동 성공 장면은 포함하지 않습니다. 실행 전 출발 영역에 DW AI가 켜진 NPC를 준비하세요.")

Area는 **실행 시점의 출발점 중심 구**를 사용합니다. 탑승·고용·다른 지원 이동 중인 NPC는 제외합니다. Clone은 원본에서 DW AI를 켠 뒤 보관함에 저장하고 선택합니다. 목록이 비면 이 준비부터 하세요. 파일 ID와 표시 이름은 다를 수 있습니다.

적을 만나면 DW의 기존 전투가 우선하고 이후 진격을 재개합니다. 막힌 길을 순간 이동으로 통과하지 않습니다. 수명 종료 때 **새로 소환한 클론만 제거**합니다. Area의 기존 NPC는 이전 이동 설정을 복구하며 실행 중 제작자가 바꾼 설정을 무조건 덮어쓰지 않습니다.

## 여러 지원 조합하기

첫 시험은 **0초 NPC → 3초 차량 → 5초 기총**처럼 시작을 나눕니다. 시작 순서가 도착 순서를 보장하지 않습니다. 실제 경로·물리·전투에 따라 달라집니다.

[시간·중심점](#dochi-warfare-expanded/expanded-support-timeline)을 정리한 뒤 [저장·실행](#dochi-warfare-expanded/expanded-support-run)으로 넘어가세요. 임시 지원 차량의 탑승·클론 저장·소울스톤 포획은 제한됩니다. 보관할 일반 차량에는 [차량 편집기](#dochi-warfare-expanded/expanded-overview)를 사용합니다.
