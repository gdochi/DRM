## NPC를 다시 사용할 수 있게 저장하기

임시 Ctrl+C 복사와 파일 템플릿은 다릅니다. **0.1.1의 v3 복제 템플릿**은 현재 NPC의 작성 데이터와 장비·인벤토리·로드아웃, 지원 애드온 바인딩을 함께 보존합니다.

1. NPC Core로 NPC 편집기를 엽니다.
2. 외형·장비·행동을 편집하고 **NPC에 저장**합니다.
3. **복제 템플레이트로 저장**을 눌러 새 이름으로 저장합니다.
4. 서버의 `config/dochi_npc_core/templates/`에서 관리합니다. 기본 템플릿과 사용자 파일 이름을 구분하세요.
5. [Spawn Control](#dochi-spawn-control/spawn-control-npc-templates)에서 저장한 템플릿을 고릅니다.

템플릿을 저장하는 DNPC 기본 기능은 DRM 없이 사용할 수 있습니다. Spawn Control 연결에는 DRM의 공개 템플릿 API와 DNPC 제공자가 모두 준비되어 있어야 합니다. 확인한 조합은 DRM 0.2.9 / DNPC 0.1.1 / Spawn Control 0.1.4이며, 시험한 버전을 새 최소 버전으로 정한 것은 아닙니다.

## 무엇을 복사하나요?

| 보존하는 것 | 새로 시작하는 것 |
| --- | --- |
| 외형·행동 설정과 작성된 목적지 | 새 UUID와 실제 생성 위치 |
| 현재 장비·인벤토리·로드아웃과 아이템 데이터 | 피해·사망·이동·작업 등 일시 상태 |
| 지원 애드온의 작성 바인딩 | 이전 스포너 소속·고용주·침대 점유 |

복제 직후 SPAWN 장비 풀로 현재 장비를 다시 추첨하지 않습니다. 이후 날짜·전투·간격에 따른 작성된 장비 교체는 계속 동작합니다. 작성 데이터 복제는 살아 있던 NPC의 세션·소유권 전체를 복원하는 기능이 아닙니다.

기존 NPC에 불러올 때는 그 대상의 UUID·위치·현재 스포너 소속을 유지합니다. 새 NPC 생성과 기존 NPC에 불러오기를 구분하세요.

## 구형 템플릿

설정 전용·v2 파일은 기존 로드 경로로 읽을 수 있지만 정확한 복제 스냅샷이 없으므로 Spawn Control 복제 목록에 나오지 않습니다. NPC에 불러온 뒤 **NPC에 저장 → 복제 템플레이트로 저장**을 새 이름으로 수행하세요. 기존 파일은 자동 덮어쓰기하지 않습니다. 구형 DNPC로 v3를 되돌려 읽는 기능은 제공하지 않습니다.

파일이나 제공자가 없으면 해당 복제 생성이 실패하며 빈 기본 NPC를 대신 생성하지 않습니다. 준비된 스냅샷은 고정되므로 원본 파일을 바꾼 후에는 사용하는 에디터/서버의 재로드 흐름으로 다시 준비합니다.
