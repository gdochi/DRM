# BattleWorks 0.1.7 쉬운 공격 제작

Forge 1.20.1, Fabric·NeoForge 1.21.1, Fabric·NeoForge 26.3에 같은 제작 흐름을 제공한다.

## 간단 편집과 상세 편집

기존 보스 파일을 불러오거나 새 공격을 만들면 패턴의 **간단 편집**에서 이름, 활성화, 사용 거리, 준비·타격·후딜 시간, 재사용 대기시간과 연결된 히트박스의 피해·크기를 조정할 수 있다. 여러 히트박스가 연결되어 있으면 수정할 히트박스를 먼저 고른다. 히트박스를 공유하는 공격 수를 표시하며 **이 공격의 히트박스 분리**로 현재 공격만 독립시킬 수 있다.

**상세 편집**은 기존 점수·조건·이벤트·이동·애니메이션·콤보 설정을 연다. 화면 전환은 문서를 변환하거나 기존 세부 설정을 초기화하지 않는다. 타임라인에서 단계나 이벤트를 고르면 해당 상세 편집으로 이동한다. 공격 사용 조건과 이벤트 실행 조건은 별도로 편집한다.

시간 입력값은 기존과 같은 정수 틱이며, 아래에 초와 틱을 함께 표시한다. 정상 게임 속도에서 `24틱 = 1.2초`이다. 서버 지연 중 실제 경과 시간을 보장하는 값은 아니다. 시간을 바꾼 뒤에는 타임라인에서 타격 시점도 확인한다.

## 공격 레시피

패턴 목록 아래 **공격 레시피**에서 다음 공격을 추가할 수 있다.

- **넓게 휩쓸기**: 근접 판정, 기본 팔 휘두르기와 연결된 바닥 예고.
- **다가가서 베기**: 접근한 뒤 멈추고 범위를 예고해 타격.
- **예고 후 지면 타격**: 대상 위치 저장, 원형 파티클 예고, 저장 위치 타격과 위치 정리.
- **물러난 뒤 반격**: 뒤로 이동한 뒤 긴 전방 판정으로 반격.

외부 스킬·모델 ID를 임의로 만들지 않는 기본 공격이다. 추가된 패턴과 자원은 편집할 수 있으며, 기존 자원과 ID가 겹치면 새 ID를 부여한다. 지면 타격의 예고와 피해는 같은 저장 위치를 사용한다.

현재 모델이 기본 팔 휘두르기를 지원하지 않으면 해당 레시피의 모션은 비워 둔다. 모델에 맞는 클립을 상세 편집에서 지정할 수 있으며, 보스의 모델 설정을 자동 변경하지 않는다. 기술함에서 모델과 호환되지 않는 애니메이션을 가져오면 문서에 추가하지 않고 안내한다.

## 내 기술함과 복사

선택한 공격의 **기술함에 저장**은 공격, 연결된 콤보, 히트박스, 내장 파티클을 서버의 사용자별 기술함에 저장한다. 서버 파티클 파일 참조는 저장 시 내장 파티클로 가져온다. **내 기술함**에서 검색하여 다른 보스 문서에 추가할 수 있다. 파일은 편집기 데이터 루트의 `battleworks/pattern_library/<사용자 UUID>/`에 보존된다. 한 사용자당 최대 128개를 저장한다.

불러온 기술은 기존 패턴·히트박스·파티클을 덮어쓰지 않는 독립된 사본이다. 연결된 콤보와 저장 위치·소환/투사체 묶음 참조도 함께 연결한다. 외부 스킬, 사운드, 모델과 애니메이션 자산은 해당 모드·리소스가 여전히 필요하며, 대상 보스의 모델 설정을 자동으로 바꾸지 않는다.

기존 **복제**에서도 다음 방식을 고른다.

- **독립된 사본**: 연결된 콤보와 전투 자원까지 새 사본으로 추가.
- **기존 자원 공유**: 선택한 패턴만 복사하고 기존 히트박스·연출·콤보 대상을 함께 사용.

추가·수정은 기존 문서 Undo/Redo에 포함된다. 서버 기술함에 저장한 항목은 문서 Undo로 삭제되지 않는다.

## 테스트 배틀 제거

2026-11-08부터 테스트 배틀과 이 공격 시험, 실행 결과 패널 및 관찰 복귀 단축키를 제거했다. 기술 라이브러리, 간단 편집과 장면 미리보기는 계속 사용할 수 있다.
