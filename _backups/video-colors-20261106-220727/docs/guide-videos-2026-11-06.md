# 문서용 무음 반복 영상

기존 GIF 3개를 WebM(VP9)과 MP4(H.264)로 교체하고, 실제 게임에서 촬영한 신규 예시 3개를 추가했다. 게시용 자산은 `src/media/guides/short-videos-20261106/`에 있다. 한국어·영어·포르투갈어·스페인어·프랑스어의 문서 40곳에 적용했다. 사용자 지시에 따라 커밋·푸시는 하지 않았다. 모드 구현 변경이 없으므로 모드 릴리스 체인지로그는 수정하지 않았다.

## 영상

| 영상 | 길이 | 내용 |
| --- | --- | --- |
| nurse-joy-treatment | 35.90초 | 기존 역할 적용·치료기 연결·치료·복귀 전체 과정 보존 |
| dnpc-bed-assignment | 18.80초 | 기존 침대 지정·저장·수면 과정 보존 |
| remnant-place-and-read | 19.75초 | 기존 메시지 마커 배치·본문 저장·읽기 과정 보존 |
| npc-appearance | 약 10.15초 | 실제 Appearance & Model에서 Scale 1.15로 변경·저장·월드 확인 |

| battleworks-first-attack | 약 8.41초 | 생성·저장·적용한 Wide Sweep의 실제 접촉 피해, 서버 체력 20→16 |

신규 장면은 NeoForge 1.21.1 / DRM 0.3.1 / DNPC 0.1.3 / BattleWorks 0.1.6으로 별도 촬영 월드에서 기록했다. 촬영 도구가 실제 편집 화면과 서버 요청을 조작했으며 수동 마우스 녹화나 NPC 생성 전체 과정으로 표현하지 않는다. 대화 예제 준비와 전투 설정은 녹화 전에 수행했다. BattleWorks 클립은 피해 발생을 검증한 자료다. 기본 생성 패턴의 애니메이션 실패 로그가 있으므로 애니메이션·공격 예고 범위·회피의 성공 자료로 취급하지 않는다. 해당 모드 구현은 변경하지 않았다.

기존 GIF는 이미 팔레트가 적용된 게시본을 입력으로 사용했다. 원본 색상을 복원하거나 프레임을 합성하지 않았고, 과정 누락과 속도 변경을 피하기 위해 기존 길이를 유지했다. 세 변환본의 WebM 합계는 1,564,805바이트로, 원래 GIF 12,880,823바이트보다 약 87.9% 작다. 브라우저는 WebM을 우선 사용하고 MP4로 호환 재생한다. 두 형식을 동시에 다운로드하도록 구성하지 않았다.

## 표시와 검증

- 자동 재생·무음·무한 반복·모바일 인라인 재생과 기본 재생 조작을 제공한다. 시스템의 동작 줄이기가 활성화된 경우 자동 재생을 멈추고 수동 재생을 허용한다.
- 첫 프레임 PNG를 포스터로 제공하고 1280×720 크기를 예약한다. 환경 배지와 기존 다국어 캡션을 보존했다. Forge 문서에 쓰인 NeoForge 영상도 영상 캡션에 실제 촬영 환경을 명시한다.
- `scripts/encode-guide-video.py`: GIF 또는 타임스탬프가 있는 실제 PNG 프레임을 인코딩한다. 모든 출력 영상을 FFmpeg로 끝까지 디코딩하고 자산별 해시·길이·크기를 기록했다.
- `npm.cmd run build`, `npm.cmd run verify`, `npm.cmd run verify:translations`: 문서·영상·포스터·환경·배포 경로와 번역 일치 검증.
- `npm.cmd run verify:videos`: 80개 데스크톱/모바일 화면과 고유 영상 6개에서 실제 자동 재생, 디코딩 프레임 증가, 탐색, 일시정지, 반복 경계, MP4 호환 재생 및 동작 줄이기를 확인했다. 이전 GIF 전용 검사 두 개는 이 검사로 대체했다.
- `docs/evidence/guide-videos-20261106/`: 인코딩 영수증, 실제 환경/JAR 해시, 서버 검증 기록, 대표 프레임과 브라우저 결과.

## 복구와 정리
