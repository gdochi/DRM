## 요구 사항과 편집기

차량 AI는 SuperbWarfare 0.8.9 final, Minecraft 1.20.1 빌드 `6effe4385`용 선택형 연동입니다. 크리에이티브 모드에서 `DW Npc Core`를 들고 지원 차량을 우클릭하면 NPC 편집기와 분리된 서버 판정 차량 편집기가 열립니다.

DW는 원본 엔진의 `processInput` 또는 비행 입력을 사용합니다. SuperbWarfare가 엔진 물리, 속도, 충돌, 에너지, 포탑, 무장, 재장전, 발사체, 사운드를 계속 담당하며 DW는 위치·회전·속도를 직접 덮어쓰지 않습니다. AI 차량에 플레이어가 타면 안전을 위해 하차되므로 직접 운전하려면 먼저 AI를 끄세요. 차량 편집기로 배치한 CustomNPC 승무원은 탑승 상태를 유지할 수 있습니다.

## 이동 모드

| 대기 모드 | 동작 |
| --- | --- |
| `Stationary` | 전투나 명시적 명령이 없으면 저장 위치를 지킵니다. |
| `Area Patrol` | 홈 반경의 여러 구역을 분산 선택하고 최근 방문 구역을 피합니다. |
| `Return Only` | 홈으로 복귀한 뒤 대기합니다. |
| `Route Patrol` | 저장 지점을 순서대로 돌며 설정한 지점 대기 시간을 적용합니다. |

전투 이동은 `Hold Position`, `Advance`, `Retreat`으로 따로 정합니다. 최소 사거리 유지가 켜져 있으면 기준 무장이 너무 가깝거나 포탑 하향각으로 맞출 수 없는 타겟에서 잠시 후퇴할 수 있습니다.

### 지상·수상 이동

바퀴·궤도·선박 프로필은 차체 폭과 길이, 회전 반경, 단차, 경사, 지지면, 장애물, 물 경계와 끼임 복구를 분리해 처리합니다. 경로는 로드된 지형에서 제한된 탐색량으로 계산합니다.

0.2.7의 Area Patrol은 현재 위치 주변의 작은 원을 반복하지 않고 홈 기준 8개 구역을 평가해 의미 있는 이동 거리를 선택합니다. 가속과 제동은 남은 거리, 현재 속도, 정지 가능 거리, 선회량과 장애물 상태에 따라 램핑되므로 짧은 이동에서 전출력 급출발을 반복하지 않습니다.

### 헬리콥터와 고정익

헬리콥터는 원본 로터 출력과 마우스 입력으로 이륙, 고도 유지, 전진·제동, 장애물 상승, 목적지 접근, 호버, 홈 반경 복귀를 수행합니다. Area Patrol은 충분한 반경에서 긴 호를 연결해 짧은 점마다 완전히 멈추지 않습니다.

고정익은 원본 스로틀·피치·롤·랜딩기어 입력으로 지상 활주, 이륙, 상승, 순항, 접근, 지형 회피와 목적지 주변 선회를 수행합니다. 고정익은 공중 정지가 불가능하므로 `Pause movement before fire`를 지원하지 않으며, 작은 반경이나 좁은 지형보다 충분한 선회 공간이 필요합니다.

## 인식과 타겟

차량 타겟은 엔티티 ID, 요구/제외 스코어보드 태그, 팩션 규칙, 소유자·팀·아군 보호를 조합합니다. 인식에는 감지 반경, 수평 시야각, 반응 지연, 근거리 감지, 피격 반응, 팩션 방어, 타겟 기억과 소리 감지가 있습니다.

`Nearest`는 거리순으로 선택합니다. `Custom`은 보병·생명체, 지상·수상 차량, 공중 차량의 가중치와 반격 보너스, 현재 타겟 유지, 거리, 전환 격차를 함께 평가합니다. `dochi_warfare_vehicle_target` 태그는 명시 타겟을 표시하지만 소유자·팀·팩션·사거리·아군 사격 검사를 우회하지 않습니다.

## 무장과 가상 탄약

무장 사용 여부는 `Weapons` 페이지가 관리합니다. 각 원본 무장은 다음 값을 독립적으로 가집니다.

* ON/OFF와 0~100 선호도
* 정확도와 보병·지상/수상·공중 대상 범주
* 엔티티·팩션·태그·차량 내구도 조건
* 원본/기본 또는 수동 최소·최대 사거리
* 사격 전 이동 일시정지(고정익 제외)와 대기 틱
* 글로벌 탄약 상속 또는 무장별 무한/제한 탄약, 탄창, 예비 탄, 재장전 시간
* 항상 활성 또는 연결 좌석의 CustomNPC 승무원 요구

`Weapon use mode`는 ON이고 현재 조건을 만족하는 무장만 대상으로 공격 기회마다 1개, 지정 개수, 또는 사용 가능한 모든 무장을 고릅니다. OFF 무장은 사거리 기준과 후보 선택에도 참여하지 않습니다.

탄약은 DW 가상 데이터이며 실제 탄약·탄창 아이템을 만들지 않습니다. 0.2.7는 벨트식 무장의 가상 장전탄을 SuperbWarfare 네이티브 발사 가능 판정과 동기화하고, 원본 발사 뒤 소비된 탄수를 다시 반영합니다.

## NPC 승무원

`Crew` 페이지는 차량 좌석을 상면 또는 측면 지도로 표시합니다. 좌석을 선택하면 위치, 점유 상태, 운전석·포탑·무장 스테이션·일반 승객 역할, 숨김 모델과 손 아이템 표시 조건을 확인할 수 있습니다.

빈 좌석의 `Board NPC`에서 다음 공급원을 선택할 수 있습니다.

* 서버 Entity Clone Library의 NPC JSON 클론
* 플레이어의 메인 인벤토리·방어구·보조손에 있는 NPC 소울스톤

서버는 크리에이티브 권한, 64블록 이내 거리, 좌석 상태, NPC 종류, 클론 경로, 소울스톤 슬롯과 팩션 적대 여부를 다시 검사합니다. 새 NPC는 UUID·위치·소유권·전투 상태를 정리한 뒤 정확한 좌석에 배치됩니다. 편집기에서 하차시킬 수 있는 대상은 CustomNPC 승무원뿐입니다.

## 프로필, 소울스톤, 클론

`Save As`와 `Load`는 재사용 차량 AI 프로필을 아래에 저장합니다.

```text
config/dochi_warfare/vehicle_ai/profiles/
```

프로필에는 현재 엔티티 신원과 월드 위치 상태가 포함되지 않습니다. 빈 CustomNPCs 소울스톤은 지원 SuperbWarfare 차량을 담았다가 원본 데이터와 DW 설정을 유지해 배치할 수 있습니다. `Clone`은 정리된 서버 차량 템플릿을 저장하며, `DW Npc Core`로 허공을 우클릭해 클론 보관함에서 소환합니다.

## 운영자 명령어

명령어는 권한 레벨 2가 필요합니다. 24블록 안의 SuperbWarfare 차량을 직접 바라본 뒤 사용합니다.

```text
/dw vehicle_ai enable
/dw vehicle_ai disable
/dw vehicle_ai wander
/dw vehicle_ai guard
/dw vehicle_ai engage
/dw vehicle_ai move_to_me
/dw vehicle_ai return_home
/dw vehicle_ai patrol_add
/dw vehicle_ai patrol_clear
/dw vehicle_ai status
```

일반 제작은 GUI가 우선입니다. 명령어는 라이브 운영, 빠른 지시와 상태 진단에 사용하세요.
