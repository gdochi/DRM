## 페이즈를 나누는 기준

페이즈는 단순히 체력이 줄었을 때 공격을 늘리는 기능이 아니라, **전투 리듬을 바꾸는 구간**입니다.

| 기준 | 사용 예 |
| --- | --- |
| 체력 | 70%, 40%, 15% 구간에서 패턴 변경 |
| 거리 | 근거리와 원거리 패턴 분리 |
| 시간 | 일정 시간마다 강제 패턴 실행 |
| 상태 | 패링 당함, 경직, 분노 상태 등 |

## 패턴 빈도 조절

- 강한 패턴은 쿨다운을 길게 둡니다.
- 플레이어에게 반응 시간이 필요한 패턴은 선딜을 명확히 둡니다.
- 연속 패턴은 회피 가능한 빈틈을 의도적으로 넣습니다.
- 페이즈 전환 직후에는 즉시 사망급 패턴을 피합니다.

## 테스트 기준

1. 같은 장비 기준으로 5회 이상 반복 테스트합니다.
2. 초보자와 숙련자 기준을 따로 잡습니다.
3. 서버 지연이 있을 때도 회피 가능한지 확인합니다.
4. 패링, 넉백, 상태 이상이 페이즈 전환을 깨지 않는지 확인합니다.
