## 현재 설치 기준

DRM **0.3.1**은 Forge 1.20.1 / Java 17, Fabric·NeoForge 1.21.1 / Java 21과 별도 Fabric·NeoForge 26.3 / Java 25 빌드로 나뉩니다. 서버와 클라이언트에 같은 Minecraft·로더의 수정본을 설치하세요. 이 안내는 **2026-10-31 로컬 소스와 배포 JAR** 기준입니다.

DRM과 DNPC는 서로 선택 연동입니다. 각 애드온의 필수 모드는 별도로 확인하며 모든 모드의 버전 번호를 같게 맞추지 않습니다. 26.3에서는 CustomNPCs를 영구 제외합니다. [26.3 기능 범위](#core-fabric/minecraft-26-3)도 확인하세요.

## 대화 GUI에 독립 텍스트 상자 만들기

0.3.0에서 추가한 기능을 포함합니다. 제작용 GUI Maker의 **대화 GUI**에서 본문·화자 표시와 별개인 텍스트 상자를 여러 개 배치할 수 있습니다.

1. GUI Maker에서 대화 GUI를 열고 **Text / 텍스트**를 추가합니다.
2. **Content / 표시 내용**에서 **Direct input / 직접 입력** 또는 **NPC name / NPC 이름**을 고릅니다.
3. 위치·크기·배경·테두리를 정합니다. NPC 이름 표시로 바꾸어도 직접 입력한 문장은 보존됩니다.
4. 기본 제공 GUI는 보호된 템플릿이므로 **Save As**로 사용자 파일을 만듭니다.
5. 대화 문서에 해당 GUI를 연결하고 실제 대화에서 확인합니다.

플레이어 대화 화면의 NPC 이름은 현재 대화 대상에서 읽으며 이름 변경도 반영합니다. 대상이 없으면 빈 이름이 되고, 제작 화면의 예시 이름은 실제 NPC 데이터가 아닙니다. 기존 본문·화자 컴포넌트도 계속 사용할 수 있습니다.

JSON 참고: 일반 `text` 컴포넌트에 `textSource: literal` 또는 `textSource: npc_name`을 저장합니다. 이 값이 없거나 알 수 없는 값이면 직접 입력한 텍스트로 처리합니다.

## DNPC와 애드온 연결

- **트레이너 이동:** 기존 1.20.1·1.21.1 대상의 NPC 제어 API에 일시적 이동 허용을 추가했습니다. 호환 DNPC·Cobblemon Editor와 함께 사용하면 DNPC 위치 고정을 켠 채 트레이너 대시·복귀를 사용할 수 있습니다. 일반 외부 제어가 항상 위치 고정을 해제하는 것은 아닙니다.
- **대화 결과와 저장 검사:** Fabric·NeoForge 1.21.1에서 애드온이 대화 완료·취소·ESC·선택지 없음의 종료를 구분하고 잘못된 설정을 저장 전에 검사할 수 있습니다. 코블몬의 [Sequential 설정](#drm-cobblemon-editor/cobblemon-trainer-editor)과 연결됩니다.
- **기존 기능:** 선택적 NPC 외형, [v3 복제 템플릿](#dochi-npc-core/npc-core-templates), Admin 트레이너 기록 정리는 [0.2.9 기록](#core-fabric/release-notes-0-2-9)을 이어받습니다.

코블몬의 최신 기능을 함께 쓰려면 DRM·DNPC·Cobblemon Editor를 해당 로더의 최신 수정본으로 교체합니다. 이는 확인한 기능 조합 안내이며 모든 과거 Core가 비호환이라는 새 최소 버전 선언은 아닙니다.

## 교체와 확인

설정과 월드를 함께 백업하고 기존 JAR을 교체한 뒤, 대화·상점·퀘스트와 사용하는 애드온을 확인하세요. 파일 저장과 NPC Apply는 별도 작업입니다. 같은 버전 번호 안에도 수정본이 있으므로 서버·클라이언트의 실제 파일을 맞춥니다.

0.3.1 버전 갱신 당시에는 0.3.0의 실행 클래스·자원을 보존했습니다. 독립 텍스트 상자의 기존 실기 검증과 이후 애드온 수정의 검증 범위를 구분하며, 버전 변경 자체를 전체 게임플레이 재검증으로 안내하지 않습니다. 26.3의 기존 월드 이행·전체 포팅 검증 범위도 그대로 구분합니다.
