## 요구 환경

| 구성 요소 | 요구 또는 역할 |
| --- | --- |
| Minecraft | 1.20.1 |
| Forge | 47 이상 |
| Java | 17 |
| dochi spawn control | 클라이언트와 서버 양쪽에 같은 빌드 설치 |
| DRM Core | 0.1.4 이상 선택 사항. 공용 에디터 선택기와 DRM UI 연동 |
| CustomNPCs | 1.20.1 이상 선택 사항. 저장 클론 스폰에 필요 |
| Dochi’s Warfare | 0.2.5 이상 선택 사항 |

일반 등록 몹만 다룬다면 CustomNPCs는 필요하지 않습니다. CustomNPCs 클론 규칙을 사용하려면 클라이언트와 서버에 CustomNPCs를 설치하고, 서버에 같은 탭과 이름의 저장 클론이 있어야 합니다.

## 설치

1. 서버와 접속할 클라이언트를 종료합니다.
2. `drm_spawn_control-<version>.jar`를 서버와 클라이언트의 `mods/`에 각각 넣습니다.
3. 같은 이름의 구버전 JAR이 함께 있지 않은지 확인합니다.
4. 서버와 클라이언트를 다시 시작합니다.
5. 서버 로그에서 `dochi spawn control loaded` 메시지와 로드 오류가 없는지 확인합니다.

DRM Core가 정상 연결되면 로그에 DRM 통합 UI 모드와 에디터 등록 메시지가 남습니다. DRM API 연결에 실패해도 전용 키 방식은 유지됩니다.

## 에디터 열기

다음 세 경로를 사용할 수 있습니다.

| 경로 | 사용법 |
| --- | --- |
| 전용 키 | 기본 `K`. Minecraft 키 설정에서 `스폰 컨트롤 열기`를 변경할 수 있습니다. |
| DRM 에디터 선택기 | DRM Core가 설치되고 API가 연결된 경우 `Spawn Control` 항목을 엽니다. |

편집 권한은 OP 2레벨 또는 크리에이티브입니다. 권한이 없으면 서버가 화면 요청과 저장을 거부합니다.

## 첫 규칙 만들기

처음에는 원본 스폰을 유지한 상태로 단순한 규칙 하나를 시험하는 것이 안전합니다.

1. 왼쪽 `엔티티 / 클론 카탈로그`에서 대상을 선택합니다.
2. 가운데가 `선택 대상` 보기인지 확인합니다.
3. 해당 대상에 규칙이 없으면 `규칙 추가`를 누릅니다.
4. 오른쪽 `기본 정보`에서 알아보기 쉬운 이름과 고유한 `프로필 ID`를 지정합니다.
5. `차원`과 `바이옴`은 비워 두어 전체 허용으로 시작합니다.
6. `스폰 확률`은 시험하기 쉬운 값으로, `검사 간격 틱`은 서버 부하를 고려해 설정합니다.
7. 대상에 맞는 `배치 방식`을 고릅니다. 육상 몹은 `지상`, Glow Squid 같은 수중 몹은 `수중`이 기준입니다.
8. 규칙 행 오른쪽 스위치 또는 일괄 `활성화`로 프로필을 켭니다.
9. 상단 `저장`을 눌러 서버에 적용합니다.
10. `고급 진단`의 `현재 위치 검사`로 조건을 확인합니다.

`몹 1개 생성`은 실제 월드에 관리 엔티티를 만듭니다. 2단계 확인 뒤 사용하고, 시험이 끝나면 `생성 개체 정리`를 누르세요.

## 원본 스폰 전환 순서

새 관리 규칙을 만들자마자 원본 스폰을 끄면 잘못된 조건 때문에 대상이 전혀 등장하지 않을 수 있습니다.

1. `원본 스폰: ON` 상태에서 관리 규칙을 저장합니다.
2. 현재 위치 검사와 실제 시험 생성으로 조건과 배치를 확인합니다.
3. 자연 스폰이 일정 시간 정상 동작하는지 확인합니다.
4. 원본 방식을 완전히 대체할 때만 `원본 스폰: OFF`로 바꾸고 다시 저장합니다.

:::warning 중복 스폰
원본 스폰과 활성 관리 규칙이 동시에 켜져 있으면 두 방식에서 모두 생성될 수 있습니다. 화면의 중복 경고는 오류가 아니라 현재 정책 조합을 알리는 안내입니다.
:::

## CustomNPCs 클론 첫 규칙

1. CustomNPCs에서 서버 클론을 먼저 저장합니다.
2. 에디터 카탈로그의 클론 목록에서 탭과 이름을 확인합니다.
3. 클론 행을 선택하고 `규칙 추가`를 누릅니다.
4. 일반 몹과 같은 방식으로 조건과 제한을 설정합니다.
5. 저장 뒤 클론 미리보기와 진단 결과를 확인합니다.

클론 프리셋은 클론 데이터 자체를 포함하지 않습니다. 다른 서버로 공유할 때는 동일한 CustomNPCs 클론도 별도로 배포해야 합니다.
