## DRM이 다루는 범위

DRM은 CustomNPCs 기반 서버 제작을 더 빠르게 하기 위한 런타임과 제작 도구 묶음입니다. 이 위키는 모드를 설치하는 사람, 에디터로 JSON을 만드는 사람, 서버에서 콘텐츠를 운영하는 사람을 모두 대상으로 합니다.

| 영역 | 설명 | 주요 독자 |
| --- | --- | --- |
| 런타임 | GUI, 대화, 상점, 조건, 액션을 게임 안에서 실행합니다. | 서버 운영자 |
| 에디터 | GUI Maker, Dialogue Editor, NPC Shop 같은 제작 도구를 제공합니다. | 콘텐츠 제작자 |
| 데이터 | JSON, 이미지 경로, StoredData, 화폐 규칙을 관리합니다. | 제작자와 운영자 |

## 문서 작성 원칙

- 기능 설명보다 실제 제작 흐름을 우선합니다.
- 경로, 파일명, ID 규칙은 표로 고정해서 찾기 쉽게 둡니다.
- 예제는 바로 복사해서 바꿀 수 있는 작은 단위로 작성합니다.
- 아직 개발 중인 기능은 안정 기능과 분리해서 표시합니다.

:::tip 추천
처음 읽는 사람은 빠른 시작, 설치 준비, 폴더와 경로, 핵심 개념 순서로 보면 됩니다.
:::
