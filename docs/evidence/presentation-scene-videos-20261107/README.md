# Presentation and Scene Maker tutorials

Seven original game recordings with English tutorial annotations. The production mods were not changed. See `../../presentation-scene-guide-videos-2026-11-07.md` for scope, workflows and reproduction.

- `videos.json` and `*-encode.json`: selected runs, original timing and output hashes.
- `capture/`: twelve representative original frames per clip, contact sheets and hashes for every recorded frame.
- `runs/`: exact environments, native action traces, saved/editor state and client logs. The Region run includes an unrelated rejected Label attempt; only its successful Region segment was published.
- `saved/` and `workflow-checks.json`: actual UI-saved files and checked values, including completed server scene playback.
- `browser/`: 70 desktop/mobile video checks, seven recordings, Korean layout captures and results.
- `final-compile.log`: final capture fixture compilation.
- `cleanup.json`: removed workspace-owned temporary runs and tools; final evidence and backups remain.
