## 노드 단위

대화는 노드 단위로 진행됩니다. 한 노드는 NPC가 말하는 한 장면이라고 보면 됩니다. 노드 안에는 대사, 선택지, 조건, 액션 정보가 들어갑니다.

| 노드 타입 | 사용 위치 | 특징 |
| --- | --- | --- |
| `start` | 대화 시작 지점 | 플레이어에게 직접 보이는 대사보다 route 분기에 집중합니다. |
| `general` | 실제 대화 장면 | 대사, 선택지, 선택지 조건, 선택지 액션을 가집니다. |

하나의 대화 세트에는 `start` 노드 하나와 여러 `general` 노드가 들어갑니다. `start` 노드는 세트의 입구이므로 여러 개를 만드는 대상이 아니라, 여러 route를 넣어 첫 흐름을 나누는 대상입니다.

## start 노드

`start` 노드는 대화의 입구입니다. 플레이어가 NPC를 우클릭하면 먼저 `start` 노드의 route가 평가되고, 조건에 맞는 일반 노드로 넘어갑니다. 플레이어가 실제로 읽는 대사 화면은 보통 그 다음에 열린 일반 노드입니다.

| route 필드 | 의미 |
| --- | --- |
| `goto` | 조건이 맞을 때 이동할 노드입니다. |
| `conditions` | 이 route를 사용할 수 있는 조건입니다. |
| `mode` | 여러 조건을 `and`로 볼지 `or`로 볼지 정합니다. |
| `actionType` | `goto`, `go_shop`, `close` 같은 시작 동작입니다. |
| `linkMode` | 같은 문서 내부 연결인지 외부 경로인지 구분합니다. |

여러 route가 있으면 위에서부터 조건을 평가해 맞는 흐름을 고릅니다.

## 일반 노드

일반 노드는 실제로 플레이어에게 보이는 대화 장면입니다.

| 필드 | 의미 |
| --- | --- |
| `name` 또는 노드 키 | 노드 식별 이름입니다. |
| `type` | 보통 `general`입니다. |
| `text` | NPC 대사입니다. |
| `textTranslationKey` | `text`를 번역 키로 볼지 정합니다. |
| `conditions` | 이 노드에 진입 가능한 조건입니다. |
| `choice` | 플레이어 선택지 배열입니다. |
| `textFx` | 대사 표시 효과나 사운드 연결 정보입니다. |

## 선택지

선택지는 `choice` 배열에 들어갑니다.

| 필드 | 의미 |
| --- | --- |
| `label` | 플레이어에게 보이는 선택지 문구입니다. |
| `labelTranslationKey` | `label`을 번역 키로 볼지 정합니다. |
| `conditionMode` | 선택지 조건 평가 방식입니다. |
| `conditions` | 선택지가 보일 조건입니다. |
| `actions` | 선택지를 눌렀을 때 실행할 액션 배열입니다. |
| `fx` | 선택지에 붙는 이미지, 아이템, 사운드 같은 표시 효과입니다. |

선택지는 조건을 통과한 것만 화면에 표시됩니다. 선택지가 보였더라도, 액션은 선택지를 클릭했을 때 실행됩니다.

## 선택지 설계 기준

| 목적 | 구성 |
| --- | --- |
| 다음 대사로 이동 | 선택지 `actions`에 `goto`를 넣습니다. |
| 상점 열기 | 선택지 `actions`에 `go_shop`을 넣습니다. |
| 대화 닫기 | 선택지 `actions`에 `close`를 넣습니다. |
| 보상 지급 후 이동 | `item` 또는 `tag`를 먼저 넣고 마지막에 `goto`를 넣습니다. |
| 조건부 선택지 | 선택지 `conditions`에 `tag`, `item`, `advancement` 등을 넣습니다. |

## 제한

- 선택지 배열 이름은 현재 문서 기준 `choice`입니다. 예전 형식처럼 `choices`로만 작성하면 에디터가 의도대로 다루지 못할 수 있습니다.
- 선택지는 화면 표시 단위입니다. 선택지를 눌렀을 때의 실제 결과는 `actions`가 담당합니다.
- 한 선택지에서 여러 화면 이동 액션을 동시에 넣으면 앞의 이동 액션이 흐름을 결정할 수 있으므로 역할을 분명히 나누는 편이 좋습니다.
