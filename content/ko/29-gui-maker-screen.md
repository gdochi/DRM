## 화면 구성

GUI Maker는 화면의 모양을 만드는 편집기입니다. 에디터는 도구 목록, 캔버스, 선택 요소 인스펙터, 파일 불러오기/저장 패널을 중심으로 동작합니다.

| 구역 | 역할 |
| --- | --- |
| 상단 버튼 | 에디터 이동, 새 GUI, 불러오기, 저장, 저장 이름 변경, 초기화를 담당합니다. |
| GUI 타입 선택 | `dialogue`, `npc_shop`, `currency_hud`, `remnant_msg` 중 작업 대상을 고릅니다. |
| 도구 목록 | 현재 GUI 타입에서 사용할 수 있는 컴포넌트를 보여줍니다. |
| 캔버스 | 실제 화면에 배치될 요소를 시각적으로 편집합니다. |
| 인스펙터 | 선택한 요소의 위치, 크기, 색상, 텍스트, 이미지, 역할을 편집합니다. |

## GUI 타입 선택

GUI 타입은 저장되는 문서의 의미를 결정합니다.

| 타입 | 만드는 화면 |
| --- | --- |
| `dialogue` | NPC 대화 화면 |
| `npc_shop` | 구매/판매 상점 화면 |
| `currency_hud` | 화폐 HUD 레이아웃 |
| `remnant_msg` | 레머넌트 메시지 화면 |

타입이 다르면 사용할 수 있는 컴포넌트도 달라집니다. 예를 들어 `choice`는 대화 GUI에서 의미가 있고, `item_slot`은 상점 GUI에서 의미가 있습니다.

## 저장과 불러오기

| 버튼 | 기능 |
| --- | --- |
| `Create New` | 현재 GUI 타입의 새 문서를 만듭니다. |
| `Load` | 현재 타입에 맞는 GUI JSON을 검색해서 불러옵니다. |
| `Save` | 현재 문서를 기존 파일에 저장합니다. |
| `Save As` | 새 파일명으로 저장합니다. |
| `Reset` | 타입별 기본 GUI로 되돌립니다. |

일반 화면 GUI는 `config/dochi_rpg_maker/gui`에 저장됩니다. `currency_hud`는 HUD 세트 저장소를 사용할 수 있으므로 HUD Maker 문서와 함께 봐야 합니다.

## 캔버스에서 조정하는 값

| 값 | 설명 |
| --- | --- |
| 위치 | 화면 기준 x, y 좌표입니다. |
| 크기 | 요소의 너비와 높이입니다. |
| z 순서 | 앞뒤 렌더링 순서입니다. |
| 정렬 | 텍스트나 목록이 요소 안에서 배치되는 방식입니다. |
| 색상 | 배경, 테두리, 글자, 강조 색상입니다. |
| 이미지 | 리소스 텍스처나 로컬 이미지 경로입니다. |
| 역할 | 상점 버튼, 선택지, 상품 행처럼 런타임 데이터와 연결되는 의미입니다. |

## 제한

- GUI Maker는 데이터의 모양을 정합니다. 데이터 자체는 각 에디터에서 만들어야 합니다.
- 컴포넌트를 다른 GUI 타입에 억지로 넣어도 런타임 의미가 생기지는 않습니다.
- 이미지 리소스는 Minecraft 리소스 위치 규칙을 따라야 합니다.
- 기본 GUI를 수정한 뒤 그대로 저장하면 업데이트 기본값과 구분이 어려워지므로 별도 파일로 저장하는 편이 좋습니다.
