## 최신 작업 안내

액션 검색·일반/군용 일정·탑승·일정 상점은 [시간표 안내](#dochi-npc-core/npc-core-schedules), 재료·도구·연료와 선택 조리 애드온은 [조리 작업](#dochi-npc-core/npc-core-cooking)에서 확인하세요. Immersive Melodies 연주는 잘못된 곡 재생과 재개 처리를 수정했습니다.

## 외형과 장비

NPC 제작 화면에서 인간형 Steve/Alex, Gecko 모델 또는 설치된 엔티티의 시각 모델을 고릅니다. 스킨은 리소스·서버 PNG·URL·지원되는 플레이어 스킨 검색 경로를 사용합니다. 이름표, 보스바, 부위 비율, 장비와 사망 드롭을 따로 설정하세요.

포저는 키프레임·보간·반복과 상황별 포즈 연결을 담당합니다. 장비 확률 목록은 슬롯별 후보와 확률을 정하는 제작 설정이며 플레이어의 실제 인벤토리 조작과 구분합니다.

## 시간표와 실제 작업

1. 데이사이클에서 시간 구간과 행동을 추가합니다.
2. 작업 종류를 고르고 위치·범위·대상 필터를 정합니다.
3. 도구와 실제 운반 인벤토리, 목적지 컨테이너를 준비합니다.
4. 테스트 시간대에 채굴·농사·벌목·수집·운반·사냥·순찰·따라가기 등의 행동을 확인합니다.

채굴 필터는 블록 ID와 `#태그`를 사용하며 허용·제외 방식을 구분합니다. 필요한 도구, `mobGriefing` 정책, 대상 블록·컨테이너 접근과 경로가 맞아야 실제 작업합니다. 시각적인 작업 모션만으로 아이템 생산이 완료된 것으로 보지 마세요.

집·거주·수면과 Rest 설정은 시간표에 연결합니다. 외부 전투 AI가 NPC 제어권을 빌린 동안에는 해당 연동의 제어 정책을 따릅니다.

## 모집 NPC와 플레이어 고용

이 흐름에는 DRM의 결제·시간·Function API가 필요합니다.

1. 작업·외형·장비를 완성한 DNPC 세트를 저장합니다.
2. DRM 에디터 선택기의 고용 에디터에서 모집 JSON을 만듭니다.
3. 모집 항목별 DNPC 세트, 시작 위치, 비용·기간, 허용 작업과 고용주 편집 권한을 정합니다.
4. 모집 담당 DNPC의 **NPC Apply → Function → NPC 고용**에 JSON을 적용합니다. 파일 저장만으로 연결되지 않습니다.
5. 플레이어는 모집 NPC와 상호작용해 비용과 위치를 확인하고 고용합니다.
6. 기본 `H`의 **내 고용**에서 작업·정지·복귀·갱신·해고와 화물 회수를 진행합니다.

고용주에게 허용된 작업 설정과 운영자용 NPC 편집 권한은 다릅니다. 계약이 끝나도 남은 실제 화물을 회수할 때까지 NPC가 보존됩니다. 모집 JSON 변경이 이미 체결한 계약의 비용·기간·권한을 소급 변경하지 않습니다.

## 위치·회전·피해 고정

이동 AI의 **위치 고정**은 저장한 현재 위치를 유지하며 배회·중력·밀림·넉백과 수면·탑승 이동을 막습니다. 호환 Cobblemon Editor의 대시·복귀가 일시 이동을 요청한 동안에는 고정을 유예하고 종료 후 다시 고정합니다. 몸 좌우·고개 좌우·고개 상하 각도와 회전 고정은 위치 고정과 독립입니다. 좌우는 -180.0~180.0도, 상하는 -90.0~90.0도로 소수점 첫째 자리까지 설정합니다. 고정 회전은 자동 시선보다 우선합니다.

전투 AI의 **무적**은 크리에이티브 공격도 막습니다. 무적을 꺼도 **플레이어 피해 허용**을 끄면 플레이어 근접·플레이어 원인 투사체와 폭발 피해를 차단합니다. 설정을 저장한 뒤 실제 NPC에서 확인하세요. 유휴 상태의 주변 플레이어 바라보기는 작업·전투·상호작용·수면보다 낮은 우선순위입니다.

## 시간 입력과 이름 반영

시간표의 시작·종료는 하루 `0~23999`틱입니다. `0=06:00`, `6000=12:00`, `12000=18:00`, `18000=00:00`를 기준으로 입력합니다. 시간 구간 이름 옆 **✓**는 현재 폼을 목록에 반영합니다. NPC에 최종 저장하는 기존 Save 흐름은 별도로 마쳐야 합니다.

## 악기 연주 — 1.20.1·1.21.1

선택 모드 **Immersive Melodies**가 있으면 시간표의 악기 연주를 사용합니다. **장착한 악기만 사용**은 지정 손에 실제 악기가 있어야 합니다. **없으면 임시 악기 지급**은 선택한 임시 악기를 연주할 때만 표시하고 실제 장착 악기가 있으면 그것을 우선합니다. 🔍는 실제 악기만 선택하며 플레이어 아이템을 가져오지 않습니다.

연주 종료·일정 종료·상호작용·편집·사망 때 임시 표시와 소리를 정리합니다. 임시 악기는 장비 저장이나 사망 드롭으로 남지 않습니다. 0.8.0의 기존 세 로더에서 검증한 연동이며 이 설명은 26.3 악기 연동 검증을 뜻하지 않습니다.
