## Structure

| Unit | Purpose |
| --- | --- |
| Set | Groups related nodes. |
| Node | Holds one conversation moment. |
| Choice | Defines what the player can select. |
| Route | Handles automatic movement or conditional branches. |

Build the base path first, then add conditions and actions.
