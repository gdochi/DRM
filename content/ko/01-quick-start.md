## 첫 실행 순서

1. Minecraft 인스턴스의 `mods` 폴더에 필요한 모드를 넣습니다.
2. 테스트할 월드에 접속합니다.
3. DRM 또는 Dochi Editor 화면을 엽니다.
4. 설치 대상이 현재 인스턴스와 월드를 가리키는지 확인합니다.
5. 샘플 GUI, 대화, 상점 중 하나를 설치하거나 직접 만듭니다.
6. JSON을 내보낸 뒤 게임 안에서 NPC 또는 명령어로 호출합니다.

## 가장 먼저 확인할 것

| 체크 | 확인 방법 | 실패 시 |
| --- | --- | --- |
| 모드 로딩 | 모드 목록에서 DRM 관련 모드가 보입니다. | 버전과 로더를 다시 확인합니다. |
| 월드 세션 | 타이틀 화면이 아니라 월드 안에 있습니다. | 월드 접속 후 다시 시도합니다. |
| 저장 경로 | `customnpcs`와 월드 폴더가 잡혀 있습니다. | 설치 대상을 다시 선택합니다. |
| JSON 출력 | Export 후 대상 폴더에 파일이 생깁니다. | 권한과 파일명을 확인합니다. |

:::warning 주의
HTML GUI나 월드별 파일은 활성 월드 경로에 들어갑니다. 다른 월드에 설치하면 에디터에서는 있어 보여도 런타임에서 찾지 못할 수 있습니다.
:::
