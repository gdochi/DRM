## What CNPC TaCZ Fire is

CNPC TaCZ Fire is an addon documentation track for making **CustomNPCs use TaCZ firearms like a player**. It focuses on shooting, reloading, stance switching, and target filtering.

## Core scope

| Feature | Description |
| --- | --- |
| Firing | NPCs shoot with assigned guns and ammo. |
| Reloading | Handles reload flow when ammunition is consumed. |
| Target Filters | Choose valid targets by tag, faction, or entity rules. |
| Stance Switching | Configure combat modes such as Auto, Ranged, or melee fallback. |

## Best for

- creators building gun-based combat servers
- users who want raiders, guards, or boss-style firearm NPCs
- operators using TaCZ together with Better Combat or faction rules
