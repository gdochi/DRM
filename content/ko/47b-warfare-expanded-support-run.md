## 저장·시험·실제 호출 구별하기

[타임라인 배치](#dochi-warfare-expanded/expanded-support-timeline)나 [지원 종류별 설정](#dochi-warfare-expanded/expanded-support-actions)을 만든 뒤 이 순서로 마무리합니다.

| 작업 | 사용하는 데이터 | 결과 |
| --- | --- | --- |
| Save / Save As | 현재 초안 | 서버의 이름 있는 JSON으로 저장 |
| Simulation | 현재 초안 | 임시 배우·차량으로 정상 속도 실행, 지형과 기존 배우 보호 |
| 운영자 명령 | 저장한 파일 | 원본 무장의 피해·월드 영향이 적용되는 실제 지원 |
| 전술 명령 아이템 | 저장된 전술이 연결한 타임라인 | 플레이어가 조준한 지점·방향으로 실제 지원 요청 |

**Simulation은 저장하지 않습니다.** 시험한 초안을 저장한 뒤 운영자 명령으로 호출하거나, [전술 명령](#dochi-warfare-expanded/expanded-tactical-orders)에 연결해 일반 플레이어에게 아이템을 지급합니다. 구버전의 상면 그림이나 “내 위치에서 실행” 버튼을 찾을 필요는 없습니다.

## 1. 이름을 정해 저장하기

1. 상단 제목에 **Road reinforcement**처럼 알아보기 쉬운 문구를 넣습니다.
2. **Save As** 아이콘을 누릅니다.
3. 파일 이름에 **tutorial_support**를 넣습니다. 제목과 파일 이름은 별개입니다.
4. 창 안의 저장 버튼을 누르고 서버의 저장 완료 상태를 기다립니다.
5. 문서 이름과 변경 표시를 확인합니다. 이후 같은 파일은 **Save / Ctrl+S**로 저장합니다.

![차량 초안을 만들고 제목·파일 이름을 따로 정해 저장한 뒤 검색·불러옵니다.](assets/media/guides/dwe-tutorials-20261109/dwe-files.mp4 "09 · Save As → tutorial_support → 저장 완료 → Load → 검색 → 항목 선택 → 불러오기. 서버 저장 파일과 다시 연 배치를 대조합니다.")

**클릭만으로 저장을 끝내지 마세요.** 저장 중·오류 상태를 읽습니다. 다른 사용자가 같은 파일을 먼저 바꿨다면 최신 파일을 다시 불러오고, 필요한 초안은 다른 이름으로 보관합니다.

새 문서·Reset·다른 파일 열기·닫기에서는 미저장 변경 확인창을 읽고 결정합니다. **Reset은 현재 문서의 저장 기준으로 복원**, **Create New는 빈 문서 만들기**입니다.

## 2. 저장한 배치 다시 열기

1. **Load**에서 파일 이름을 검색합니다.
2. 목록의 파일을 선택하고 서버의 문서 요약을 기다립니다.
3. 창 안의 **Load**로 엽니다.
4. 이벤트 수·시각·경로·중심점을 확인합니다.

**Relative coordinates로 불러오면 현재 중심에 맞춰 배치가 이동합니다.** 저장된 월드 위치를 유지하려면 **먼저 Absolute coordinates로 전환**하세요. 다른 장소에서 재사용하려면 상대 모드에서 **Center**를 먼저 지정합니다.

## 3. Simulation으로 시험하기

1. 차량 한 대처럼 확인하기 쉬운 문서로 시작합니다.
2. 상단 **Simulation**을 누릅니다. 저장 전 초안도 시험할 수 있습니다.
3. 시작 대기가 끝나고 임시 차량과 경과 시간이 보이는지 확인합니다.
4. 경로·시작 시각·수명·도달 여부를 관찰합니다.
5. **Stop**으로 이번 시뮬레이션의 임시 지원이 정리되는지 확인합니다.

![차량 경로 작성부터 실제 Simulation의 임시 차량과 Stop 정리까지 확인합니다.](assets/media/guides/dwe-tutorials-20261109/dwe-simulation.mp4 "10 · 실제 클라이언트·통합 서버의 차량 지원 시뮬레이션입니다. 운영자 명령으로 실행하는 실제 전투와 구별합니다.")

시뮬레이션은 실제 임시 엔티티와 원본 이동을 사용하고 정상 속도로 진행합니다. 중심 편집은 실행 중 잠기므로 먼저 Stop한 뒤 수정합니다.

지형과 기존 배우를 보호하므로 **시뮬레이션 피해를 실제 전투 피해 검증으로 판단하지 마세요.** NPC 준비·무기와 기체 호환성·서버 정책·목표 지형도 확인해야 합니다.

## 4. 실제 지원 호출하기

권한 레벨 **2**가 필요합니다. 예제 파일은 **tutorial_support**이며 명령에 확장자는 붙이지 않습니다.

```text
/dw callgimmicks tutorial_support
/dw callgimmicks tutorial_support ~ ~ ~
```

| 호출 | 배치 위치 |
| --- | --- |
| 좌표 생략 | 저장된 월드 위치 |
| 좌표 지정 | 저장 origin에서 호출 좌표까지의 차이만큼 모든 출발·목표·도착을 함께 이동 |

상대 명령 좌표는 **명령 실행 위치** 기준입니다. 플레이어가 실행하면 플레이어, 커맨드 블록이면 해당 블록 위치입니다. Y도 전체 높이에 반영되므로 공중·지하 기준으로 호출하지 않았는지 확인하세요.

미저장 변경은 명령에 포함되지 않습니다. 실제 호출은 Simulation의 지형 보호 시험과 다르므로 의도한 전투 장소에서 경로·원본 무장 동작을 확인합니다.

단발 폭격도 가능합니다. 기체·폭탄 ID는 설치된 모드의 명령 자동완성에서 확인합니다.

```text
/dw bombard ~ ~ ~ superbwarfare:ju_87 superbwarfare:sc_250 10
```

여기서 **10은 틱**입니다. 정상 20 TPS에서 0.5초 뒤 첫 투하입니다. 단발 명령은 점·영역을 지원하며 선은 에디터에서 만듭니다.

## 막혔을 때 확인하기

| 증상 | 먼저 할 일 |
| --- | --- |
| 지면을 눌러도 이벤트가 없음 | 배치 도구, 불러온 블록 표면, 월드 뷰 안 클릭 확인 |
| 속성이 안 보임 | 이벤트 선택, 오른쪽 패널 펼치기, 패널 안 스크롤 |
| 숫자 편집 후 작업이 안 됨 | 빈 값·−만 남은 입력 완성, 상태 오류 확인 |
| 차량·기체·무장 목록이 비어 있음 | 서버의 실제 카탈로그와 설치 조합 확인 |
| NPC가 안 움직임 | DW AI, Clone 준비 또는 Area 출발 구의 NPC, 탑승·고용·다른 이동 확인 |
| 차량 생성·이동이 막힘 | 출발 빈 공간·지형·대형 간격·실제 통과 경로 확인 |
| 도착 전에 지원이 사라짐 | 생성부터 흐르는 Lifetime 확인 |
| Load 후 위치가 달라짐 | Relative / Absolute와 현재 Center 확인 |
| 명령 결과가 초안과 다름 | 저장 완료·이름·호출 좌표·서버 정책 확인 |
| 저장 충돌 | 최신 파일을 Load하고 필요한 초안은 Save As |

## 파일과 참고용 JSON

GUI로 만드는 데 외울 필요는 없습니다. 백업·직접 편집용 참고입니다.

- 경로: `config/dochi_warfare/vehicle_ai/gimmicks/<name>.json`
- 현재 스키마: `dochi.warfare.gimmicks.v6`. v1~v5도 읽습니다.
- `origin`은 기준점, `steps`는 이벤트 목록, `at_tick`은 시작 틱입니다.
- 단계 하나에는 `bombard`, `vehicle_support`, `fire_support`, `npc_move` 중 하나가 들어갑니다.
- `lifetime_ticks`는 임시 지원 수명입니다. 상대 GUI에서도 저장 위치 필드는 월드 좌표를 유지합니다.
- `explosion_damage`·`direct_damage`는 기본 폭발·직격 HP 피해입니다. **0은 해당 성분을 0으로 설정**, 빈 입력은 원본 값을 유지합니다. 폭발 반경·지형 파괴를 바꾸지 않으며 실제 피해에는 거리 감쇠·방어가 적용됩니다.

내장 예제는 없는 파일만 설치합니다. 구버전 파일도 원본을 보관하고 **Save As**로 새 이름에 저장해 비교하세요.

[첫 폭격 만들기](#dochi-warfare-expanded/expanded-support-timeline)로 돌아가거나 [차량·기총·NPC 지원](#dochi-warfare-expanded/expanded-support-actions)을 조합해 보세요.
