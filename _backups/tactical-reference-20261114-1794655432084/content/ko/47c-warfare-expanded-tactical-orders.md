## 무엇을 하는 아이템인가요?

DWE 0.3.3의 **플레이어용 소모 아이템**입니다. 관리자는 제작자용 Tactical Orders 편집기에서 저장된 기믹 타임라인을 연결하고, 플레이어는 무전기나 태블릿으로 지면을 조준해 지원을 요청합니다. 외형만 바뀌며 두 기기는 같은 전술을 사용할 수 있습니다.

서버와 클라이언트에는 같은 DWE 빌드와 호환 DW를 설치합니다. 원본 차량·무장 모드도 필요합니다. 전술 아이템 호출은 **실제 전투**이며 Simulation의 지형 보호를 적용하지 않습니다. 아군·요청자와 지형에도 원본 무기의 피해가 갈 수 있습니다.

## 관리자: 전술을 만들고 지급하기

1. 권한 레벨 2의 관리자가 아래 명령이나 Warfare 편집기 선택 화면의 **Tactical Orders**를 엽니다.
2. 기존 전술을 불러오거나 새 문서를 만듭니다. **General**에서 저장된 기믹 ID를 연결합니다. 연결 기믹 편집은 기존 월드 편집기를 엽니다.
3. **Use & Target**에서 조준 거리·유지 시간·유지 중 이동 허용을 정합니다. **Limits**에서는 대기시간 그룹·동시 요청·허용 차원을 정합니다.
4. **Item & HUD**에서 외형과 게이지 방향·색상을 정하고 저장합니다. 전술을 켠 뒤 아이템을 발급합니다. 일반 플레이어는 이미 받은 아이템을 사용할 때 OP 권한이 필요하지 않습니다.

```text
/dw tactical editor
/dw tactical give @s light_bombardment ww2_radio 1
/dw tactical give @s tank_reinforcement rugged_tablet 1
```

## 플레이어: 조준해서 요청하기

1. 아이템을 메인핸드에 들고, 로드된 지면의 윗면을 조준합니다. 툴팁의 사거리·유지 시간·이동 허용을 먼저 읽으세요.
2. 사용 버튼을 길게 누릅니다. 지면 안내선은 미리보기이며, 목표 좌표와 방향은 **유지가 끝나는 서버 시점**에 결정됩니다.
3. 이동 금지 전술은 몸이 움직이면 취소됩니다. 시점 회전은 가능합니다. 접수 전에 버튼을 놓거나 아이템·슬롯·차원을 바꾸면 취소됩니다.
4. 서버 접수 효과와 소리를 확인합니다. 로컬 게이지 100%만으로 접수가 끝난 것은 아닙니다. 접수되면 크리에이티브에서도 아이템 한 개를 소모하고 대기시간을 시작합니다.
5. 재시도하려면 버튼을 놓고 다시 누릅니다. 접수는 명중 보장이 아니며, 접수된 지원은 아이템 교체나 로그아웃만으로 취소되지 않습니다.

같은 그룹의 전술은 **플레이어별 대기시간을 공유**하고 재접속·서버 재시작에도 유지됩니다. 외형이나 아이템을 바꿔도 초기화되지 않습니다.

## 처음 설치되는 프리셋

아래는 새로 생성되는 기본값입니다. 기존 사용자 파일은 덮어쓰지 않으므로 실제 아이템 툴팁과 서버 설정을 우선하세요. 정밀·직선·복합은 air_support, 전차는 ground_support 그룹입니다. 예제는 기본 SuperbWarfare 차량을 사용하며, 진영과 경로는 연결 기믹에서 편집합니다.

| 전술 ID | 지원 | 유지 | 거리 | 이동 | 대기시간 |
| --- | --- | --- | --- | --- | --- |
| light_bombardment | 정밀 폭격, MK-82 1발 | 1 s | 128 | 허용 | 60 s |
| line_bombardment | 직선 폭격, MK-82 4발 | 2 s | 192 | 이동 시 취소 | 90 s |
| tank_reinforcement | M1A2 2대 증원 | 2 s | 96 | 허용 | 180 s |
| combined_support | 폭격 후 M1A2 2대 지원 | 3 s | 128 | 이동 시 취소 | 240 s |

## HUD와 소리 바꾸기

**Item & HUD**에서 **Bar: Vertical / Bar: Horizontal**, **Guide color**, **Bar color**를 고릅니다. 두 색상은 별개이며 불투명 RGB를 사용합니다. 색상창의 **Apply** 후 전술도 저장하세요. 가로·세로를 동시에 표시하지 않습니다. 접수·실패는 짧은 시각·음향 효과로 알려 주므로 채팅 알림을 기다릴 필요가 없습니다.

무전기와 태블릿은 장착·사용·접수·실패 소리가 다릅니다. 사용자 소리는 JSON의 sounds 설정으로 지정하며 소리 편집 GUI는 없습니다. 리소스팩에 등록한 사운드 ID를 사용하고 직접 파일 경로나 URL을 넣지 마세요.

## 요청이 안 될 때

| 증상 | 확인할 것 |
| --- | --- |
| 전술 미지정·사용 불가 | 전술 ID, 활성화, 연결 기믹과 원본 모드 설치 확인 |
| 조준·경로 거절 | 로드된 지면, 사거리·시야, 허용 차원과 실제 진입 공간 확인 |
| 유지 중 취소 | 툴팁의 이동 규칙, 슬롯·차원 변경, 버튼 해제 확인 |
| 대기시간·동시 요청 제한 | 같은 그룹의 다른 전술과 진행 중인 지원 확인 |
| 파일 수정이 반영되지 않음 | 저장된 ID와 아래 reload 명령 확인 |
| 게이지는 찼는데 지원이 안 옴 | 서버 접수·실패 효과 확인. 원본 기체·무장과 연결 기믹 시험 |

## 파일·스크립트 참고

GUI 사용에는 JSON 필드를 외울 필요가 없습니다. 직접 편집·연동할 때만 참고하세요.

전술 파일은 **config/dochi_warfare/vehicle_ai/tactical_orders/<id>.json**, 연결 타임라인은 **config/dochi_warfare/vehicle_ai/gimmicks/**입니다. 기본 파일은 없을 때만 생성됩니다. 프리셋을 끄려면 enabled를 false로 저장하세요. 삭제하면 다음 시작 때 복원될 수 있습니다. 사용자 전술은 Save As로 별도 ID에 보관합니다. 직접 수정한 뒤에는 아래 reload를 실행합니다.

```text
/dw tactical reload
```

activation의 hold_ticks·allow_movement, targeting의 max_distance, limits의 cooldown_group·cooldown_ticks를 설정합니다. 정상 20 TPS에서 20틱은 1초입니다. hud는 bar_style·guide_color·bar_color, sounds는 외형별 equip·use·cast·fail을 사용합니다. 소리 반복은 use에만 적용합니다.

HUD 연동 개발자는 클라이언트 전용 TacticalOrderHud.renderGauge로 전술 게이지를 그릴 수 있습니다. 이것은 화면 렌더링이며 서버의 요청 접수·아이템 소모·지원 실행을 대신하지 않습니다.
