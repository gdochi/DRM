## Baixar e instalar

[ Baixe o Núcleo NPC de Dochi no CurseForge](https://www.curseforge.com/minecraft/mc-mods/dochi-s-npc-core)

Escolha sua versão Minecraft e carregador. No multiplayer, instale arquivos correspondentes no servidor e em todos os clientes. Fabric também precisa de Fabric API.

| Minecraft | Carregador | Java |
| --- | --- | --- |
| 1.20.1 | Forge | 17 |
| 1.21.1 | Fabric / NeoForge | 21 |
| 26.3 | Fabric / NeoForge | 25 |

DNPC sozinho permite que você crie, personalize e atribua trabalhos a NPCs. Adicione DRM quando quiser conversas ou lojas.

## Coloque seu primeiro NPC

1. Pegue o Núcleo na guia Criativo **NPC Core** ou use `/dnpc core`.
2. Clique com o botão direito no chão para colocar um NPC.
3. Clique com o botão direito do mouse no NPC com o Core para editá-lo.
4. Digite um nome, escolha uma pele e equipamento e salve.
5. Afaste o Núcleo e olhe para o seu NPC.

![Identity no editor DNPC 0.1.3, com categorias à esquerda, a visualização no meio e Name e Title à direita.](assets/media/guides/dnpc-013-neo1211/dnpc-identity.png "IU Inglês em NeoForge 1.21.1. Name seu NPC sob Identity → Name. Use Appearance & Model para peles e Inventory & Equipment para armadura.")

Use o controle em forma de disco **Save to NPC** após a edição. Para manter o NPC para posterior reutilização, também [salvar um modelo com Save As](#dochi-npc-core/npc-core-templates).

## Controles principais

| Entrada | Resultado |
| --- | --- |
| Clique com o botão direito no chão | Coloque um NPC |
| Clique com o botão direito do mouse em um NPC | Editá-lo |
| Ar com o botão direito do mouse | Abrir configurações globais e o poser |
| Clique com o botão esquerdo | Abrir controles de utilitário NPC |
| Segure o Núcleo na sua mão principal; Ctrl+C / Ctrl+V | Copiar / colar um NPC |
| Segure o Núcleo na sua mão principal; Ctrl+X | Apagar o NPC alvo |

Para uso repetido, [salvar um modelo](#dochi-npc-core/npc-core-templates).
