## First run

1. Put the required mods into the Minecraft instance.
2. Join the test world.
3. Open DRM or Dochi Editor.
4. Confirm the selected instance and world folders.
5. Create or install a sample GUI, dialogue, or shop.
6. Export JSON and test it in game.

:::warning Note
World-specific HTML GUI files must be installed into the active world path.
:::
