# Dochi RPG Maker 0.1.3 — What’s New

Version 0.1.3 makes it faster and easier to build RPG content directly in-game.

## New Creative Tools

- **HUD Maker** — Create custom HUD layouts, currency displays, and player status elements. You can also choose which vanilla HUD parts to hide.
- **Remnant Messages** — Place interactive messages and lore points in the world, complete with conditions, actions, and custom presentation.

## Better NPC Shops

- Choose a different payment method for individual shop items.
- Set stock limits, restock timing, and how many items return each time.
- Enjoy a cleaner shop editor with clearer sections and more consistent spacing.
- Shop previews and stock timers now look closer to the final in-game result.

## A More Useful GUI Maker

- Improved component alignment and opacity controls.
- More accurate previews for shop interfaces.
- Added support for HUD and Remnant Message layouts.

## Faster, Safer Editing

- Use **Ctrl+Z** to undo and **Ctrl+Shift+Z** or **Ctrl+Y** to redo changes in major editors.
- Open the new **?** help menu to quickly check editor shortcuts.
- Find the editor you need faster with the improved searchable editor screen.
- Save and switch between files with fewer interruptions and clearer feedback.

## In Short

0.1.3 gives you more tools to build with, better previews to trust, and an easier editing workflow from start to finish.
