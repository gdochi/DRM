## 타겟 필터가 필요한 이유

총기 NPC는 사거리와 피해량이 높기 때문에, 잘못된 대상에게 사격하면 일반 근접 NPC보다 문제가 크게 보입니다. 먼저 공격 가능한 대상을 명확히 제한해야 합니다.

| 기준 | 사용 예 |
| --- | --- |
| 팩션 | 같은 진영은 공격하지 않음 |
| 태그 | 특정 이벤트 태그가 있는 대상만 공격 |
| 엔티티 ID | 특정 몬스터나 NPC만 공격 |
| 거리 | 지정 거리 밖의 대상은 무시 |

## 추천 구성

1. 기본 적대 대상을 먼저 확인합니다.
2. 같은 팩션 제외 규칙을 둡니다.
3. 이벤트용 태그 예외를 추가합니다.
4. 보스전이나 진영전에서는 별도 필터 프리셋을 둡니다.

:::tip 추천
필터는 복잡하게 한 번에 만들지 말고, 팩션 → 태그 → 엔티티 예외 순서로 단계적으로 추가하는 편이 안전합니다.
:::
