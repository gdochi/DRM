## 대화 구조

대화는 세트, 노드, 선택지로 나눠서 생각하면 편합니다. 세트는 큰 묶음이고, 노드는 한 장면이며, 선택지는 플레이어가 고르는 분기입니다.

| 단위 | 역할 | 주의 |
| --- | --- | --- |
| Set | 관련 노드를 묶습니다. | 너무 크게 만들지 않습니다. |
| Node | NPC 대사와 흐름을 담습니다. | ID를 안정적으로 유지합니다. |
| Choice | 플레이어 선택과 이동 대상을 정합니다. | 모든 선택지에 결과가 있어야 합니다. |
| Route | 자동 이동이나 조건 분기를 처리합니다. | 시작 노드에서 특히 중요합니다. |

## 안전한 제작 흐름

1. 시작 노드 하나를 만듭니다.
2. 선택지를 두 개 이하로 붙입니다.
3. 각 선택지가 도착할 노드를 만듭니다.
4. 조건과 액션은 마지막에 추가합니다.
5. Overview와 Blueprint로 끊어진 링크를 확인합니다.
6. Export 후 테스트 NPC에서 호출합니다.

:::warning 주의
오래된 JSON이 `choices` 배열을 쓰고 새 런타임이 `choice` 배열을 기대하면 가져오기나 실행이 실패할 수 있습니다.
:::
