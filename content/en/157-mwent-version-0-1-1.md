## Public upload

MWENT first shipped publicly in Minigames **0.1.1**. CurseForge uploads on October 23, 2026 include [Fabric 1.21.1](https://www.curseforge.com/minecraft/mc-mods/dochi-s-minigames/files/9299087), [NeoForge 1.21.1](https://www.curseforge.com/minecraft/mc-mods/dochi-s-minigames/files/9299082) and [Forge 1.20.1](https://www.curseforge.com/minecraft/mc-mods/dochi-s-minigames/files/9299089). No 26.3 file appears in this version's upload list.

## Initial card catalog

The uploaded Fabric 1.21.1 file contains **263 built-in** and **89 optional-mod** definitions, **352 total**. Counting regular and animated editions gives 704 prints. The 72 cards added in the 0.1.5 workspace are excluded.

| Optional provider | Definitions |
| --- | --- |
| Cobblemon | 14 |
| L_Ender's Cataclysm | 16 |
| Mowzie's Mobs | 16 |
| Iron's Spells 'n Spellbooks | 43 |

Providers are required only for their optional content. Some built-in definitions also require actual model-library assets; the catalog count is not a claim that every definition works with vanilla assets alone.

## Public gameplay baseline

The release includes six factions—Volkar, Avalin, Nevra, Mistwake, Roden and Morga—plus neutral cards, faction leaders and decks. It includes placement, Orders, passing and round battles; vault storage, print variants, deck building and encyclopedia; packs and table matches. This page records the debut baseline. Use the [current guide](#mwent/start) for present-day operator UI and later card-authoring features.

## Next release

[0.1.2](#mwent/version-0-1-2) preserves these 352 definitions. Cards marked 0.1.1 in the [specification catalog](#mwent/card-catalog) retain their baseline power, provisions, Deploy, Orders and keywords. Distinguish them from the 0.1.5 additions.
