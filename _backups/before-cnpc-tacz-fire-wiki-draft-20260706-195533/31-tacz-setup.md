## Base stack

| Item | Role |
| --- | --- |
| CustomNPCs | NPC base |
| TaCZ | Gun and ammunition system |
| CNPC TaCZ Fire | Addon that allows NPC firearm use |
| Optional mods | TACZ Magazines, Better Combat, faction or gun-related addons |

## First setup checklist

1. Start with one test NPC.
2. Decide the gun, ammo, range, and whether reload is enabled.
3. Decide whether target filtering is needed.
4. Check whether melee fallback should exist.

## Minimum verification flow

- confirm the gun appears correctly
- test firing animation and fire frequency
- confirm reload behavior when ammo runs out
- verify that friendly or excluded targets are not hit by mistake
